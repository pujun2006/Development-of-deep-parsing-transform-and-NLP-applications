Domain_Data_Fine-tuning.py这段代码演示了在自然语言处理（NLP）项目中，进行**数据预处理与划分的标准工程流程**。它特别针对机器学习实战中的两个核心痛点进行了规范处理：**防止数据泄露**和**处理类别不平衡**。

下面详细拆解代码的核心逻辑和工程考量：

---

### 一、 核心步骤逐行解析

#### 1. 模拟加载金融和医学领域数据集

```python
data = {
    "text": [...],
    "label": [0, 1, 0, 1, 0, 1]  # 0-finance, 1-medical
}
df = pd.DataFrame(data)

```

* 构建了一个包含 6 条文本的 Pandas 数据框（DataFrame），模拟一个包含金融（标签 `0`）和医学（标签 `1`）的二分类文本分类任务。

#### 2. 划分训练集与测试集（防数据泄露）

```python
train_df, test_df = train_test_split(df, test_size=0.33, random_state=42, stratify=df["label"])

```

* **核心动作**：**先划分数据集，再做数据处理/重采样**。
* **`stratify=df["label"]`（分层抽样）**：确保训练集和测试集中，金融和医学样本的比例与原数据集保持一致，避免因随机划分导致某个类别在测试集里缺失。
* **工程意义（防数据泄露）**：必须在划分出测试集*之后*，才对训练集进行重采样、清洗等操作。如果先重采样再划分，测试集的数据可能会“泄露”到训练集中（例如重采样导致训练集和测试集出现重复样本），从而导致模型评估结果严重失真（虚高）。

#### 3. 训练集的平衡重采样（处理类别不平衡）

```python
finance_train = train_df[train_df.label == 0]
medical_train = train_df[train_df.label == 1]

finance_upsampled = resample(
    finance_train,
    replace=True,
    n_samples=len(medical_train),
    random_state=42
)
train_balanced = pd.concat([finance_upsampled, medical_train])

```

* **背景**：在真实业务中，不同类别的样本量往往不均衡（例如金融文本多，医学文本少）。
* **操作**：代码通过 `scikit-learn` 的 `resample` 工具，对少数类或多数类进行过采样/欠采样（这里演示了对金融类别 `finance_train` 进行有放回抽样 `replace=True`，使其样本量与医学类别保持一致），最后通过 `pd.concat` 合并为一个平衡的新训练集 `train_balanced`。

#### 4. 使用 BERT 分词器（Tokenizer）处理文本

```python
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

train_encodings = tokenizer(
    train_balanced["text"].tolist(),
    padding=True,
    truncation=True,
    return_tensors="pt"
)

```

* **加载分词器**：加载预训练的 `bert-base-uncased` 分词器（大小写不敏感）。
* **批量编码（Batch Encoding）**：
* 将平衡后的文本列表转为 Python 列表传入分词器。
* `padding=True`：将批次内较短的文本自动填充（Pad）到与最长文本相同的长度，以便形成整齐的张量矩阵输入模型。
* `truncation=True`：当文本长度超过 BERT 的最大限制（通常为 512 个 Token）时，自动进行截断。
* `return_tensors="pt"`：直接将结果转换为 PyTorch 张量（Tensor），方便后续直接送入神经网络训练。


* **注释强调的规范**：现代 Transformer 模型（如 BERT）具有强大的语境理解和子词切分能力（WordPiece），因此**无需手动使用复杂的正则表达式清洗**数字、标点或特殊符号，保留原始文本即可。

#### 5. 打印与验证

```python
print("编码后的 input_ids 维度:", train_encodings["input_ids"].shape)
print("第一个样本还原为 Token:", tokenizer.convert_ids_to_tokens(train_encodings["input_ids"][0]))

```

* **`input_ids.shape`**：输出张量的形状（例如 `[Batch_Size, Sequence_Length]`），用于检查批次大小和对齐后的文本长度是否正确。
* **`convert_ids_to_tokens`**：将编码后的数字 ID 重新反解成 Token（词块），用于人工抽样检查分词效果是否符合预期（例如观察是否正确切出了 `[CLS]`、`[SEP]` 以及子词）。

### 三、 这段代码在实际项目中的价值

这段代码虽然简短，但包含了工业级 NLP 文本分类任务的几个黄金法则：

1. **严格的流程先后顺序**：数据划分 $\rightarrow$ 训练集重采样 $\rightarrow$ 分词编码。
2. **高效的批处理模式**：利用 Hugging Face Transformers 的向量化分词接口，一次性处理整个列表，效率远高于循环单条处理。
