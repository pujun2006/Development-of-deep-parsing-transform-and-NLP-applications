LoRA_PT.py代码实现了一个**从零手写（From Scratch）的 LoRA（Low-Rank Adaptation）核心模块**，并将其成功注入到 Hugging Face 的 BERT 模型中，完成了对自注意力机制（Self-Attention）的参数高效微调。

下面详细拆解这段代码的核心实现逻辑：

---

### 一、 标准 LoRA 线性层实现 (`LoRALinear` 类)

这是整个代码的核心，它通过自定义一个 PyTorch 模块，包裹了原本的线性层，并引入了低秩旁路。

```python
class LoRALinear(nn.Module):
    def __init__(self, original_linear: nn.Linear, rank: int = 8, alpha: float = 16.0):
        super(LoRALinear, self).__init__()
        self.in_features = original_linear.in_features
        self.out_features = original_linear.out_features
        self.rank = rank
        self.scaling = alpha / rank

        # 1. 冻结原始线性层的权重
        self.linear = original_linear
        self.linear.weight.requires_grad = False
        if self.linear.bias is not None:
            self.linear.bias.requires_grad = False

        # 2. 定义低秩分解矩阵 A 和 B
        self.lora_A = nn.Parameter(torch.zeros(rank, self.in_features))
        self.lora_B = nn.Parameter(torch.zeros(self.out_features, rank))

        # 3. 参数初始化
        nn.init.kaiming_uniform_(self.lora_A, a=math.sqrt(5))
        nn.init.zeros_(self.lora_B)

```

* **权重冻结**：把传入的 `original_linear` 的 `requires_grad` 设为 `False`，确保原模型权重在训练时不会发生改变。
* **低秩矩阵**：
* `lora_A` 形状为 `(rank, in_features)`，负责降维。
* `lora_B` 形状为 `(out_features, rank)`，负责升维。


* **零初始化技巧**：`lora_B` 初始化为全 0。这意味着**在训练开始的第一步，`lora_A @ lora_B` 的乘积结果为 0**，LoRA 旁路的输出为 0，模型行为与原模型完全一致，保证了训练的平稳过渡。
* **缩放系数 (`scaling`)**：<img width="45" height="39" alt="cea67c51-8b90-4046-a92f-580838a77e43" src="https://github.com/user-attachments/assets/04ef18c5-7f6f-4c10-8827-3cd1d1e491f3" />
，用于控制 LoRA 权重更新的缩放比例。

```python
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # 1. 计算原始权重的输出 (已冻结)
        result = self.linear(x)
        # 2. 计算旁路低秩更新: x @ A.T @ B.T * scaling
        lora_update = (x @ self.lora_A.T) @ self.lora_B.T
        return result + lora_update * self.scaling

```

* **前向传播公式**：最终输出等于原线性层输出加上低秩更新：`output = original(x) + (x @ A.T @ B.T) * scaling`。

### 二、 初始化 BERT 并冻结基座

```python
# 初始化 BERT 模型
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
model = BertModel.from_pretrained("bert-base-uncased")

# 冻结模型的所有基础参数
for param in model.parameters():
    param.requires_grad = False

```

* 加载标准的 `BertModel`，并通过全局遍历将其所有参数的梯度计算关闭（`requires_grad = False`）。

---

### 三、 将 LoRA 注入到注意力机制中

```python
# 将 LoRA 注入到 BERT 各层的 Self-Attention Query & Value 矩阵中
for layer in model.encoder.layer:
    layer.attention.self.query = LoRALinear(layer.attention.self.query, rank=8, alpha=16.0)
    layer.attention.self.value = LoRALinear(layer.attention.self.value, rank=8, alpha=16.0)

```

* **精准注入**：遍历 BERT 的每一层 Transformer 编码器（`model.encoder.layer`），将自注意力机制（Self-Attention）中的查询矩阵（Query）**和**值矩阵（Value）的线性层替换为我们刚才定义的 `LoRALinear`。
* *(注：在很多 LoRA 实现中，通常只对 Query 和 Value 注入，或者同时对 Query、Key、Value、Dense 全都注入。这里选择了 Q 和 V)*。

---

### 四、 优化器配置与参数过滤

```python
# 只将可训练的 LoRA 参数加入优化器
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = optim.AdamW(trainable_params, lr=1e-3)

print(f"总训练参数量: {sum(p.numel() for p in trainable_params)} 个")

```

* 通过列表推导式筛选出所有 `requires_grad == True` 的参数（即我们刚刚创建的 `lora_A` 和 `lora_B`）。
* 将这些极少量的参数传给 `AdamW` 优化器。打印出来的可训练参数量通常仅占原模型总参数量的 0.1% ~ 1% 左右。

---

### 五、 前向传播与测试训练

```python
inputs = tokenizer("LoRA is a parameter-efficient fine-tuning method.", return_tensors="pt")

model.train()
optimizer.zero_grad()
outputs = model(**inputs)
loss = outputs.last_hidden_state.pow(2).mean()
loss.backward()
optimizer.step()

print(f"训练 1 步完成，Loss: {loss.item():.4f}")

```

* 模拟了一次完整的训练迭代：分词 $\rightarrow$ 前向传播 $\rightarrow$ 计算虚拟 Loss（利用输出的平方均值代替真实标签 Loss 验证流程） $\rightarrow$ 反向传播（梯度仅回传到 `lora_A` 和 `lora_B`） $\rightarrow$ 优化器更新参数。
* 这一步完整验证了自定义 LoRA 模块能够无缝嵌入 Hugging Face 模型并正常运作。
