Parameter freezing.py代码实现了一个基于 **BERT** 模型进行文本分类任务时的**部分层冻结微调（Partial Freezing Fine-Tuning）**。

核心思想是：**保留 BERT 底层学习到的通用语言特征，只解冻并训练高层及分类头，以节省显存并防止灾难性遗忘。**

下面逐段详细拆解代码的具体作用：

---

### 一、 核心步骤逐行解析

#### 1. 加载预训练模型与分词器

```python
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
model = BertForSequenceClassification.from_pretrained("bert-base-uncased")

```

* **分词器（Tokenizer）**：负责将文本转化为 BERT 能够理解的 Token ID。
* **模型（Model）**：加载标准预训练模型 `bert-base-uncased`（包含 12 层 Transformer Encoder，顶层带有用于分类的 `classifier` 全连接层）。

#### 2. 示例数据与预处理

```python
sentences = ["Machine learning is evolving.", "Natural language processing is intriguing."]
labels = torch.tensor([1, 0])
inputs = tokenizer(sentences, return_tensors="pt", padding=True, truncation=True)

```

* 准备了两句简单的英文文本和对应的二分类标签 `[1, 0]`。
* 通过分词器批量处理文本，生成 PyTorch 张量（`return_tensors="pt"`），并自动完成了填充（`padding`）和截断（`truncation`）。

#### 3. 精准冻结参数（核心逻辑）

```python
for name, param in model.named_parameters():
    if "embeddings" in name or any(f"encoder.layer.{i}." in name for i in range(10)):
        param.requires_grad = False
    else:
        param.requires_grad = True

```

* **遍历参数**：`model.named_parameters()` 可以获取 BERT 模型中每一个参数的名称（`name`）和张量（`param`）。
* **冻结条件**：
* 如果参数名称包含 `embeddings`（词嵌入层），或者属于 `encoder.layer.0` 到 `encoder.layer.9`（前 10 层编码器），则设置 `param.requires_grad = False`。这会关闭这些层的梯度计算，使其在反向传播时保持不变。


* **解冻条件**：
* 剩余的层（即 BERT 的第 10、11 层，以及后面的 `pooler` 和分类器 `classifier`）设置 `param.requires_grad = True`，允许在训练中更新权重。



*(注：`bert-base` 一共有 12 层，索引从 0 到 11。这里冻结了 0~9 层，实际只训练最后 2 层 + 分类头)*。

#### 4. 打印可训练的层

```python
trainable_layers = [name for name, param in model.named_parameters() if param.requires_grad]
...

```

* 过滤并打印出所有 `requires_grad=True` 的参数名称，用来**安全检查**是否成功冻结了指定层。

#### 5. 定义优化器

```python
optimizer = AdamW(filter(lambda p: p.requires_grad, model.parameters()), lr=2e-5)

```

* 使用 `AdamW` 优化器。关键点在于 `filter(lambda p: p.requires_grad, model.parameters())`——**只把需要梯度的参数传给优化器**。被冻结的参数不会被优化器更新，从而节省了优化器状态所需的显存。

#### 6. 训练循环

```python
model.train()
for epoch in range(3):
    optimizer.zero_grad()
    outputs = model(**inputs, labels=labels)
    loss = outputs.loss

    loss.backward()
    optimizer.step()

    print(f"Epoch {epoch + 1} Loss: {loss.item():.4f}")

```

* **`model.train()`**：将模型设置为训练模式。
* **`optimizer.zero_grad()`**：清空上一轮的梯度。
* **前向传播**：将处理好的输入和标签传入模型，计算出模型输出及交叉熵损失（`loss`）。
* **`loss.backward()`**：反向传播计算梯度。因为前 10 层被设为了 `requires_grad = False`，PyTorch 不会为它们计算和存储梯度，极大节省了计算开销。
* **`optimizer.step()`**：仅更新那些 `requires_grad = True` 的参数。

### 三、 这种写法的实际应用场景

1. **算力有限**：当显存较小、带不动全量微调时，冻结大部分底层可以减少显存中梯度和优化器状态的占用。
2. **防过拟合（小数据集）**：如果你的训练样本非常少，微调全部参数容易导致模型“学偏”或过拟合。锁定底层的通用语言学特征，只训练高层来适应特定任务，通常能取得更稳健的效果。
