在大模型（LLM）时代，参数高效微调（PEFT - Parameter-Efficient Fine-Tuning）是降低训练成本、提升部署效率的核心技术。传统的全量微调需要更新模型的所有参数，而 PEFT 仅需训练极少量的附加参数或模型原参数的子集，就能达到接近甚至超越全量微调的效果。

以下为您详细拆解目前最经典的三种 PEFT 方法：**Adapter Tuning**、**Prefix Tuning** 和 **LoRA** 的核心原理。

---

## 一、 Adapter Tuning（适配器微调）

Adapter Tuning 最早由 Houlsby 等人在 2019 年提出，是结构修改型微调的鼻祖。

### 1. 核心原理

Adapter 的核心思想是：**保持原有 Transformer 层的权重完全冻结（Frozen），在每个 Transformer 块（Transformer Block）内部嵌入小型的前馈神经网络子模块（称为 Adapter 模块）。**

在标准的 Transformer 层中，通常包含自注意力机制（Self-Attention）和前馈网络（FFN），并且每层都有残差连接（Residual Connection）。Adapter 通常被插入在这两个子层之后。

### 2. 网络结构与计算流程

一个典型的 Adapter 模块包含“瓶颈（Bottleneck）”结构，其计算过程如下：

1. **降维投影（Down-projection）**：将高维特征向量 $h$ 投影到一个低维空间（假设维度从 $d$ 降到 $m$，其中 $m \ll d$）。这极大地减少了需要训练的参数量。
2. **非线性激活**：通过一个激活函数（如 ReLU 或 GeLU）。
3. **升维投影（Up-projection）**：将低维特征再投影回原来的高维空间 $d$。
4. **残差连接**：将变换后的输出与原始输入 $h$ 相加输出：$h' = h + \text{Up}(\text{Activation}(\text{Down}(h)))$。

### 3. 优缺点

* **优点**：训练参数量极小（通常不到原模型参数的 1%），显存占用低。
* **缺点**：由于在 Transformer 内部串联了额外的子模块，**增加了模型前向推理的计算路径与延迟（Inference Latency）**。

---

## 二、 Prefix Tuning（前缀微调）

Prefix Tuning 由 Li 和 Liang 在 2021 年提出，它改变了微调的视角：**不修改模型内部的网络结构，而是通过在输入序列前拼接可训练的“连续虚拟前缀”来引导模型。**

### 1. 核心原理

在传统的提示词工程（Prompt Engineering）中，我们人工编写如“请将以下文本翻译为英文：”的离散文本。而 Prefix Tuning 将其转化为**可直接优化的连续张量（Continuous Tensors）**。

* 对于每一层的注意力机制（Attention），模型原本会计算自注意力的 Key ($K$) 和 Value ($V$) 矩阵。
* Prefix Tuning 在每个 Transformer 层的 $K$ 和 $V$ 矩阵前面，**拼接（Concatenate）一组可训练的连续向量**（称为 Prefix）。

### 2. 计算公式变化

在计算注意力权重时：


$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right)V$$


引入 Prefix 后，$K$ 和 $V$ 变成了：

* $K_{new} = [\text{Prefix}_K ; K]$
* $V_{new} = [\text{Prefix}_V ; V]$
其中 $\text{Prefix}_K$ 和 $\text{Prefix}_V$ 是随机初始化并随训练更新的矩阵。模型在计算注意力时，会把这些前缀当作“记忆”或“上下文”参考。

### 3. 优缺点

* **优点**：推理时可以与原模型合并或无缝拼接，**不会增加模型主干的结构复杂度，没有额外的推理延迟**。
* **缺点**：
* 改变了模型的输入序列长度（占用了宝贵的 Context Window）。
* 优化过程相对不稳定，直接对连续前缀进行反向传播较难收敛，通常需要通过多层感知机（MLP）重新参数化后再训练。

## 三、 LoRA（Low-Rank Adaptation，低秩适应）

LoRA 由微软研究团队于 2021 年提出，是目前大模型微调中最主流、应用最广泛的技术。

### 1. 核心原理

LoRA 基于一个关键假设：**大模型在适应特定下游任务时，其参数权重的更新矩阵（$\Delta W$）具有较低的“内禀秩”（Intrinsic Rank）。**

也就是说，虽然大模型有数十亿参数，但决定其微调方向的有效维度其实很低。因此，我们不需要去完整更新巨大的权重矩阵 $W_0$，而是可以用**两个低秩小矩阵相乘**来近似权重的变化量。

### 2. 数学表达

对于预训练权重矩阵 $W_0 \in \mathbb{R}^{d \times k}$，在全量微调中，其更新为：


$$W = W_0 + \Delta W$$


在 LoRA 中，将更新矩阵 $\Delta W$ 分解为两个低秩矩阵 $A$ 和 $B$ 的乘积：


$$\Delta W = B \times A$$


其中：

* $W_0$ 被**冻结**（`requires_grad = False`）。
* $A \in \mathbb{R}^{r \times k}$，使用高斯分布随机初始化。
* $B \in \mathbb{R}^{d \times r}$，初始化为全 $0$ 矩阵（确保训练刚开始时 $\Delta W = 0$，模型输出与原模型一致）。
* **秩（Rank） $r$** 远小于 $d$ 和 $k$（通常取 $r = 8, 16, 32$ 等）。

前向传播的计算公式为：


$$h = W_0 x + \Delta W x = W_0 x + BA x$$

### 3. 部署零推理延迟（Zero Inference Latency）

LoRA 的一大杀手级优势在于**部署极度友好**。
在训练完成后，由于矩阵运算具有线性叠加性，我们可以直接将低秩矩阵的乘积加回到原模型权重中：


$$W_{\text{final}} = W_0 + BA$$


合并后，模型在推理时**没有任何额外的计算开销和结构修改**，与原生大模型完全一致。

## 四、 三种方法核心对比总结

| 维度 | Adapter Tuning | Prefix Tuning | LoRA |
| --- | --- | --- | --- |
| **修改位置** | 模型内部结构（串联额外 FFN 模块） | 注意力层的 Key/Value（拼接连续前缀） | 线性权重层（旁路低秩矩阵相加） |
| **参数量** | 极少（~0.5% - 5%） | 极少（由前缀长度决定，通常 <0.1%） | 极少（通常占原模型 0.1% - 1%） |
| **推理延迟** | **有延迟**（增加了串联层计算） | **无延迟**（不改变结构长度） | **无延迟**（可合并入原权重矩阵） |
| **工程实现难度** | 中等（需修改 Transformer 架构代码） | 中等（需干预 Attention 层的键值拼接） | 极其简单（仅替换 Linear 层为 LoRA 线性层） |
| **当前应用热度** | 较低（逐渐被替代） | 中等（部分场景使用） | **极高（行业绝对主流）** |
