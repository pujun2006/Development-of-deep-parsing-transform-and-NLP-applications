Adapter_Tuning.py代码实现了一个基于 **Adapter Tuning（适配器微调）** 的经典架构：通过在 Hugging Face BERT 模型的各个 Transformer 层内部（Self-Attention 和 FFN 之后）串联低维的瓶颈（Bottleneck）Adapter 模块，冻结原模型的所有参数，仅训练 Adapter 相关的极少量参数。

下面详细拆解这段代码的核心实现逻辑：

---

### 一、 定义标准的 Bottleneck Adapter 模块 (`Adapter` 类)

这是 Adapter Tuning 的灵魂结构，实现了特征的“降维 $\rightarrow$ 激活 $\rightarrow$ 升维 $\rightarrow$ 残差连接”。

```python
class Adapter(nn.Module):
    def __init__(self, input_dim=768, bottleneck_dim=64):
        super(Adapter, self).__init__()
        self.down_project = nn.Linear(input_dim, bottleneck_dim)
        self.activation = nn.GELU()  # BERT 通常搭配 GELU 激活函数
        self.up_project = nn.Linear(bottleneck_dim, input_dim)
        self.layer_norm = nn.LayerNorm(input_dim)

    def forward(self, x):
        residual = x
        adapter_out = self.up_project(self.activation(self.down_project(x)))
        return self.layer_norm(residual + adapter_out)

```

* **瓶颈结构（Bottleneck）**：BERT 的隐藏层维度 `input_dim = 768`，而 Adapter 内部将其降维到 `bottleneck_dim = 64`。这极大地压缩了中间计算量和参数量。
* **残差连接与层归一化（Residual & LayerNorm）**：输入 `x` 先通过“降维 $\to$ 激活 $\to$ 升维”得到 `adapter_out`，然后与原输入 `x` 相加（残差连接），最后再过一层 `LayerNorm`。这与公式 `h' = LayerNorm(h + Up(Activation(Down(h))))` 完全对应。

---

### 二、 包装完整的 Output 模块 (`AdapterOutputWrapper` 类)

由于 BERT 内部的 `layer.attention.output` 和 `layer.output` 并不是单纯的线性层，而是包含了 `Dense`、`Dropout` 和 `LayerNorm` 的复杂子模块，因此需要用一个 Wrapper（包装器）将其串联起来。

```python
class AdapterOutputWrapper(nn.Module):
    def __init__(self, original_output, bottleneck_dim=64):
        super(AdapterOutputWrapper, self).__init__()
        self.original_output = original_output
        self.adapter = Adapter(original_output.dense.out_features, bottleneck_dim)

    def forward(self, hidden_states, input_tensor):
        # 1. 先执行原本 BERT Output 层的 Dense + Dropout + LayerNorm
        orig_out = self.original_output(hidden_states, input_tensor)
        # 2. 再将结果送入 Adapter 进行残差学习
        return self.adapter(orig_out)

```

* **串联嵌入**：它拦截了原本 BERT 子层的输出（`orig_out`），并将其无缝喂给新定义的 `Adapter` 模块，从而在不破坏原网络主干流的前提下引入了适配能力。

---

### 三、 将 Adapter 注入到 BERT 各层中

```python
for layer in model.encoder.layer:
    # 替换 Attention 后的 Output 层
    layer.attention.output = AdapterOutputWrapper(layer.attention.output)
    # 替换 FFN 后的 Output 层
    layer.output = AdapterOutputWrapper(layer.output)

```

* 遍历 BERT 的每一层编码器（`model.encoder.layer`），将原有的 Self-Attention 输出层和前馈网络（FFN）输出层替换为我们写好的 `AdapterOutputWrapper`。这就是 Adapter “内嵌于 Transformer 内部”的直接体现。

---

### 四、 参数冻结与精确过滤

```python
# 1. 冻结 BERT 原生参数
for param in model.parameters():
    param.requires_grad = False

# 2. 仅解冻包含 "adapter" 名字的参数
for name, param in model.named_parameters():
    if "adapter" in name:
        param.requires_grad = True

# 3. 过滤出可训练参数并初始化优化器
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = optim.AdamW(trainable_params, lr=1e-3)

```

* **全局冻结**：先将模型所有参数设为 `requires_grad = False`。
* **精准解冻**：通过遍历参数名称，把带有 `"adapter"` 关键字的参数设为 `requires_grad = True`（即我们刚才注入的 Adapter 内部的线性层和 LayerNorm）。
* 打印出的参数量对比可以发现，可训练参数通常只占总参数量的极小一部分（通常不到 1% ~ 2%）。

### 五、 模拟前向传播与训练

```python
text = "Adapter Tuning is a method for efficient model fine-tuning."
inputs = tokenizer(text, return_tensors="pt", padding=True, truncation=True)

model.train()
for epoch in range(3):
    optimizer.zero_grad()
    outputs = model(**inputs)
    loss = outputs.last_hidden_state.pow(2).mean()
    loss.backward()
    optimizer.step()
    print(f"Epoch {epoch + 1}, Loss: {loss.item():.4f}")

```

* 模拟了一个完整的 3 个 Epoch 的微调训练循环：前向传播 $\rightarrow$ 计算基于隐状态的虚拟 Loss $\rightarrow$ 反向传播（梯度仅会流向我们注入的 Adapter 模块） $\rightarrow$ 优化器更新参数。
