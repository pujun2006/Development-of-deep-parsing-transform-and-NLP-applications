_Parameter_Freeze_unfreeze.py提供的两段代码分别展示了基于 **BERT** 模型微调时两种不同的层管理策略：

1. **第一段代码**：**静态部分解冻策略（Static Partial Freezing）** —— 冻结整个底座，仅显式解冻并微调**最后两层**。
2. **第二段代码**：**渐进式动态解冻策略（Gradual Dynamic Unfreezing）** —— 随着训练周期（Epoch）的推进，**逐层向内动态解冻**网络参数。

以下是对这两段代码的详细拆解与对比说明：

---

### 第一段代码：静态部分解冻策略

#### 核心代码逻辑

```python
# 1. 冻结所有BERT的层
for param in model.bert.parameters():
    param.requires_grad = False

# 2. 显式解冻特定的层（例如最后两层）
for param in model.bert.encoder.layer[-2:].parameters():
    param.requires_grad = True

# 3. 优化器仅更新 requires_grad=True 的参数
optimizer = AdamW(filter(lambda p: p.requires_grad, model.parameters()), lr=2e-5)

```

#### 逐段解析

1. **全局冻结**：`model.bert.parameters()` 包含了 BERT 底座的所有参数。将其统一设为 `requires_grad = False`，这意味着在反向传播时，这些层不会计算梯度，权重保持不变。
2. **局部解冻（最后两层）**：`model.bert.encoder.layer[-2:]` 获取了 Transformer 编码器的最后两层（对 `bert-base` 而言是第 10 层和第 11 层）。将它们设为 `requires_grad = True`，允许它们更新。
* *注意*：`BertForSequenceClassification` 顶层的分类器（Classifier Head）本身就是随机初始化且默认可训练的（`requires_grad = True`），因此无需额外手动解冻。


3. **优化器过滤**：通过 `filter(lambda p: p.requires_grad, model.parameters())`，只把最后两层和分类头的参数交由 `AdamW` 更新，大幅节省了显存和计算资源。

#### 应用场景

* 算力或显存有限，希望快速完成微调。
* 任务与预训练任务差异中等，仅需微调高层语义表示来适应新标签。

---

### 第二段代码：渐进式动态解冻策略

#### 核心代码逻辑

```python
# 初始冻结所有层
for param in model.bert.parameters():
    param.requires_grad = False

# 在训练循环中动态解冻
for epoch in range(3):  
    if epoch < len(model.bert.encoder.layer):
        # 每一个 epoch 顺次向内解冻新的一层
        for param in model.bert.encoder.layer[-(epoch + 1)].parameters():
            param.requires_grad = True

    # 训练步骤...

```

#### 逐段解析

1. **动态解冻机制**：代码在训练循环（`for epoch in range(3)`）内部嵌入了层解冻逻辑：
* **Epoch 1 (`epoch = 0`)**：解冻 `-(0 + 1)`，即倒数第 1 层（`layer[-1]`）。
* **Epoch 2 (`epoch = 1`)**：解冻 `-(1 + 1)`，即倒数第 2 层（`layer[-2]`）（此时倒数第 1 层依然保持解冻状态并继续训练）。
* **Epoch 3 (`epoch = 2`)**：解冻 `-(2 + 1)`，即倒数第 3 层（`layer[-3]`）。


2. **训练随时间扩展**：随着 Epoch 增加，参与训练的参数量逐渐由少变多，模型由外向内逐渐“苏醒”。

#### 应用场景

* **防止灾难性遗忘（Catastrophic Forgetting）**：如果一上来就全量微调或解冻高层，由于预训练权重和新任务数据分布有差异，可能会引起梯度剧烈震荡。渐进式解冻允许高层先稳定适应新任务，再逐渐让更深的底层参与微调，使模型过渡更平滑。
* **精细化调优**：常见于学术界或对模型精度要求极高的工业级微调场景中。
