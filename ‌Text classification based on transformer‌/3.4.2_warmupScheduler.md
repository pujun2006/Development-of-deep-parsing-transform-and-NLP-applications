warmupScheduler.py代码展示了在文本分类微调中最标准的优化方案：**结合 Warmup（预热）与线性衰减（Linear Decay）的学习率调度器**（使用了 Hugging Face 提供的 `get_linear_schedule_with_warmup`）。

代码中存在两处小小的语法笔误（第 36 行的 `int(0.1 total_steps)` 漏写了乘号 `*`，以及最后一行 `print` 语句中的字符串换行），修复这些小瑕疵后，其核心逻辑与上一版代码相比主要有两大升级：**引入了 Warmup 机制**，并将**学习率的更新频率从“按 Epoch”提升到了“按 Step（步数）”**。

下面详细拆解这段代码的核心逻辑与升级点：

---

### 一、 核心升级：Warmup 与按 Step 更新学习率

相较于上一版使用的 `StepLR`（每个 Epoch 结束时降一次学习率），这段代码的核心改动体现在优化器配置和训练循环中：

```python
# 1. 计算总步数与 warmup 步数
total_steps = len(train_loader) * 3  # 总步数 = (每个 epoch 的 batch 数) × 3 个 epoch
warmup_steps = int(0.1 * total_steps)  # 取总步数的 10% 作为 warmup 阶段

# 2. 引入 Hugging Face 标准调度器
scheduler = get_linear_schedule_with_warmup(
    optimizer, 
    num_warmup_steps=warmup_steps, 
    num_training_steps=total_steps
)

```

* **总步数（`total_steps`）**：在基于 Step 的调度器中，必须明确整个训练过程总共会进行多少次参数更新。这里通过 `len(train_loader) * 3` 计算出 3 个 Epoch 的总迭代步数。
* **Warmup 步数（`warmup_steps`）**：设置为总步数的 10%（即前 10% 的 Step 学习率从 0 线性增加到 `2e-5`）。
* **线性衰减（Linear Decay）**：在度过 Warmup 阶段后，接下来的 90% 的 Step 中，学习率会以线性方式匀速衰减至 0。

---

### 二、 训练循环的改动点

```python
for epoch in range(3):  
    for batch in train_loader:
        optimizer.zero_grad()

        input_ids = batch["input_ids"].to(device)
        attention_mask = batch["attention_mask"].to(device)
        labels = batch["labels"].to(device)

        outputs = model(input_ids, attention_mask=attention_mask, labels=labels)
        loss = outputs.loss
        loss.backward()

        optimizer.step()

        # 【核心改动】每个 Batch 结束时立即更新学习率
        scheduler.step()

```

* **按 Step 更新（`scheduler.step()` 的位置）**：
* 在上一版使用 `StepLR` 时，`scheduler.step()` 放在 Epoch 循环内部、Batch 循环外部（每个 Epoch 调一次）。
* 而在 `get_linear_schedule_with_warmup` 中，**`scheduler.step()` 必须放在每个 Batch 内部、`optimizer.step()` 之后**。这意味着学习率在每一个 Step 都在发生极其微小的变化（前 10% 递增，后 90% 递减），从而让 Transformer 模型的训练轨迹极其平滑。



---

### 三、 其余部分简要梳理

* **自定义数据集 (`SampleDataset`)**：
* 负责清洗文本（去标点、转小写）、使用 BERT Tokenizer 进行分词与填充（`max_length=128`），并转为 PyTorch 张量。


* **模型与数据加载**：
* 加载 `bert-base-uncased` 用于二分类。注意：**此代码中没有像上一版那样显式冻结前几层**，这意味着默认会对 BERT 的所有层（包括主干网络和分类头）进行全面微调（Full Fine-tuning）。


* **修正后的打印输出**：
* 循环结束后打印最后一个 Batch 的损失值以及当前的实际学习率（通过 `scheduler.get_last_lr()[0]` 获取）。在 Warmup 期间，你能观察到学习率从非常小的值逐渐上升；而在中后期，则会看到它稳步下降。
