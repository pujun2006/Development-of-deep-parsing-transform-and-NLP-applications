这段代码展示了一个经典的**机器学习文本分类流水线（Pipeline）**。与上一段代码的“基于规则（Rule-Based）”不同，这段代码采用的是基于统计与机器学习模型（Machine Learning Based）的方法。

代码对比并实现了两种常见的中文文本分类方案：

1. **方案一：TF-IDF 特征提取 + 支持向量机（SVM）分类器**
2. **方案二：Word2Vec 词向量表征（求平均） + 逻辑回归（Logistic Regression）分类器**

---

## 一、 代码整体流程总览

1. **准备数据集**：定义了 12 条中文文本，均匀分布在“科技”、“体育”、“财经”三个类别中。
2. **划分数据集**：使用 `train_test_split` 按 3:1 的比例将数据集划分为训练集（9条）和测试集（3条），并通过 `stratify=labels` 保证训练集和测试集中的类别比例一致。
3. **中文分词准备**：中文不像英文有天然的空格分词，因此需要使用 `jieba` 库进行分词处理。
4. **模型训练与评估**：分别用两种不同的特征工程与机器学习模型组合进行训练，并输出准确率及分类报告。

### 2. 方案一：TF-IDF + Linear SVM

这是处理文本分类非常经典且高效的“干练”组合。

```python
def chinese_tokenizer(text):
    return list(jieba.cut(text))

tfidf_vectorizer = TfidfVectorizer(tokenizer=chinese_tokenizer, token_pattern=None)
svm_model = SVC(kernel='linear', C=1.0)
pipeline = Pipeline([('tfidf', tfidf_vectorizer), ('svm', svm_model)])

```

* **中文分词函数 (`chinese_tokenizer`)**：将输入的完整句子切分成词语列表，传给 `TfidfVectorizer`。
* **TF-IDF (词频-逆文档频率)**：
* **原理**：衡量一个词对文档的重要程度。如果一个词在当前文档中出现次数多（TF 高），但在整个语料库中出现次数少（IDF 高），说明这个词具有很强的类别区分能力（例如“人工智能”对科技类）。
* 它会将文本转化为一个**稀疏的高维数值矩阵**（列数等于整个语料库不重复词的总数）。


* **SVM（支持向量机，Linear 线性核）**：
* **原理**：在高维空间中寻找一个最优超平面（Hyperplane），把不同类别的文本隔开。对于文本分类这种高维稀疏数据，线性 SVM 效果通常极佳且不易过拟合。


* **Pipeline（流水线）**：
* 将“文本特征提取（TF-IDF）”和“模型分类（SVM）”串联成一个整体。输入是原始文本，输出直接是预测标签，避免了手动对训练集和测试集分别做特征转换的繁琐步骤。

### 3. 方案二：Word2Vec + 逻辑回归

这种方案代表了基于分布式词嵌入（Word Embedding）的传统深度/浅层语义建模方法。

```python
# 1. 对训练集和测试集分词
X_train_segmented = [list(jieba.cut(text)) for text in X_train]
X_test_segmented = [list(jieba.cut(text)) for text in X_test]

# 2. 训练 Word2Vec 词向量模型
w2v_model = Word2Vec(
    sentences=X_train_segmented,
    vector_size=50,   # 每个词用 50 维的稠密向量表示
    window=3,         # 上下文窗口大小
    min_count=1,      # 忽略词频小于1的词
    epochs=100        # 训练迭代次数
)

```

* **Word2Vec 原理**：它通过上下文学习每个词的语义，把词映射到低维稠密向量空间（比如“人工智能”和“机器学习”在向量空间中距离会很近）。
* **文本向量化（`get_word2vec_embeddings`）**：
```python
def get_word2vec_embeddings(segmented_texts, embedding_model):
    embeddings = []
    for words in segmented_texts:
        # 获取文本中所有在词表里的词的向量
        word_vectors = [embedding_model.wv[word] for word in words if word in embedding_model.wv]
        if word_vectors:
            # 简单粗暴的方法：对一句话里所有词的向量求平均，作为整句话的句向量
            text_embedding = np.mean(word_vectors, axis=0)
        else:
            text_embedding = np.zeros(embedding_model.vector_size)
        embeddings.append(text_embedding)
    return np.array(embeddings)

```


* **句向量合成**：因为逻辑回归和许多经典模型需要固定长度的输入向量，这里采用了最常用的**词向量平均法（Average Word Embeddings）**，把一句话降维并融合成一个 50 维的特征向量。


* **逻辑回归分类（Logistic Regression）**：
* 利用合成好的句向量特征矩阵（大小为 `样本数 × 50`）训练逻辑回归多分类模型，最后对测试集进行预测。

## 四、 两种方案的本质区别对比

| 维度 | 方案一：TF-IDF + SVM | 方案二：Word2Vec + 逻辑回归 |
| --- | --- | --- |
| **特征类型** | **统计特征（稀疏高维）**：基于词频统计，字面匹配。 | **语义特征（稠密低维）**：基于上下文语义，能捕捉同义词。 |
| **句向量合成方式** | 加权词频矩阵（高维，维度=词表大小）。 | 词向量简单求平均（低维，如固定50维）。 |
| **对小数据集的适应性** | **极佳**。即便语料很少，也能通过关键词准确分类。 | **较弱**。Word2Vec 需要足够多的语料来训练语义空间，12条文本对 Word2Vec 来说太少了，容易学不到好的语义。 |
| **可解释性** | 较高（可以通过 SVM 权重看哪些词对分类贡献最大）。 | 较低（稠密向量的组合较难直观解释）。 |
