这段代码是一个使用 **PyTorch** 和 **Hugging Face Transformers** 库对中文文本进行二分类（财经/科技 vs. 体育）微调（Fine-tuning）的完整示例。它基于预训练的中文 BERT 模型（`bert-base-chinese`），涵盖了从数据准备、分词、模型加载、训练到评估的全过程。

下面为您逐段详细拆解这段代码的核心逻辑和功能：

---

### 1. 数据准备与划分

```python
texts = [...]
labels = [...]
train_texts, test_texts, train_labels, test_labels = train_test_split(
    texts, labels, test_size=0.25, random_state=42, stratify=labels
)

```

* **原始数据**：定义了 8 条短文本及其对应的标签（`1` 表示财经/科技，`0` 表示体育）。
* **`train_test_split`**：将数据集按照 3:1 的比例划分为训练集和测试集。
* **`stratify=labels`**：分层采样，确保训练集和测试集中各类别的比例与原数据集保持一致，防止因样本量小导致某类别在测试集中缺失。

---

### 2. 自定义数据集类 (`TextDataset`)

```python
class TextDataset(Dataset):
  ...

```

* 继承自 PyTorch 的 `torch.utils.data.Dataset`，用于将原始文本包装成 PyTorch 能够批量加载的格式。
* **`__getitem__` 方法**：
* 使用 `tokenizer` 对文本进行编码（Tokenization）。
* **关键参数**：
* `padding="max_length"`：将所有文本填充到统一长度。
* `truncation=True`：截断超过最大长度的文本。
* `max_length=64`：最大序列长度设为 64。
* `return_tensors="pt"`：返回 PyTorch 张量。


* 返回 `input_ids`（词对应的 ID）、`attention_mask`（注意力掩码，区分真实词和填充的 `[PAD]`）以及对应的标签。



---

### 3. 加载中文 BERT 模型和分词器

```python
MODEL_NAME = "bert-base-chinese"
tokenizer = BertTokenizer.from_pretrained(MODEL_NAME)
model = BertForSequenceClassification.from_pretrained(
    MODEL_NAME, num_labels=2
)

```

* **`BertTokenizer`**：负责将中文字符切分为 BERT 模型能理解的 Token（子词/字级别）。
* **`BertForSequenceClassification`**：带有分类头（Classification Head）的 BERT 模型。`num_labels=2` 表示这是一个二分类任务，模型会自动在 BERT 输出之上外接一个线性层，输出对应 2 个类别的 Logits（未归一化的概率）。

---

### 4. 数据加载器 (`DataLoader`)

```python
train_dataset = TextDataset(train_texts, train_labels, tokenizer)
test_dataset = TextDataset(test_texts, test_labels, tokenizer)
train_loader = DataLoader(train_dataset, batch_size=2, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=2)

```

* 将数据集包装进 `DataLoader`，设置 `batch_size=2`（每个批次处理 2 条样本）。
* 训练集设置 `shuffle=True`，在每个 Epoch 开始时打乱数据顺序，以增强模型的泛化能力。

---

### 5. 训练配置

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = model.to(device)
optimizer = optim.AdamW(model.parameters(), lr=2e-5)

```

* **设备选择**：检测并优先使用 GPU（CUDA），如果没有则退回到 CPU。
* **优化器**：使用 `AdamW`（带有权重衰减的 Adam 优化器），这是微调 Transformer 模型时的标准选择。
* **学习率（`lr`）**：设为 `2e-5`，这是微调 BERT 类模型时非常经典的较小学习率，防止破坏预训练权重。

---

### 6. 训练函数 (`train_model`)

```python
def train_model(model, data_loader, optimizer, device, epochs=5):
  model.train()
  for epoch in range(epochs):
    total_loss = 0
    for input_ids, attention_mask, labels in data_loader:
      ...
      optimizer.zero_grad()  # 清空历史梯度
      outputs = model(
          input_ids=input_ids, attention_mask=attention_mask, labels=labels
      )
      loss = outputs.loss  # 自动计算交叉熵损失
      loss.backward()  # 反向传播计算梯度
      optimizer.step()  # 更新模型参数
      total_loss += loss.item()
    print(...)

```

* **`model.train()`**：将模型设置为训练模式（启用 Dropout 等机制）。
* **标准训练循环**：
1. 将数据移至对应的设备（GPU/CPU）。
2. 梯度清零（`optimizer.zero_grad()`）。
3. 前向传播：传入输入并直接获取 `outputs.loss`（Hugging Face 模型在传入 `labels` 时会自动计算交叉熵损失）。
4. 反向传播（`loss.backward()`）。
5. 优化器更新参数（`optimizer.step()`）。


* 循环执行 5 个 Epoch。

---

### 7. 评估函数 (`evaluate_model`)

```python
def evaluate_model(model, data_loader, device):
  model.eval()
  predictions, true_labels = [], []
  with torch.no_grad():
    for input_ids, attention_mask, labels in data_loader:
      ...
      outputs = model(input_ids=input_ids, attention_mask=attention_mask)
      logits = outputs.logits
      preds = torch.argmax(logits, dim=1)  # 取概率最大的类别作为预测结果
      ...
  acc = accuracy_score(true_labels, predictions)
  ...

```

* **`model.eval()`**：切换到评估模式（关闭 Dropout 等）。
* **`torch.no_grad()`**：关闭梯度计算，节省显存并加快推理速度。
* **`torch.argmax(logits, dim=1)`**：从模型的输出 Logits 中挑选出概率最高的类别索引（0 或 1）。
* **指标计算**：利用 `sklearn` 的 `accuracy_score` 计算准确率，并通过 `classification_report` 生成详细的分类报告（包含精准率、召回率、F1 值等）。

---

### 8. 执行流程

```python
train_model(model, train_loader, optimizer, device, epochs=5)
evaluate_model(model, test_loader, device)






```

* 先后调用训练函数和评估函数，完成整个微调与测试流程。由于数据集非常小，该脚本可以快速在 CPU 或 GPU 上运行完毕。
