在文本分类任务中（特别是基于 Transformer 的 BERT 等深度学习模型的任务），**数据集加载与预处理**是连接原始文本和模型训练的桥梁。一个规范、高效的预处理流程不仅能保证模型正确读取数据，还能显著提升训练稳定性和最终准确率。

整个流程通常包含**数据加载**、**文本清洗与切分**、**分词与向量化（Tokenization）**、**标签处理**以及批次化封装（DataLoader）五个核心步骤。

---

### 一、 数据加载（Data Loading）

数据加载的目标是将原始文本和标签从外部存储（如 CSV、JSON 文件、或者在线数据集仓库）读取到内存中，并划分为训练集、验证集和测试集。

* **常见加载方式**：
* **本地文件**：使用 Python 内置的 `open`，或借助 `pandas` (`pd.read_csv()`)、`datasets` 库加载本地的 CSV/JSON 文件。
* **在线开源数据集**：使用 Hugging Face 的 `datasets` 库（如前文代码中的 `load_dataset("nyu-mll/glue", "sst2")`），能够一键下载并缓存各类经典学术数据集。


* **数据集划分**：
* 使用 `sklearn.model_selection.train_test_split` 按比例拆分。
* **关键技巧（Stratify）**：在分类任务中，务必开启 `stratify=labels`（分层采样）。这能确保划分后的训练集和测试集中，各类别样本的比例与原数据集保持一致，防止因样本量较小导致某些稀疏类别在测试集中彻底消失。



---

### 二、 文本清洗与格式化（Text Cleaning）

在送入分词器之前，需要对文本进行基础的规范化处理：

* **类型转换**：确保所有文本数据都是标准的字符串格式（`str(text)`），避免因为数据中混入数字、`NaN`（空值）或布尔值而导致程序崩溃。
* **标点与大小写处理**：
* 英文任务中，若使用 `uncased` 模型（如 `bert-base-uncased`），模型会自动转小写。
* 标点符号通常**不需要**盲目全盘剔除。对于情感分析（如 SST-2 任务），感叹号 `!`、问号 `?` 往往携带强烈的情感色彩，保留它们对模型理解语义至关重要。



---

### 三、 分词与向量化（Tokenization）

机器无法直接理解人类的文字，必须将文本转化为模型可计算的数值张量。现代预训练语言模型（如 BERT、RoBERTa）使用 **WordPiece / BPE（子词分词）** 算法。

使用预训练分词器（如 `BertTokenizer`）处理文本时，包含以下关键参数：

1. **`padding="max_length"`（填充）**：
* 批次（Batch）训练要求矩阵形状对齐。如果一条句子长度为 10，另一条长度为 50，矩阵无法合并。填充会将所有短句子后面补上特殊的 `[PAD]` 托底。


2. **`truncation=True`（截断）**：
* 模型的最大输入长度有限制（例如 BERT 经典限制为 512 个 Token）。超过 `max_length`（如设为 64 或 128）的文本会被直接截断。


3. **`return_tensors="pt"`**：
* 指定返回的数据格式为 PyTorch 张量（Tensor）。



分词器处理后会产出两个核心张量：

* **`input_ids`**：文本中每个词在模型词表（Vocabulary）中对应的数字 ID 序列。
* **`attention_mask`**：一个由 `1` 和 `0` 组成的掩码。对应真实文本的位置为 `1`，对应填充的 `[PAD]` 位置为 `0`。它告诉模型在计算自注意力机制（Self-Attention）时忽略那些填充的空白部分，避免引入噪声。

---

### 四、 标签处理（Label Encoding）

* **类型与格式**：分类任务中的标签必须转换为整型张量（`torch.tensor(label, dtype=torch.long)`）。
* **原因**：无论是二分类还是多分类，交叉熵损失函数（`CrossEntropyLoss`）在计算时都严格要求目标标签是整型类别索引（Class Index），而不能是浮点数或独热编码（One-Hot）形式。

---

### 五、 自定义 Dataset 与 DataLoader 封装

为了将上述处理逻辑和 PyTorch 的训练流程无缝对接，通常会编写自定义的 `Dataset` 类，并利用 `DataLoader` 进行批次化管理。

#### 1. 自定义 Dataset 类

继承 PyTorch 的 `torch.utils.data.Dataset`，必须实现两个核心方法：

* `__len__(self)`：返回数据集的总样本数。
* `__getitem__(self, idx)`：根据索引 `idx` 获取单条数据，并在这一步动态完成分词、填充和标签转张量。

#### 2. DataLoader 批次加载器

将 `Dataset` 传入 `DataLoader`，主要配置包括：

* **`batch_size`**：批次大小（例如 16 或 32）。它决定了每次喂给模型并行计算的样本数量，直接影响显存占用和梯度更新的平稳度。
* **`shuffle=True`（仅训练集）**：在每个 Epoch 开始时打乱数据顺序，打破样本的固有排列，防止模型因为死记硬背样本顺序而降低泛化能力。测试集和验证集通常不需要打乱（`shuffle=False`）。
