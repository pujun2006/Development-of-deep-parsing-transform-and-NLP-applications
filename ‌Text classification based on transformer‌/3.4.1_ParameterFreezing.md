这段代码实现了一个基于 PyTorch 和 Transformers 库的文本分类模型微调（Fine-tuning）完整流程，涵盖了**自定义数据集处理**、**模型层参数冻结**、**优化器配置**以及**训练循环**。

下面逐段详细拆解并梳理其核心逻辑：

---

### 一、 自定义数据集定义 (`SampleDataset`)

```python
class SampleDataset(Dataset):
    def __init__(self, texts, labels, tokenizer, max_length=128):
        self.texts = texts
        self.labels = labels
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        # 1. 文本清洗：去标点、转小写
        text = re.sub(r"[^\w\s]", "", self.texts[idx]).lower()
        
        # 2. 编码与对齐
        encoding = self.tokenizer(
            text,
            padding="max_length",
            truncation=True,
            max_length=self.max_length,
            return_tensors="pt"
        )
        
        # 3. 返回符合模型输入的张量字典
        return {
            "input_ids": encoding["input_ids"].flatten(),
            "attention_mask": encoding["attention_mask"].flatten(),
            "labels": torch.tensor(self.labels[idx], dtype=torch.long)
        }

```

* **数据清洗**：使用正则表达式 `re.sub(r"[^\w\s]", "", ...)` 去除文本中的标点符号，并通过 `.lower()` 统一转为小写（契合 `bert-base-uncased` 的预训练习惯）。
* **Tokenization**：调用 BERT 的分词器，将文本转化为 Token ID。通过 `padding="max_length"` 和 `truncation=True` 将所有输入样本规整化到固定长度（`max_length=128`），确保可以顺利打包成 Batch。
* **扁平化处理**：由于 `tokenizer` 返回的张量通常带有额外的 Batch 维度（形如 `[1, 128]`），代码中使用了 `.flatten()` 将其转为一维张量（`[128]`），以便后续通过 `DataLoader` 自动进行批处理组合。

---

### 二、 模型加载与参数冻结 (`Parameter Freezing`)

```python
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
model = BertForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=2)

# 冻结前几层参数
for name, param in model.named_parameters():
    if "encoder.layer.0" in name or "encoder.layer.1" in name or "encoder.layer.2" in name:
        param.requires_grad = False

```

* **模型初始化**：加载了支持二分类（`num_labels=2`）的预训练 BERT 序列分类模型。
* **分层冻结策略**：
* BERT 的 Transformer 主干网络通常包含 12 层（索引从 `layer.0` 到 `layer.11`）。
* 代码遍历模型的所有参数名（`name`），通过条件判断将前三层（`layer.0`, `layer.1`, `layer.2`）的 `requires_grad` 设置为 `False`。
* **效果**：在反向传播时，这前三层的权重将不会被梯度更新，从而节省显存并保护底层的通用语言学特征不被破坏。其余层（第 3 层至第 11 层及分类头）则正常参与训练。



---

### 三、 优化器与学习率调度器

```python
optimizer = AdamW(model.parameters(), lr=2e-5)
scheduler = StepLR(optimizer, step_size=1, gamma=0.9)

```

* **优化器 (`AdamW`)**：使用适用于 Transformer 的 AdamW 优化器，基础学习率设为常规的 `2e-5`。它会自动过滤掉被冻结参数（`requires_grad=False`），只对需要更新的参数计算梯度。
* **学习率调度器 (`StepLR`)**：
* 这里使用了基于 Epoch 的步进衰减策略。
* `step_size=1` 表示每经过 1 个 Epoch，学习率就会乘以衰减系数 `gamma=0.9`（即每个 Epoch 结束后，学习率变为原来的 90%）。
* *注：在标准大模型微调中，更常使用的是带有 Warmup 的线性衰减（如前面所述的 `get_linear_schedule_with_warmup`），而 `StepLR` 属于比较传统的阶梯式衰减。*

### 四、 核心训练循环 (`Training Loop`)

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)
model.train()

for epoch in range(3):  # 假设训练3个epoch
    for batch in train_loader:
        optimizer.zero_grad()  # 1. 梯度清零

        # 2. 数据搬运到 GPU/CPU
        input_ids = batch["input_ids"].to(device)
        attention_mask = batch["attention_mask"].to(device)
        labels = batch["labels"].to(device)

        # 3. 前向传播：计算模型输出与 Loss
        outputs = model(input_ids, attention_mask=attention_mask, labels=labels)
        loss = outputs.loss
        
        # 4. 反向传播：计算梯度
        loss.backward()

        # 5. 权重更新
        optimizer.step()

    # 每个epoch结束时更新学习率
    scheduler.step()
    # 修正后的打印语句格式
    print(f"Epoch {epoch + 1} Loss: {loss.item():.4f}, Learning Rate: {scheduler.get_last_lr()[0]:.6f}")

```

1. **设备迁移**：通过 `model.to(device)` 和 `batch[...].to(device)` 将模型和批次数据加载到 GPU（如果可用）中加速计算。
2. **训练模式**：`model.train()` 确保 Dropout 和 LayerNorm 等组件处于训练状态。
3. **标准训练五部曲**：
* `optimizer.zero_grad()`：清空上一轮残留的梯度。
* `outputs = model(...)`：传入输入和标签，BERT 内部会自动计算交叉熵损失（Cross-Entropy Loss）。
* `loss.backward()`：反向传播计算各参数的梯度（被冻结的层由于 `requires_grad=False`，不会产生梯度）。
