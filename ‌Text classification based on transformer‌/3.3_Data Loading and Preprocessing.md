Data Loading and Preprocessing.py代码展示了如何使用 Hugging Face 的 `datasets` 库加载经典的英文情感分类数据集 **SST-2**（来自 GLUE 评测基准），并通过 PyTorch 的自定义 `Dataset` 和 `DataLoader` 对其进行分词和批处理，以便后续输入到 BERT 模型中。

代码中包含了网络镜像加速、自定义数据集类的编写以及数据批次的验证。以下是逐段详细拆解：

---

### 1. 镜像配置与依赖导入

```python
import os
import torch
import torch.nn as nn
import torch.optim as optim
from datasets import load_dataset
from torch.utils.data import DataLoader, Dataset
from transformers import BertTokenizer

# 1. 配置国内镜像源（必须放在 import datasets 之后或最顶端，解决网络与 HfUriError 报错）
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"

```

* **`os.environ["HF_ENDPOINT"]`**：将 Hugging Face 的下载端点重定向到国内镜像站 (`hf-mirror.com`)。这可以有效解决在中国大陆由于网络限制导致无法下载或连接超时（如 `HfUriError`）的问题。

---

### 2. 自定义数据集类 (`CustomTextDataset`)

```python
class CustomTextDataset(Dataset):

  def __init__(self, texts, labels, tokenizer, max_length=128):
    self.texts = texts
    self.labels = labels
    self.tokenizer = tokenizer
    self.max_length = max_length

  def __len__(self):
    return len(self.texts)

  def __getitem__(self, idx):
    text = str(self.texts[idx])
    label = self.labels[idx]

    # 将文本转换为 BERT 输入格式
    encoding = self.tokenizer(
        text,
        padding="max_length",
        truncation=True,
        max_length=self.max_length,
        return_tensors="pt",
    )
    return {
        "input_ids": encoding["input_ids"].squeeze(0),
        "attention_mask": encoding["attention_mask"].squeeze(0),
        "label": torch.tensor(label, dtype=torch.long),
    }

```

* **继承 `Dataset**`：这是 PyTorch 处理数据的标准规范，必须实现 `__len__` 和 `__getitem__` 两个方法。
* **分词与对齐 (`tokenizer`)**：
* `padding="max_length"`：将所有句子补齐到统一长度（默认为 `128`），以便能够打包成张量。
* `truncation=True`：如果句子长度超过 `max_length` 则进行截断。
* `return_tensors="pt"`：直接返回 PyTorch 张量格式。


* **返回值**：
* `input_ids`：分词后的词表 ID 序列。
* `attention_mask`：注意力掩码（用于区分真实的词和填充的 `[PAD]` 占位符，填充部分为 0，真实部分为 1）。
* `label`：情感标签（SST-2 中 0 代表负面，1 代表正面），转为 `torch.long` 类型以便计算交叉熵损失。



---

### 3. 加载 SST-2 数据集与分词器

```python
# 2. 修改数据集加载名称为完整命名空间 "nyu-mll/glue"
dataset = load_dataset("nyu-mll/glue", "sst2")
train_texts = dataset["train"]["sentence"]
train_labels = dataset["train"]["label"]

# 初始化 BERT 分词器
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

```

* **`load_dataset("nyu-mll/glue", "sst2")`**：使用 Hugging Face 的 `datasets` 库在线加载 GLUE 任务中的 SST-2（Stanford Sentiment Treebank）数据集。
* **提取数据**：从返回的数据集中取出训练集的句子 (`sentence`) 和标签 (`label`)。
* **`bert-base-uncased`**：因为 SST-2 是英文数据集，这里加载的是**英文大小写不敏感**的 BERT 分词器（会自动将所有英文转为小写并切分词汇）。

---

### 4. 构建数据加载器 (`DataLoader`)

```python
# 创建自定义数据集
train_dataset = CustomTextDataset(train_texts, train_labels, tokenizer)

# 定义 DataLoader
batch_size = 16
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)

```

* **`train_dataset`**：实例化刚刚定义的自定义数据集类。
* **`DataLoader`**：将数据集包装成批次（Batch）加载器。
* `batch_size=16`：每个批次包含 16 条样本。
* `shuffle=True`：在每个 Epoch 开始时打乱数据顺序，防止模型学到样本的先后顺序，提升泛化能力。



---

### 5. 批次数据检查与验证

```python
# 检查 DataLoader 中的一个批次
for batch in train_loader:
  print("Input IDs 形状:", batch["input_ids"].shape)
  print("Attention Mask 形状:", batch["attention_mask"].shape)
  print("Labels 形状:", batch["label"].shape)
  print("\n第一个样本的 Input IDs:\n", batch["input_ids"][0])
  print("\nLabels 数据:\n", batch["label"])
  break

```

* **`break`**：只循环一次，专门用来抽查和验证第一个批次的数据结构和维度是否正确。
* **输出维度解析**：
* `input_ids` 的形状通常是 `[16, 128]`（Batch Size 为 16，序列最大长度为 128）。
* `label` 的形状是 `[16]`（包含 16 个样本对应的分类标签）。
* 这种字典形式的返回结构可以直接通过 `model(**batch)` 的方式传入 Hugging Face 的 BERT 模型中进行训练。
