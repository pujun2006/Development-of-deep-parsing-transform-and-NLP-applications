BERT_fine_tune.py代码在之前单一分类任务的基础上进行了扩展，展示了如何用同一套数据结构和训练逻辑，分别处理**二分类任务**（财经/科技 vs. 非财经）和**多分类任务**（财经/科技 vs. 娱乐/体育 vs. 其他）。

代码通过调整 `num_labels` 参数和传入不同的标签数据，演示了 Hugging Face `BertForSequenceClassification` 在不同任务场景下的灵活性。

---

### 一、 数据准备与多标签切分

```python
texts = [...]
binary_labels = [1, 1, 0, 0, 1, 0, 0, 0, 1, 0]  # 二分类标签
multi_labels = [0, 0, 1, 2, 0, 1, 2, 1, 0, 2]   # 多分类标签

(
    train_texts,
    test_texts,
    train_bin_labels,
    test_bin_labels,
    train_multi_labels,
    test_multi_labels,
) = train_test_split(
    texts,
    binary_labels,
    multi_labels,
    test_size=0.3,
    random_state=42,
    stratify=multi_labels,
)

```

* **多维度标签**：为同一组文本定义了两套标签：
* `binary_labels`：二分类（0 和 1）。
* `multi_labels`：多分类（0, 1, 2 三个类别）。


* **联合切分 (`train_test_split`)**：同时传入这两组标签。`stratify=multi_labels` 确保了在划分训练集和测试集时，多分类标签的类别比例保持平衡（由于样本较少，这能防止某个类别在测试集里完全消失）。

### 二、 自定义数据集类 (`TextDataset`)

```python
class TextDataset(Dataset):
  ...
  def __getitem__(self, idx):
    encoding = self.tokenizer(...)
    label = torch.tensor(self.labels[idx], dtype=torch.long)
    return (
        encoding["input_ids"].squeeze(0),
        encoding["attention_mask"].squeeze(0),
        label,
    )

```

* **复用性设计**：这个 `TextDataset` 类被设计成“通用型”的。无论是二分类还是多分类，只要传入对应的标签列表（`binary_labels` 或 `multi_labels`），它就能正常工作。
* 返回的 `label` 必须是 `torch.long`（整型张量），因为交叉熵损失函数（CrossEntropyLoss）要求标签必须是类别索引的长整型。

---

### 三、 数据加载器 (`DataLoader`) 的创建

```python
bin_train_loader = DataLoader(
    TextDataset(train_texts, train_bin_labels, tokenizer),
    batch_size=2,
    shuffle=True,
)
...
multi_train_loader = DataLoader(
    TextDataset(train_texts, train_multi_labels, tokenizer),
    batch_size=2,
    shuffle=True,
)

```

* 分别为二分类和多分类任务实例化了两套独立的 `Dataset` 和 `DataLoader`。
* `batch_size=2` 意味着每个批次包含 2 条文本。

---

### 四、 通用的训练与评估函数

代码定义了 `train_model` 和 `evaluate_model` 两个通用函数，它们**不绑定特定的类别数**，因此可以无缝应用于二分类和多分类：

1. **自动适配损失函数**：
* 在 `train_model` 中，模型前向传播 `outputs = model(input_ids=..., labels=labels)` 会直接返回计算好的 `outputs.loss`。
* `BertForSequenceClassification` 内部会根据传入的 `num_labels` 自动选择合适的损失函数：
* 当 `num_labels=2` 且标签为 0/1 时，内部使用二分类或标准的多分类交叉熵。
* 当 `num_labels=3` 时，内部使用多分类交叉熵（CrossEntropyLoss）。




2. **统一的预测逻辑 (`evaluate_model`)**：
* 模型输出的 `outputs.logits` 的形状是 `(batch_size, num_labels)`。
* 使用 `torch.argmax(outputs.logits, dim=1)` 无论面对几分类任务，都能直接选出概率最大的那一维索引作为预测类别（返回 0/1 或 0/1/2）。

### 五、 执行二分类与多分类任务

#### 1. 二分类任务

```python
print("=== 二分类任务训练 ===")
binary_model = BertForSequenceClassification.from_pretrained(
    MODEL_NAME, num_labels=2
).to(device)
bin_optimizer = optim.AdamW(binary_model.parameters(), lr=2e-5)

train_model(binary_model, bin_train_loader, bin_optimizer, device, epochs=5)
evaluate_model(binary_model, bin_test_loader, device)

```

* `num_labels=2`：告诉模型输出层的线性变换矩阵大小为 `[hidden_size, 2]`，输出 2 个 Logits。

#### 2. 多分类任务

```python
print("\n=== 多分类任务训练 ===")
multi_model = BertForSequenceClassification.from_pretrained(
    MODEL_NAME, num_labels=3
).to(device)
multi_optimizer = optim.AdamW(multi_model.parameters(), lr=2e-5)

train_model(multi_model, multi_train_loader, multi_optimizer, device, epochs=5)
evaluate_model(multi_model, multi_test_loader, device)

```

* `num_labels=3`：将模型输出层的维度改为 `[hidden_size, 3]`，输出 3 个 Logits，分别对应“财经/科技”、“娱乐/体育”、“其他”三个类别。

### 六、添加分类头

在这段代码中，添加分类头的关键代码体现在使用 **`BertForSequenceClassification`** 类加载模型的这两行：

```python
# 二分类模型的分类头（输出 2 个类别）
binary_model = BertForSequenceClassification.from_pretrained(
    MODEL_NAME, num_labels=2
).to(device)

# 多分类模型的分类头（输出 3 个类别）
multi_model = BertForSequenceClassification.from_pretrained(
    MODEL_NAME, num_labels=3
).to(device)

```

### 为什么这几行代码就是“添加分类头”？

1. **`bert-base-chinese` 的本质**：
原始的 `bert-base-chinese` 只是一个**基础语言模型（Base Model）**，它只负责理解文本、提取特征（输出每个词或整句话的特征向量，维度通常是 768），它**没有**做分类的能力。
2. **`BertForSequenceClassification` 做了什么**：
当你调用 `transformers` 库的 `BertForSequenceClassification.from_pretrained` 时，Hugging Face 在底层自动帮我们做了两件事：
* **加载骨干网络**：下载并加载 BERT 预训练的特征提取层（Transformer 编码器）。
* **自动拼接分类头（Classification Head）**：在 BERT 的输出之上，自动附加了一个 Dropout 层和一个全连接线性层（Linear Layer）。


3. **`num_labels` 参数的作用**：
* 当你传入 `num_labels=2` 时，分类头底部的线性层输出维度会被设置为 `2`（对应二分类的 2 个 Logits）。
* 当你传入 `num_labels=3` 时，线性层输出维度会被设置为 `3`（对应多分类的 3 个 Logits）。



### 内部结构示意

如果你打印 `binary_model` 的结构，你会看到它包含两部分：

* `bert`：基础的 BERT 特征提取器。
* `classifier`：新添加的分类头（通常是一个 `Dropout` 加上一个 `Linear(768 -> 2)` 或 `Linear(768 -> 3)` 的线性层）。
