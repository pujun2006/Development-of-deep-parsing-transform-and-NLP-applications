BiLSTM.py代码完整地实现了一个**基于双向 LSTM（BiLSTM）的序列分类模型**（例如用于文本情感分类、意图识别等“整个序列输出一个类别”的任务）。

与之前讨论的“序列标注（每个词都要预测一个标签）”不同，这段代码演示的是多对一（Many-to-One）的序列处理结构。下面详细拆解：

---

### 一、 模型结构初始化 (`__init__` 函数)

```python
class BiLSTMModel(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers, output_size):
        super(BiLSTMModel, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        # 双向LSTM，设置bidirectional=True
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True, bidirectional=True)
        # 全连接层
        self.fc = nn.Linear(hidden_size * 2, output_size)  # 双向，因此维度为2倍hidden_size

```

1. **`nn.LSTM` 与 `bidirectional=True**`：
* `input_size`：每个时间步输入特征的维度（例如词向量维度）。
* `hidden_size`：单向 LSTM 的隐藏层神经元数量。
* `bidirectional=True`：开启双向。


2. **全连接层 `self.fc` 的输入维度**：
* 因为是双向 LSTM，模型会同时从正向和反向处理序列，并把两个方向的隐状态在特征维度上进行拼接（Concatenate）。
* 所以全连接层的输入维度必须是 **`hidden_size * 2`**。



---

### 二、 前向传播过程 (`forward` 函数)

```python
    def forward(self, x):
        # 初始化LSTM的隐层状态和记忆单元状态，双向则num_layers需*2
        h0 = torch.zeros(self.num_layers * 2, x.size(0), self.hidden_size)
        c0 = torch.zeros(self.num_layers * 2, x.size(0), self.hidden_size)
        # LSTM的输出
        out, _ = self.lstm(x, (h0, c0))
        # 仅保留最后时间步的输出
        out = self.fc(out[:, -1, :])
        return out

```

1. **初始化隐状态 `h0` 和 `c0**`：
* 形状规则为 `(num_layers * num_directions, batch_size, hidden_size)`。
* 因为是双向（`num_directions = 2`），所以第一维的大小必须是 `num_layers * 2`。如果不显式传入 `(h0, c0)`，PyTorch 也会默认用全 0 初始化。


2. **LSTM 输出 `out**`：
* 输入 `x` 的形状为 `(batch_size, seq_length, input_size)`。
* 经过 `self.lstm(x, (h0, c0))` 后，输出 `out` 的形状是 `(batch_size, seq_length, hidden_size * 2)`。它包含了序列中**每一个时间步**的双向隐藏状态。


3. **提取最后时间步特征（Many-to-One 关键点）**：
* `out[:, -1, :]`：在序列长度维度（第 1 维，索引为 `-1`）上，只取**最后一个时间步**的输出向量。
* 这一步体现了典型的**文本分类**逻辑：把整个句子的语义浓缩到最后一个时间步的综合表征中。


4. **全连接映射**：将该向量送入 `self.fc`，输出形状为 `(batch_size, output_size)` 的类别得分（Logits）。

---

### 三、 实例化与模拟数据测试

```python
# 参数设置
input_size = 10  # 输入特征维度
hidden_size = 20  # 隐藏层维度
num_layers = 2  # LSTM层数
output_size = 5  # 输出类别数
model = BiLSTMModel(input_size, hidden_size, num_layers, output_size)

# 随机生成输入数据
batch_size = 3
seq_length = 7  # 序列长度
x = torch.randn(batch_size, seq_length, input_size)

# 模型输出
output = model(x)
print("模型输出：")
print(output)

```

* **模拟数据**：
* 创建了一个 Batch 大小为 3、序列长度为 7、每个特征维度为 10 的随机张量 `x`。


* **运行结果**：
* 模型最终输出一个形状为 `(3, 5)` 的张量（3 个样本，每个样本对应 5 个类别的预测得分），可以直接配合 `CrossEntropyLoss` 进行分类任务的训练。
