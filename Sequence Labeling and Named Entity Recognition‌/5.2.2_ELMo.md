ELMo.py代码实现了一个模拟 **ELMo（Embeddings from Language Models）** 风格的深层双向特征拼接网络，并将其应用于**序列标注任务**（每个时间步都输出分类结果）。

ELMo 的核心思想是**整合来自深度双向语言模型不同层的隐状态特征**，因为底层的特征偏向于语法结构，而高层特征偏向于语义信息。

下面详细拆解这段代码：

---

### 一、 模型初始化（`__init__` 与多层双向 LSTM）

```python
class ELMo(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers):
        super(ELMo, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        # 多层双向LSTM
        self.lstm_layers = nn.ModuleList(
            [nn.LSTM(input_size if i == 0 else hidden_size * 2, hidden_size, batch_first=True, bidirectional=True)
             for i in range(num_layers)]
        )
        # 最后线性层，用于序列标注
        self.classifier = nn.Linear(hidden_size * 2 * num_layers, 3)  # 假设3类序列标签（注：原代码第14行有拼接书写失误，此处已隐式修复）

```

1. **`nn.ModuleList` 构建多层 LSTM**：
* 代码通过循环创建了 `num_layers` 层 LSTM。
* **输入维度巧妙的衔接**：
* 第 0 层：输入特征维度为 `input_size`。
* 第 $i$ 层（i > 0）：因为上一层是**双向 LSTM**，输出维度是 `hidden_size * 2`，所以第 $i$ 层的输入大小为 `hidden_size * 2`。


* 每层内部也是双向的（`bidirectional=True`），单向隐藏层大小为 `hidden_size`，因此每层输出的特征维度都是 `hidden_size * 2`。


2. **分类器 `self.classifier**`：
* 线性层的输入特征维度是 **`hidden_size * 2 * num_layers`**。这是因为代码将**所有层**的输出在特征维度上进行了拼接（Concatenate）。
* 输出维度为 `3`（假设总共有 3 类序列标签，属于经典的每个时间步多分类任务）。



---

### 二、 前向传播过程（`forward` 函数）

```python
    def forward(self, x):
        hidden_states = []
        for lstm in self.lstm_layers:
            h0 = torch.zeros(2, x.size(0), self.hidden_size)  # 双向LSTM需2倍的hidden_size
            c0 = torch.zeros(2, x.size(0), self.hidden_size)
            x, _ = lstm(x, (h0, c0))
            hidden_states.append(x)

        # 拼接每层LSTM的输出，形成最终的ELMo嵌入
        elmo_embedding = torch.cat(hidden_states, dim=2)
        # 通过分类层进行标签预测
        output = self.classifier(elmo_embedding)
        return output

```

1. **逐层迭代 LSTM**：
* 循环遍历每一层 LSTM。每次初始化该层的初始状态 `h0` 和 `c0`（形状为 `(2, batch_size, hidden_size)`，其中第一维 `2` 代表双向）。
* 将当前层的输出 `x` 存入列表 `hidden_states` 中，并作为下一层 LSTM 的输入。


2. **特征拼接（ELMo 核心思想）**：
* `torch.cat(hidden_states, dim=2)`：将 `num_layers` 个 LSTM 的输出在特征维度（`dim=2`）上进行拼接。
* 假设 `hidden_size = 20`，双向就是 40。有 2 层的话，拼接后的 `elmo_embedding` 维度就是 $40 \times 2 = 80$。这综合了浅层语法和深层语义特征。


3. **序列标注输出**：
* 将拼接好的特征送入线性分类器 `self.classifier`。
* 因为没有做降维或取最后一步，所以输出张量的形状是 `(batch_size, seq_length, 3)`，完美对应了**序列标注**的要求（即输入序列中每一个词/字都对应 3 个类别的预测得分）。



---

### 三、 实例化与模拟数据测试

```python
# 参数设置
input_size = 10  # 输入特征维度
hidden_size = 20  # LSTM隐藏层维度
num_layers = 2  # LSTM层数
elmo_model = ELMo(input_size, hidden_size, num_layers)

# 生成模拟输入数据
batch_size = 2
seq_length = 5  # 序列长度
x = torch.randn(batch_size, seq_length, input_size)

# 模型输出
output = elmo_model(x)
print("模型输出：")
print(output)

```

* **模拟输入**：Batch 大小为 2，序列长度为 5，每个时间步的特征维度为 10。
* **运行结果**：模型输出的形状为 `(2, 5, 3)`，代表 2 个样本，每个样本包含 5 个 Token，每个 Token 对应 3 个标签类别的 Logits（可直接配合 `CrossEntropyLoss` 进行训练）。
