这段代码使用 Python 的 `torch` 和 Hugging Face 的 `transformers` 库，演示了如何加载预训练的 BERT 模型（`bert-base-uncased`），对输入文本进行分词，并通过前向传播提取出 **`[CLS]` 向量** 以及**各个 Token 的嵌入特征向量**。

下面分步骤详细解释这段代码：

---

### 1. 初始化模型与分词器

```python
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

```

* **`BertTokenizer`**: 负责将输入的自然语言文本转换成 BERT 模型能理解的数字 ID（Token IDs）。`bert-base-uncased` 表示全小写、基础版的 BERT 模型。
* **`BertModel`**: 加载预训练的 BERT 核心网络结构（不包含特定的下游任务分类头）。

---

### 2. 文本分词与模型推理

```python
text = 'John Doe lives in New York and works at OpenAI.'
encoded_input = tokenizer(text, return_tensors='pt')

with torch.no_grad():
  outputs = model(**encoded_input)

```

* **分词编码**: `tokenizer(text, return_tensors='pt')` 将文本切分为 Token，并返回 PyTorch 格式的张量（包含 `input_ids`、`attention_mask` 等）。
* **`torch.no_grad()`**: 关闭梯度计算。因为这里只是进行特征提取（推理），不需要反向传播更新权重，这样可以节省内存并加速计算。
* **`outputs`**: 模型的前向传播输出。`outputs.last_hidden_state` 的形状通常是 `(batch_size, sequence_length, hidden_size)`（这里 batch_size 为 1），包含了每个 Token 的最终隐藏层状态（维度为 768）。

---

### 3. 提取特征向量

```python
cls_output = outputs.last_hidden_state[0, 0]  # [CLS] 向量 (768,)
token_outputs = outputs.last_hidden_state[0]  # 所有 Token 的向量 (seq_len, 768)

```

* **`[CLS]` 向量**: BERT 在句首会自动添加一个特殊的 `[CLS]` 符号（索引为 0）。它的向量通常被用作整句话的综合语义表示（常用于文本分类任务）。
* **Token 级别向量**: `token_outputs` 提取了句子中每一个 Token 的 768 维向量，可用于命名实体识别（NER）、词性标注等任务。

---

### 4. 遍历与分析每个 Token 的嵌入向量

```python
token_embeddings = []
input_ids_list = encoded_input['input_ids'][0]

for i, token_id_tensor in enumerate(input_ids_list):
  token_id = token_id_tensor.item()  # 转换为 Python int
  token = tokenizer.convert_ids_to_tokens(token_id)  # ID 转回字符串

  vec = token_outputs[i].detach().numpy()  # 转为 NumPy 数组
  token_embeddings.append((i, token, vec))  # 用列表保存元组

```

* 这段代码遍历了输入的所有 Token：
* 使用 `.item()` 将单元素的张量转为纯 Python 数值。
* 使用 `convert_ids_to_tokens` 把数字 ID 还原成可读的单词/子词（Subword）。
* **核心点**：使用列表存储元组 `(索引, 字符串, 向量)`，而不是用字典，**防止文本中出现重复单词时键名被覆盖**。



---

### 5. 向量比对验证

```python
print('\n--- 向量比对验证 ---')
print('CLS Vector (first 5 elements):', cls_output[:5].numpy())

# 从列表中匹配第一个 'john'
john_item = next(item for item in token_embeddings if item[1] == 'john')
print(
    f"Sample Token Vector - '{john_item[1]}' (Index {john_item[0]}):",
    john_item[2][:5],
)

```

* 这部分用于展示如何检索特定词（如 `'john'`）的向量，并打印出其前 5 维数据，方便与 `[CLS]` 向量或其他 Token 进行对比或后续的向量计算（如余弦相似度）。
