Gazetteers_NER.py代码展示了一个基于 **PyTorch** 和 **Hugging Face Transformers (`bert-base-uncased`)** 的命名实体识别（NER）框架原型。代码的核心亮点在于**将领域词典（Gazetteer）特征与深度学习模型（BERT）结合**：它不仅通过 BERT 模型输出预测分类，还独立编写了一个词典特征匹配函数，将词典信息编码为掩码（Mask），用于辅助或校准实体的识别。

整个脚本可以分为 6 个核心模块：

---

### 1. 词典定义与 Tokenizer 初始化

```python
# 1. 定义领域词典（转换为小写以便与 uncased tokenizer 匹配）
gazetteer = {
    "location": ["paris", "new york", "beijing", "london"],
    "organization": ["google", "microsoft", "openai", "tesla"],
    "person": ["john", "alice", "bob", "charlie"],
}

# 全局初始化 Tokenizer
tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")

```

* **作用**：定义了三类实体（`location`、`organization`、`person`）的词典。
* **细节**：由于使用的是 `bert-base-uncased`（不区分大小写的词表），词典中的词也统一转换为小写，保证后续匹配时大小写一致。

---

### 2. 数据集类（`TextDataset`）

```python
class TextDataset(Dataset):
    def __init__(self, texts, tokenizer):
        self.texts = texts
        self.tokenizer = tokenizer

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        text = self.texts[idx]
        encoding = self.tokenizer(
            text,
            max_length=64,
            padding="max_length",
            truncation=True,
            return_tensors="pt",
        )
        return {
            "input_ids": encoding["input_ids"].squeeze(0),
            "attention_mask": encoding["attention_mask"].squeeze(0),
            "text": text,
        }

```

* **作用**：标准的 PyTorch `Dataset` 实现，负责将原始文本通过 BERT Tokenizer 转换为模型可接受的张量（Tensor）。
* **细节**：`max_length=64`，并进行了 `padding`（填充）和 `truncation`（截断）。`.squeeze(0)` 用于去掉 DataLoader 组装前单样本多出来的 batch 维度。

---

### 3. NER 模型定义（`NERModel`）

```python
class NERModel(nn.Module):
    def __init__(self):
        super(NERModel, self).__init__()
        self.bert = BertModel.from_pretrained("bert-base-uncased")
        self.classifier = nn.Linear(self.bert.config.hidden_size, 4)  # 0: O, 1: location, 2: organization, 3: person

    def forward(self, input_ids, attention_mask):
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
        sequence_output = outputs.last_hidden_state
        logits = self.classifier(sequence_output)
        return logits

```

* **作用**：构建一个基础的基于 BERT 的 Token-level 分类模型。
* **架构**：
* **预训练骨干网络**：`BertModel` 负责提取每个 Token 的上下文语境特征（输出维度为 `[batch_size, seq_len, hidden_size]`）。
* **分类器**：线性层 `nn.Linear` 将隐向量映射到 4 个类别：`0: O（非实体）`、`1: location`、`2: organization`、`3: person`。



---

### 4. 词典特征匹配函数（`integrate_gazetteer`）

```python
def integrate_gazetteer(tokens, gazetteer):
    gazetteer_mask = torch.zeros(len(tokens), dtype=torch.long)
    # 展平词典列表进行搜索
    for idx, token in enumerate(tokens):
        clean_token = token.replace("##", "").lower()
        if clean_token in ["[cls]", "[sep]", "[pad]"]:
            continue
        
        for ent_type_idx, (entity_type, words) in enumerate(gazetteer.items(), start=1):
            for word in words:
                if clean_token in word.split():
                    gazetteer_mask[idx] = ent_type_idx
                    break
    return gazetteer_mask

```

* **核心意图**：将文本分词后的 `tokens` 与领域词典进行对齐，生成一个与 `tokens` 同长度的特征张量（`gazetteer_mask`）。
* **关键处理逻辑**：
* **清洗 Token**：通过 `token.replace("##", "")` 去除 BERT WordPiece 分词产生的子词前缀（例如 `##ing` 变成 `ing`）。
* **过滤特殊符号**：跳过 `[CLS]`、`[SEP]`、`[PAD]` 等控制符号。
* **匹配打标**：遍历词典，如果清洗后的 token 包含在词典词条中，则赋予相应的类别索引（`1` 代表 location，`2` 代表 organization，`3` 代表 person）。



---

### 5. 推理与验证流程

```python
texts = ["John works at Google in New York.", "Alice visited Paris last year."]
dataset = TextDataset(texts, tokenizer)
dataloader = DataLoader(dataset, batch_size=1, shuffle=False)

model = NERModel()
model.eval()

print("=== 开始处理与匹配 ===")
for batch in dataloader:
    input_ids = batch["input_ids"]
    attention_mask = batch["attention_mask"]
    text = batch["text"][0]

    # 将 Token ID 转换回可读的 Token 字符串
    tokens = tokenizer.convert_ids_to_tokens(input_ids[0])

    # 获取词典掩码
    gazetteer_mask = integrate_gazetteer(tokens, gazetteer)

    with torch.no_grad():
        logits = model(input_ids, attention_mask)

    predictions = torch.argmax(logits, dim=-1).squeeze(0).tolist()

```

* 这一段代码驱动了整个数据流：从 DataLoader 获取文本 -> Tokenizer 转 Token -> 调用词典匹配函数生成 `gazetteer_mask` -> 模型前向传播计算预测标签 `predictions`（由于模型未进行训练，此时预测结果是随机的）。

---

### 6. 结果整理与输出

```python
    result = []
    for token, pred, gaz_mask in zip(tokens, predictions, gazetteer_mask):
        if token in ["[PAD]", "[CLS]", "[SEP]"]:
            continue
        # 只要模型预测非 0 或词典匹配非 0，即输出显示
        if pred != 0 or gaz_mask.item() != 0:
            result.append((token, f"Pred:{pred}", f"GazetteerMatch:{gaz_mask.item()}"))

    print(f"\nText: {text}")
    print("Tokens & Gazetteers Match Result:", result)

```

* **展示逻辑**：将模型预测标签（`Pred`）和词典匹配标签（`GazetteerMatch`）进行对齐展示。
* **实际工程意义**：在实际项目中，这个 `gazetteer_mask` 可以作为额外的特征直接拼接（Concatenate）到 BERT 的输出层后面，再送入分类器，或者通过条件随机场（CRF）的特征函数注入，从而显著提升模型对罕见词或已知专有名词的识别率。
