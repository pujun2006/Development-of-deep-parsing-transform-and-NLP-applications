NER_fineTuning.py代码使用 Hugging Face 的生态（`transformers`、`datasets`、`evaluate`）实现了一个完整的 **BERT 模型命名实体识别（NER，Named Entity Recognition）** 微调任务。使用的模型是 `bert-base-uncased`，数据集是经典的 **CoNLL-2003**。

下面详细拆解和说明这段代码的核心逻辑：

---

### 1. 环境与镜像配置

```python
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"

```

* **作用**：将 Hugging Face 的下载端点重定向到国内镜像站 (`hf-mirror.com`)。这可以有效解决在国内直接访问 Hugging Face 官方服务器时常见的网络连接超时或无法下载模型、数据集的问题。

---

### 2. 加载 Fast 分词器

```python
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased", use_fast=True)

```

* **作用**：加载预训练的 BERT 分词器。
* **关键点**：`use_fast=True` 是**必须的**。因为后续的数据对齐操作中需要用到 Fast 分词器特有的 `.word_ids()` 方法，用来建立子词（Subword）与原始单词的映射关系。

---

### 3. 数据集加载与容错机制

```python
try:
  dataset = load_dataset("conll2003", trust_remote_code=False)
except Exception:
  # 备用加载逻辑（名字加载或直接加载 Parquet 文件）
  ...

```

* **作用**：加载 CoNLL-2003 数据集。
* **亮点**：代码中加入了多层 `try-except` 容错逻辑。由于 `conll2003` 脚本在某些 `datasets` 版本中可能存在远程脚本加载限制或网络源变动，代码准备了多套降级方案（包括直接拉取 Hugging Face 镜像上的 parquet 文件），确保代码在各种环境下都能稳健跑通。
* **标签获取**：`label_list = dataset["train"].features["ner_tags"].feature.names` 获取了所有实体标签的类别名称（如 `O`, `B-PER`, `I-PER`, `B-ORG` 等）。

---

### 4. 数据预处理与标签对齐（核心难点）

```python
def tokenize_and_align_labels(examples):
  tokenized_inputs = tokenizer(
      examples["tokens"], truncation=True, is_split_into_words=True
  )
  labels = []
  for i, label in enumerate(examples["ner_tags"]):
    word_ids = tokenized_inputs.word_ids(batch_index=i)
    label_ids = [
        -100 if word_id is None else label[word_id] for word_id in word_ids
    ]
    labels.append(label_ids)
  tokenized_inputs["labels"] = labels
  return tokenized_inputs


tokenized_datasets = dataset.map(tokenize_and_align_labels, batched=True)

```

* **背景**：NER 是**字/词级别**的分类任务，而 BERT 的分词器会将一个单词切分为多个 **Subword（子词）**（例如将 `"unflattering"` 切分为 `["un", "flat", "ter", "ing"]`）。此外，分词后还会自动加上特殊的填充符 `[CLS]` 和 `[SEP]`。
* **对齐逻辑**：
1. `is_split_into_words=True` 告诉分词器输入的 `examples["tokens"]` 已经是分好词的列表。
2. `tokenized_inputs.word_ids(batch_index=i)` 返回每个子词对应原句中第几个单词的索引。
3. **`-100` 的妙用**：对于特殊符号（如 `[CLS]`、`[SEP]`）或者被切分的非首个子词，其 `word_id` 为 `None`，将其标签设为 `-100`。在 PyTorch 的 `CrossEntropyLoss` 损失函数中，**默认会忽略标签为 `-100` 的位置**，不计算损失，从而保证模型只对每个真实单词的第一个子词进行梯度更新和损失计算。



---

### 5. 模型初始化与训练参数配置

```python
model = BertForTokenClassification.from_pretrained(
    "bert-base-uncased", num_labels=len(label_list)
)

training_args = TrainingArguments(
    output_dir="./results",
    eval_strategy="epoch",  # 每个 Epoch 结束后评估一次
    save_strategy="epoch",  # 每个 Epoch 结束后保存一次检查点
    learning_rate=2e-5,  # 微调常用的学习率
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    num_train_epochs=3,
    weight_decay=0.01,
    logging_steps=50,
    report_to="none",  # 禁用 wandb 等外部日志上报，避免环境报错

```

* **模型**：`BertForTokenClassification` 在 BERT 基础模型之上外接了一个线性分类层（Linear Layer），输出维度为 `num_labels`，用来对每个 Token 进行分类。
* **超参数**：设定了标准的微调超参数（学习率 `2e-5`，训练 `3` 个 Epoch，批大小 `16` 等）。`report_to="none"` 确保程序在本地纯净运行，不强制要求配置 Weights & Biases 等账号。

### 6. 评估指标配置 (`seqeval`)

```python
metric = evaluate.load("seqeval")


def compute_metrics(p):
  predictions, labels = p
  predictions = np.argmax(predictions, axis=2)

  # 过滤掉标签为 -100 的位置
  true_labels = [
      [label_list[l] for l in label if l != -100] for label in labels
  ]
  true_predictions = [
      [label_list[p] for (p, l) in zip(prediction, label) if l != -100]
      for prediction, label in zip(predictions, labels)
  ]

  results = metric.compute(
      predictions=true_predictions, references=true_labels
  )
  return {
      "precision": results["overall_precision"],
      "recall": results["overall_recall"],
      "f1": results["overall_f1"],
      "accuracy": results["overall_accuracy"],
  }

```

* **指标工具**：NER 任务不能单纯看 Token 级别的准确率，通常采用 **Seqeval** 评估框架来计算**实体级别**的 Precision（精确率）、Recall（召回率）和 F1 值。
* **`compute_metrics` 函数**：
1. 将模型输出的 Logits 通过 `np.argmax` 转化为预测的类别 ID。
2. 剔除对齐时设为 `-100` 的特殊占位符。
3. 将数字 ID 映射回文本标签（如 `B-PER`），然后交由 `seqeval` 计算出整体的实体识别表现。



---

### 7. 数据整理器与训练器初始化

```python
data_collator = DataCollatorForTokenClassification(tokenizer=tokenizer)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_datasets["train"],
    eval_dataset=tokenized_datasets["validation"],
    data_collator=data_collator,
    compute_metrics=compute_metrics,
)

```

* **`DataCollatorForTokenClassification`**：专门针对 Token 分类任务的数据整理器。它在每个 Batch 动态将输入文本填充（Padding）到相同的长度，同时会将对应的 `labels` 自动填充 `-100`（而不是 0），确保填充部分不参与损失计算。
* **`Trainer`**：Hugging Face 封装的高阶训练器，集成了训练循环、梯度累积、混合精度、分布式训练和定期评估等全套工业级功能。

---

### 8. 启动训练与评估

```python
trainer.train()
eval_results = trainer.evaluate()
print("\nEvaluation results:", eval_results)

```

* 执行 `trainer.train()` 开始训练，并在验证集上自动按 Epoch 触发评估。
* 训练结束后，调用 `trainer.evaluate()` 在测试集或验证集上跑出最终指标并打印输出。
