**序列标注任务（Sequence Labeling Task）**是自然语言处理（NLP）中的一项核心基础任务。与文本分类（整个文本输出一个标签）不同，序列标注要求**为输入序列中的每一个 Token（词、字或子词）预测一个对应的标签**。

结合前述代码（使用 LSTM 做命名实体识别 NER），下面梳理序列标注任务的定义、典型应用场景以及主流的常用方法。

---

## 一、 什么是序列标注任务？

在序列标注中，给定输入序列 $X = (x_1, x_2, \dots, x_n)$，模型需要输出一个等长的标签序列 $Y = (y_1, y_2, \dots, y_n)$。

### 典型应用场景

1. **命名实体识别 (NER, Named Entity Recognition)**：
* 识别文本中的人名、地名、组织机构名等。
* **常用标注体系**（如你代码中的 BIO 体系）：`B-ORG`（组织名开始）、`I-ORG`（组织名内部）、`O`（非实体）。


2. **词性标注 (POS Tagging, Part-of-Speech)**：
* 为每个词标注其词性（名词、动词、形容词等）。


3. **中文分词 (CWS, Chinese Word Segmentation)**：
* 将连续的字切分为词，常转化为字级别的序列标注（`B` 表示词首，`M` 表示词中，`E` 表示词尾，`S` 表示单字词）。


4. **槽位填充 (Slot Filling)**：
* 智能对话系统中，从用户语句中提取关键槽位（如查机票时提取出发地、目的地、时间）。

## 二、 序列标注的常用方法演进

从传统机器学习到现代深度语言模型，序列标注的方法主要经历了以下几个发展阶段：

### 1. 传统统计机器学习方法

在深度学习兴起之前，序列标注主要依赖统计学模型，核心思想是利用特征工程结合上下文概率。

* **隐马尔可夫模型 (HMM)**：生成式模型，通过假设当前状态只依赖于前一个状态，计算联合概率。缺点是难以引入丰富的手工特征。
* **最大熵隐马尔可夫模型 (MEMM)**：判别式模型，克服了 HMM 不能使用长距离特征的缺点，但存在“标记偏置”问题。
* **条件随机场 (CRF, Conditional Random Fields)**：
* **里程碑式方法**。它是一个全局的判别式模型，能够考虑整个句子维度的标签转移概率（例如：在 BIO 体系中，`I-PER` 绝不能直接跟在 `B-ORG` 后面）。在深度学习普及之前，CRF 是序列标注的绝对统治者。



### 2. 深度学习方法（特征提取器 + 线性层）

深度学习通过嵌入层和神经网络自动提取特征，减少了繁琐的手工特征工程。

* **RNN / LSTM / GRU + Linear**（即你代码中的架构）：
* **优势**：利用循环神经网络捕捉长距离的上下文依赖。
* **劣势**：传统的 `Softmax` 是在**每个时间步独立分类**的，无法直接对相邻标签之间的约束关系（如 BIO 规则）进行建模。例如，模型可能会预测出 `I-ORG` 开头的非法序列。



### 3. 经典黄金组合：BiLSTM-CRF

为了结合深度学习强大的特征提取能力与 CRF 对标签转移的全局约束能力，学术界和工业界长期广泛使用 **BiLSTM-CRF** 架构：

* **BiLSTM（双向长短期记忆网络）**：正向和反向扫描文本，自动学习每个 Token 的上下文特征表示。
* **CRF 层**：在 BiLSTM 输出的特征之上增加一个转移矩阵层，用全局归一化概率来规范标签序列的合法性，有效避免了非法标签组合（如 `I-` 标签直接出现在 `O` 标签之后而没有 `B-` 的情况）。

### 4. 预训练语言模型时代（Transformer-based）

随着 BERT、RoBERTa、GPT 等大模型的崛起，序列标注迎来了质的飞跃：

* **BERT / RoBERTa + Linear / CRF**：
* 预训练语言模型拥有极强的语义表征能力。通常将 BERT 作为编码器（Feature Extractor），在其输出的每个 Token 向量上接一个线性分类层（或者再接一个 CRF 层）。
* 相比传统的 BiLSTM，BERT 能够通过 Self-Attention 机制捕获更深层次、更长距离的全局语义，使得 NER 等任务的准确率（F1-score）大幅提升。


* **大模型提示学习 / 指令微调 (Prompt / Instruction Tuning)**：
* 在大模型时代，也可以通过设计 Prompt（如：“请提取以下文本中的人名和组织机构：...”）直接让生成式大模型输出结果，特别适合少样本（Few-shot）或零样本（Zero-shot）场景。

## 三、 核心技术细节与评估指标

### 1. 解码方式（Decoding）

* **贪婪解码 (Greedy Decoding / Argmax)**：如你代码中所用，每个时间步直接取概率最大的一项（`torch.argmax`）。速度快，但忽略了标签间的转移约束。
* **维特比解码 (Viterbi Decoding)**：常用于配合 CRF，通过动态规划算法寻找全局得分最高的整条标签路径，保证输出序列的合法性和最优性。

### 2. 评估指标 (Evaluation Metrics)

由于序列标注（如 NER）中绝大多数 Token 都是非实体的 `O`，如果仅看 **Accuracy（准确率）**，模型什么都不做全预测为 `O` 也能有 95% 以上的高准确率。因此，评估通常采用 **Span 级别的精密指标**：

* **Precision (精确率)**：模型预测出的实体中，有多少是真正的实体。
* **Recall (召回率)**：真实的实体中，有多少被模型正确预测出来了。
* **F1-Score (F1 值)**：Precision 和 Recall 的调和平均数，是衡量序列标注模型性能的核心标准。
