BIOCoding.py代码完整地展示了使用 **PyTorch** 构建、训练并测试一个**序列标注模型**（类似于命名实体识别 NER 任务）的全过程。

整体流程可以分为 5 个核心部分：**数据准备**、**模型定义**、**损失函数设计**、**模型训练** 以及 **模型测试**。下面逐段详细拆解：

---

### 一、 数据准备（Dataset 与 DataLoader）

```python
class SequenceDataset(Dataset):
    def __init__(self, sequences, labels, label_map):
        self.sequences = sequences
        self.labels = labels
        self.label_map = label_map

    def __len__(self):
        return len(self.sequences)

    def __getitem__(self, idx):
        seq = self.sequences[idx]
        label = [self.label_map[l] for l in self.labels[idx]]
        return torch.tensor(seq, dtype=torch.long), torch.tensor(label, dtype=torch.long)

```

* **`SequenceDataset`**：继承自 PyTorch 的 `Dataset` 类，用于管理样本数据。
* `__len__` 返回数据集的大小（样本数量）。
* `__getitem__` 根据索引获取单个样本，并将文本标签通过 `label_map` 转换为对应的整型 ID。


* **样本数据**：
* `sequences`：两个长度为 5 的整数序列。
* `labels`：对应的 BIO 格式实体标签（如 `B-ORG` 表示组织机构开始，`O` 表示非实体）。
* `label_map`：标签到数字的映射字典（共 7 个类别，`output_dim = 7`）。


* **`DataLoader`**：将数据集打包成批次（`batch_size=2`），并在每个 Epoch 开始时打乱数据（`shuffle=True`），方便进行批处理训练。

### 二、 模型定义（SimpleSequenceModel）

```python
class SimpleSequenceModel(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim, output_dim):
        super(SimpleSequenceModel, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x = self.embedding(x)
        x, _ = self.lstm(x)
        x = self.fc(x)
        return x

```

这是一个标准的 **RNN / LSTM 序列标注网络**：

1. **`nn.Embedding`**：将输入的离散词索引（维度 `vocab_size=11`）转化为稠密的连续向量（维度 `embedding_dim=8`）。
2. **`nn.LSTM`**：循环神经网络层，负责捕捉序列中的上下文信息。`batch_first=True` 表示输入的张量形状为 `(batch_size, seq_len, embedding_dim)`。输出的隐藏状态维度为 `hidden_dim=16`。
3. **`nn.Linear`**：全连接层，将 LSTM 的输出特征从 `hidden_dim` 映射到类别数 `output_dim`（即每个时间步都预测一个标签概率分布）。

### 三、 标签平滑损失函数（LabelSmoothingLoss）

```python
class LabelSmoothingLoss(nn.Module):
    def __init__(self, smoothing=0.1):
        super(LabelSmoothingLoss, self).__init__()
        self.smoothing = smoothing
        self.confidence = 1.0 - smoothing  # 注：原代码此处有笔误，补充了减号

    def forward(self, pred, target):
        pred = pred.log_softmax(dim=-1)
        true_dist = torch.zeros_like(pred)
        true_dist.fill_(self.smoothing / (pred.size(-1) - 1))
        true_dist.scatter_(1, target.data.unsqueeze(1), self.confidence)
        return torch.mean(torch.sum(-true_dist * pred, dim=-1))

```

* **标签平滑（Label Smoothing）**：一种正则化技术，防止模型在训练时对正确标签过度自信（Probability 变为 1.0），从而提高模型的泛化能力。
* 它将原本为 1 的正确标签概率分出一小部分（`smoothing=0.1`）平均分配给其他错误类别。
* *(注：原代码第 48 行 `self.confidence = 1.0 smoothing` 漏掉了 `-` 符号，实际运行前应修改为 `self.confidence = 1.0 - self.smoothing`)*。

### 四、 训练模型（Training Loop）

```python
num_epochs = 3
for epoch in range(num_epochs):
    total_loss = 0
    for inputs, targets in dataloader:
        optimizer.zero_grad()
        outputs = model(inputs)
        outputs = outputs.view(-1, output_dim)
        targets = targets.view(-1)
        loss = criterion(outputs, targets)
        loss.backward()
        optimizer.step()
        total_loss += loss.item()
    print(f"Epoch {epoch + 1}, Loss: {total_loss:.4f}")

```

训练循环的核心步骤：

1. **`optimizer.zero_grad()`**：清空上一轮迭代的梯度。
2. **前向传播**：`outputs = model(inputs)` 获取模型预测值。
3. **张量展平（View）**：因为是序列标注，原本的输出形状是 `(batch_size, seq_len, output_dim)`，目标形状是 `(batch_size, seq_len)`。通过 `.view(-1, output_dim)` 和 `.view(-1)` 将其展平为二维和一维，以便直接送入交叉熵/标签平滑损失函数计算。
4. **反向传播与优化**：
* `loss.backward()`：计算梯度。
* `optimizer.step()`：使用 Adam 优化器更新模型权重。

### 五、 测试与推理（Inference）

```python
with torch.no_grad():
    for inputs, targets in dataloader:
        outputs = model(inputs)
        predicted_labels = torch.argmax(outputs, dim=-1)
        print("Predictions:", predicted_labels)
        print("Targets:", targets)

```
* **`torch.no_grad()`**：在测试阶段关闭梯度计算，节省内存并加快计算速度。
* **`torch.argmax(outputs, dim=-1)`**：获取最后一个维度（类别维度）上概率最大的索引，即模型预测出的类别 ID。
* 最后将模型的预测结果与真实标签（Targets）打印出来进行直观对比。
