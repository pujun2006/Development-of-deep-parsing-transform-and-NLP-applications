在命名实体识别（**NER**, Named Entity Recognition）任务中，`[CLS]` 标记（Sentence-level）和 **Token 向量**（Token-level）扮演着截然不同的角色。NER 本质上是一个**序列标注任务**（Sequence Labeling），这意味着我们需要对句子中的**每一个词**都做出分类判断（例如判断它是人名、地名、机构名还是普通词）。

下面从两者的定义、在 NER 中的具体作用以及协作方式进行详细说明。

---

### 一、 Token 向量：NER 的绝对核心

在标准的 BERT-NER 模型中，Token 向量（即 `outputs.last_hidden_state` 中对应各个词的向量）是进行实体识别的主力军。

#### 1. 为什么用 Token 向量？

* **序列标注的需求**：NER 的目标是给输入文本的每一个 Token 打上标签（通常采用 BIO 标记法，如 `B-PER` 表示人名开始，`I-PER` 表示人名延续，`O` 表示非实体）。
* **上下文感知（Contextualized Embeddings）**：BERT 的每一层 Token 向量都融合了双向上下文信息。例如，“Apple” 在“苹果手机很好用”和“苹果公司发布了新品”中，其 Token 向量会因为上下文的不同而表现出不同的语义特征，这正是 BERT 强大威力的来源。

#### 2. Token 向量在 NER 中的处理流程

1. **特征提取**：取模型的最后一层隐藏状态，形状为 `(batch_size, sequence_length, hidden_size)`（如 `768` 维）。
2. **线性分类层（Linear Layer）**：将每个 Token 的 768 维向量通过一个全连接线性层，映射到标签空间（类别数 $C$，例如标签总数为 7 种：B-PER, I-PER, B-LOC, I-LOC, B-ORG, I-ORG, O），得到每个标签的得分（Logits）。
3. **解码层（Softmax 或 CRF）**：
* 简单做法：直接用 Softmax 选出得分最高的标签。
* 工业界标准做法：在后面接一个 **CRF（条件随机场）层**，用来约束标签之间的转移合理性（例如防止 `I-PER` 紧跟在 `O` 后面出现的不合逻辑情况）。



#### 3. 需要注意的子词（Subword）对齐问题

由于 BERT 使用了 WordPiece 分词器（如将 `OpenAI` 拆分为 `open`, `##ai`），一个完整的词可能会被拆成多个 Token。

* 在做 NER 预测时，通常**只取每个原词的第一个子词（Subword）的向量**来进行分类，或者通过特定对齐策略将子词的标签映射回原词。

---

### 二、 `[CLS]` 标记：全局视角的辅助角色

`[CLS]`（Classification Token）是 BERT 在输入序列最前方自动添加的特殊标记（索引为 0），其初始设计主要用于**整句分类任务**（如情感分析、文本分类）。

#### 1. `[CLS]` 在常规 NER 中的角色

在**纯粹的 Token 级别 NER** 任务中，`[CLS]` 向量**通常不直接参与**每个 Token 的标签预测。因为 `[CLS]` 聚合的是**全句的全局语义**，而 NER 关注的是局部的、词级别的实体边界与类别，全局信息无法精确指导每个词是 `B-PER` 还是 `O`。因此，在标准的 BERT-NER 代码中，切片时往往会直接丢弃 `[CLS]` 和 `[SEP]`，只取中间的实体 Token 向量。

#### 2. `[CLS]` 在特定复杂 NER 场景中的妙用

虽然在标准扁平 NER 中用处不大，但在以下扩展场景中，`[CLS]` 向量可以发挥重要作用：

* **句子级实体存在性辅助判断（Multi-task Learning）**：有些复杂系统会同时做“整句中是否包含某类实体”的分类任务（利用 `[CLS]`）和“具体实体位置标注”的任务（利用 Token 向量），通过多任务联合训练增强模型对全局的理解。
* **文档级（Document-level）或长文本 NER**：在跨句子、篇章级的 NER 中，`[CLS]`（或类似的高层全局向量）可以作为篇章级上下文背景，辅助模型判断跨句子的实体共指或长距离依赖关系。

---

### 三、 核心维度对比表

| 维度 | `[CLS]` 标记向量 | Token 向量（如 `John`, `OpenAI`） |
| --- | --- | --- |
| **语义范围** | **全局语义**（整句话的综合摘要） | **局部与上下文语义**（特定词或子词的特征） |
| **在标准 NER 中的作用** | **无直接作用**（通常被忽略或裁剪掉） | **核心作用**（输入到线性层/CRF进行序列标注） |
| **输出形状** (以 `bert-base` 为例) | `(768,)` | `(sequence_length, 768)` 中的单个向量 |
| **典型应用任务** | 文本分类、情感分析、文本匹配 | 命名实体识别（NER）、词性标注（POS）、文本抽取 |

### 总结

在 BERT-NER 的架构中，**Token 向量**是完成实体识别的“主攻手”（提供每个词在上下文中的精准特征），而 **`[CLS]` 向量**则是“局外人”或“全局参谋”（负责整句层面的信息），两者的分工由 NER 任务本身的**序列标注**属性决定。
