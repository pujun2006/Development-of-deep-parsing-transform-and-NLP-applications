Kmeans_text_clustering.py代码实现了一个完整的**基于 TF-IDF 和 K-Means 的中文文本聚类任务**。它涵盖了从中文分词、文本向量化、K-Means 模型训练、结果展示到聚类效果评估（轮廓系数）的完整流程。

下面对代码的每一个部分进行逐行、逐模块的详细拆解和说明：

---

### 一、 导入依赖库

```python
import numpy as np
import pandas as pd
import jieba
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

```

* **`numpy` & `pandas**`：用于处理矩阵数据以及将最终结果整理成规范的表格（DataFrame）输出。
* **`jieba`**：国内最流行的中文分词工具，用于将连续的中文句子切分成独立的词语。
* **`sklearn` (Scikit-learn)**：机器学习库。
* `TfidfVectorizer`：用于将分词后的文本转化为 TF-IDF 特征矩阵。
* `KMeans`：执行 K-Means 聚类算法。
* `silhouette_score`：计算**轮廓系数**，用于评估聚类效果的好坏。



---

### 二、 准备示例文本数据

```python
documents = [
    "机器学习是一种人工智能技术。",
    "深度学习是机器学习的一个分支。",
    "NLP处理自然语言数据。",
    "监督学习使用标记数据进行训练。",
    "聚类分析是无监督学习的一种。",
    "Python是一种编程语言。",
    "数据科学包括数据分析和统计学。",
    "算法设计是计算机科学的核心。",
    "神经网络是深度学习的基础。",
    "数学在机器学习中很重要。"
]

```

* 定义了一个包含 10 条简短中文句子的列表。这些句子大致围绕人工智能、编程、算法和数据科学等主题。

---

### 三、 代码核心步骤详解

#### 1. 中文分词（Pre-processing & Tokenization）

```python
segmented_documents = [" ".join(jieba.cut(doc)) for doc in documents]

```

* **核心目的**：英文是以空格分词的自然语言，而中文词语之间没有天然的分隔符。计算机无法直接理解整句话，必须先切分成词。
* **实现逻辑**：
* `jieba.cut(doc)` 对每句话进行中文分词，返回一个可迭代的词语生成器。
* `" ".join(...)` 将切分好的词语用**空格**连接起来。例如，`"深度学习是机器学习的一个分支。"` 会被转化为 `"深度 学习 是 机器学习 的 一个 分支 。"`。
* 这样做的原因是后续的 `TfidfVectorizer` 默认依靠“空格”来识别不同的词汇。



#### 2. TF-IDF 文本向量化（Feature Extraction）

```python
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(segmented_documents)

```

* **核心目的**：将文本转化为数学矩阵，以便算法进行计算。
* **实现逻辑**：
* `TfidfVectorizer` 会自动统计词频（TF）并计算逆文档频率（IDF），给每篇文档生成一个高维稀疏向量。
* `.fit_transform()` 会遍历所有文档，建立词汇表（Vocabulary），并将文本转换为 TF-IDF 权重矩阵 $X$。



#### 3. K-Means 聚类训练（Clustering Model）

```python
num_clusters = 3
kmeans = KMeans(n_clusters=num_clusters, random_state=42, n_init=10)
kmeans.fit(X)

labels = kmeans.labels_
centers = kmeans.cluster_centers_

```

* **核心参数**：
* `n_clusters=3`：指定要将文本划分为 3 个簇（类别）。
* `random_state=42`：设置随机种子，确保每次运行代码时随机初始化中心点的结果一致，具备可复现性。
* `n_init=10`：用不同的随机初始化中心点运行 10 次，选择效果最好的一次作为最终结果，避免陷入局部最优。


* **核心输出**：
* `kmeans.labels_`：每个文本对应的聚类标签（例如：`[0, 0, 1, 0, 1, 2, 2, 2, 0, 0]`），标明每句话属于第几个簇。
* `kmeans.cluster_centers_`：每个簇的聚类中心向量，维度为 `(3, 词表大小)`。



#### 4. 结果展示与表格化

```python
df = pd.DataFrame({'文档': documents, '聚类标签': labels})
print("聚类结果表格:")
print(df.to_string(index=False))

```

* 将原始文本与对应的聚类标签合并成一个 `pandas.DataFrame` 表格，方便直观查看哪几句话被归为了同一类。

#### 5. 聚类效果评估（轮廓系数）

```python
silhouette_avg = silhouette_score(X, labels)
print(f"\n聚类的轮廓系数: {silhouette_avg:.4f}")

```

* **轮廓系数（Silhouette Score）**：衡量聚类质量的重要无监督指标。
* 取值范围为 `[-1, 1]`。
* 分值越接近 1，说明簇内样本靠得越紧密，簇与簇之间分得越开，聚类效果越好。
* 如果接近 0 或为负数，说明类别重叠严重或聚类效果较差。



#### 6. 提取每个簇的特征关键词（Theme Interpretation）

```python
terms = vectorizer.get_feature_names_out()
for i in range(num_clusters):
    print(f"\n聚类 {i} 中心关键词:")
    cluster_terms = centers[i].argsort()[-5:][::-1]
    for term in cluster_terms:
        print(f" - {terms[term]}")

```

* **核心目的**：聚类算法只给出了数字标签（0, 1, 2），我们需要知道这些标签代表什么主题。通过分析簇中心向量，可以找出对该簇贡献最大的关键词。
* **实现逻辑**：
* `vectorizer.get_feature_names_out()` 获取所有不重复的词汇表。
* `centers[i].argsort()` 对第 $i$ 个聚类中心的各项权重进行从小到大的排序，返回对应的索引。
* `[-5:][::-1]` 取出权重最高的 **前 5 个词**（按权重从大到小排列）。
* 打印这些关键词，我们就能根据它们直观地看出每个聚类分别代表什么主题（例如：一个簇可能高频出现“机器学习、深度学习”，另一个簇出现“编程、语言”等）。
