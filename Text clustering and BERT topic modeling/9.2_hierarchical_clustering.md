hierarchical_clustering.py代码实现了一个完整的**基于层次聚类（Hierarchical Clustering）和 TF-IDF 的英文文本聚类任务**，并利用 `scipy` 和 `matplotlib` 绘制了直观的**树状图（Dendrogram）**。

与前面基于 K-Means 的硬切分聚类不同，层次聚类能够展现出文本之间多层次的嵌套相似关系。下面对代码的每一个部分进行逐行、逐模块的详细拆解和分析：

---

### 一、 核心依赖库导入与后端设置

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from scipy.cluster.hierarchy import linkage, dendrogram

# 修复核心报错：在导入 pyplot 前显式设置后端
import matplotlib
matplotlib.use('TkAgg')  # 如果在无界面服务器运行，可更改为 'Agg' 并在末尾保存图片
import matplotlib.pyplot as plt

```

* **`scipy.cluster.hierarchy`**：SciPy 库中的层次聚类模块。
* `linkage`：用于计算分层聚类（或凝聚聚类）的链接矩阵。
* `dendrogram`：用于将链接矩阵绘制成树状图。


* **Matplotlib 后端设置（关键细节）**：
* `matplotlib.use('TkAgg')` 在导入 `matplotlib.pyplot` 之前显式指定了图形界面后端（TkAgg），这能有效避免在某些操作系统（如 macOS 或某些 Linux 环境）中弹窗绘图时报 GUI 线程冲突或无响应的经典错误。
* 若在无图形界面的服务器（如云服务器、Docker）上运行，应将其改为 `'Agg'`（非交互式后端），并将最后的 `plt.show()` 替换为 `plt.savefig('dendrogram.png')` 将图片保存到本地。

### 二、 准备示例文本数据

```python
texts = [
    "Machine learning is fascinating.",
    "Artificial intelligence and machine learning are closely related.",
    "Clustering algorithms help in grouping data.",
    "Natural language processing and AI have great potential.",
    "Hierarchical clustering builds a tree structure of clusters.",
    "Text clustering is useful for organizing information.",
    "AI and machine learning are advancing rapidly.",
    "Data analysis is essential for insights."
]

```

* 定义了一个包含 8 条英文句子的列表。这些句子主要围绕机器学习、人工智能、文本聚类和数据分析等计算机科学与 AI 领域。

### 三、 核心步骤详解

#### 1. 文本向量化

```python
vectorizer = TfidfVectorizer(stop_words='english')
tfidf_matrix = vectorizer.fit_transform(texts).toarray()

```

* **`stop_words='english'`**：自动过滤掉英文中的常见停用词（如 "is", "and", "are", "in" 等），减少无意义词汇对相似度计算的干扰。
* **`.toarray()`**：将 Scikit-learn 输出的稀疏矩阵（Sparse Matrix）转换为标准的 NumPy 二维稠密数组，因为 SciPy 的 `linkage` 函数接收标准二维数组时兼容性更好。

#### 2. 计算层次聚类链接矩阵（Linkage Matrix）

```python
linkage_matrix = linkage(tfidf_matrix, method='average', metric='cosine')

```

* 这是整个代码的**核心算法步骤**（凝聚型层次聚类，Agglomerative Hierarchical Clustering）：
* **`metric='cosine'`**：使用**余弦距离**。在文本挖掘中，文本长度不一，余弦距离通过计算向量夹角来衡量方向一致性，比欧氏距离更能准确反映文本语义的相似度。
* **`method='average'`**：使用类平均法（UPGMA）计算簇与簇之间的距离（即两个簇中所有文本对之间余弦距离的平均值）。它兼顾了最短距离法容易产生“链状效应”和最长距离法受异常值影响大的缺点，表现较为稳健。
* **`linkage_matrix`**：输出一个形状为 `(n-1, 4)` 的矩阵，记录了每一步合并的是哪两个簇、簇间距离以及合并后新簇包含的样本数。



#### 3. 绘制并配置层次聚类树状图

```python
plt.figure(figsize=(12, 7))
dendrogram(
    linkage_matrix,
    labels=texts,
    orientation='left',  # 改为左侧排列，文本显示更清晰
    leaf_font_size=10
)
plt.title('Hierarchical Clustering Dendrogram (Cosine Distance)')
plt.xlabel('Distance')
plt.ylabel('Texts')
plt.tight_layout()
plt.show()

```

* **`labels=texts`**：将树状图叶子节点的标签替换为原始的英文句子，使图表具备可读性。
* **`orientation='left'`**：将树状图设置为向左生长（根在右，叶在左），这样可以让较长的文本标签水平横向排列，极大程度避免了文字重叠和拥挤，非常适合文本数据的可视化。
* **`leaf_font_size=10`**：设置叶子节点文本的字体大小。
* **`plt.tight_layout()`**：自动调整子图参数，确保标签不会被画布边缘截断。

### 五、 层次聚类相比 K-Means 的优势与这段代码的亮点

1. **无需预先指定簇数量 ($K$)**：
* K-Means 必须硬性规定 $K$ 等于几；而层次聚类通过观察树状图（Dendrogram）的“分支高度（Distance）”，可以在任意高度“横向切一刀”，从而自由决定最终切分成几个簇。


2. **丰富的层次结构信息**：
* 从树状图中，不仅能看出哪些文本属于同一类，还能看出**哪些文本“最先合并”（相似度最高）**，以及不同大类之间是在哪个距离层级合并的（反映了宏观主题关系）。


3. **针对文本的度量适配**：
* 代码显式指定了 `metric='cosine'`，这是处理高维向量文本时的经典佳实践，能有效避免文本长度差异带来的计算偏差。
