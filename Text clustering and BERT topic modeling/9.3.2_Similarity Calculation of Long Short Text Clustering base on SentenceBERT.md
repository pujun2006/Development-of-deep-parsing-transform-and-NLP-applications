Similarity Calculation of Long Short Text Clustering base on SentenceBERT.py代码演示了如何使用 **Sentence-BERT (`sentence-transformers`)** 处理**不同长度的文本（短文本 vs 长文本）**，并通过 `scikit-learn` 计算**自相似度矩阵**以及**跨文本集合的交叉相似度矩阵**。

这是在实际业务场景（如**短文本匹配长文档**、**智能客服问答检索**、**搜索推荐**）中非常经典且常用的代码模式。下面逐段详细拆解和分析：

---

### 一、 核心依赖库导入

```python
from sentence_transformers import SentenceTransformer
from sklearn.metrics.pairwise import cosine_similarity

```

* 导入 SBERT 模型类和计算余弦相似度的工具函数。

---

### 二、 加载模型与定义两组不同长度的文本

```python
# 加载Sentence-BERT模型
model = SentenceTransformer('paraphrase-MiniLM-L6-v2')

# 定义短文本和长文本
short_texts = [
    "Climate change impacts weather patterns",       # 气候变化影响天气模式
    "Global warming affects sea levels",              # 全球变暖影响海平面
    "Artificial intelligence is evolving",            # 人工智能正在演进
    "Machine learning is a subset of AI"              # 机器学习是AI的一个子集
]

long_texts = [
    "Climate change is causing significant alterations in global weather patterns, leading to more frequent extreme events.", # 气候变化导致全球天气模式显著改变...
    "The rise in global temperatures has led to the melting of polar ice caps, subsequently causing sea levels to rise and impacting coastal regions.", # 全球气温上升导致极地冰盖融化...
    "Artificial intelligence, particularly in the field of natural language processing, is transforming how humans interact with technology.", # 人工智能，特别是自然语言处理领域...
    "Machine learning, a subset of artificial intelligence, involves algorithms that improve through experience, driving advancements across industries." # 机器学习...
]

```

* **文本结构分析**：
* `short_texts` 包含了 4 条简短的陈述句（前两句关于环境/气候，后两句关于 AI/机器学习）。
* `long_texts` 包含了 4 条对应的长段落（它们在语义上分别与 `short_texts` 中的 4 条语句**一一对应**，但扩充了更多的细节和解释性词汇）。



---

### 三、 生成嵌入向量（Embeddings）

```python
# 生成嵌入
short_embeddings = model.encode(short_texts)
long_embeddings = model.encode(long_texts)

```

* 分别调用 `model.encode()` 将短文本列表和长文本列表转化为稠密向量：
* `short_embeddings` 的形状为 `(4, 384)`（4 个短文本，每个 384 维）。
* `long_embeddings` 的形状为 `(4, 384)`（4 个长文本，每个 384 维）。


* **SBERT 的核心能力体现**：尽管短文本和长文本的字数、词汇量差异巨大，SBERT 都能将它们映射到**同一个语义向量空间**中，这为后续直接比较它们之间的相似度奠定了基础。

---

### 四、 计算并打印短文本自身的相似度矩阵

```python
# 短文本相似度矩阵
short_similarity_matrix = cosine_similarity(short_embeddings)
print("Short Texts Cosine Similarity Matrix:\n", short_similarity_matrix)

```

* **作用**：计算 `short_embeddings` 内部两两之间的余弦相似度。
* **输出形状**：`4 × 4` 的方阵。
* **预期效果**：前两句（气候类）之间相似度较高，后两句（AI类）之间相似度较高，而跨类别的相似度较低。

---

### 五、 计算并打印长文本自身的相似度矩阵

```python
# 长文本相似度矩阵
long_similarity_matrix = cosine_similarity(long_embeddings)
print("Long Texts Cosine Similarity Matrix:\n", long_similarity_matrix)

```

* **作用**：计算 `long_embeddings` 内部两两之间的余弦相似度。
* **输出形状**：`4 × 4` 的方阵。
* **预期效果**：由于长文本包含了更丰富的语义细节，同类长文本之间的区分度可能会更加明显或稳健。

---

### 六、 计算短文本与长文本之间的“交叉相似度矩阵”（核心亮点）

```python
# 短文本和长文本之间的相似度
cross_similarity_matrix = cosine_similarity(short_embeddings, long_embeddings)
print("Cross Similarity Matrix between Short and Long Texts:\n", cross_similarity_matrix)

```

* **函数用法亮点**：`cosine_similarity(X, Y)` 支持传入两个不同的矩阵！
* `X` 的形状是 `(4, 384)`（短文本）。
* `Y` 的形状是 `(4, 384)`（长文本）。
* 输出的 `cross_similarity_matrix` 形状为 **`4 × 4`**。


* **矩阵含义解析**：
* 矩阵中的第 $i$ 行第 $j$ 列，代表**第 $i$ 个短文本**与**第 $j$ 个长文本**之间的语义相似度。
* **对角线上的值（如 `[0][0]`, `[1][1]`, `[2][2]`, `[3][3]`）**：因为长短文本是一一对应的，你会发现对角线上的相似度数值会非常高（通常在 `0.75 ~ 0.9` 以上）。这证明了 SBERT 能够跨越“长短文本的字数鸿沟”，精准识别出短查询（Query）和长文档（Document）表达的是同一个意思。
* **非对角线上的值**：短文本与不相关长文本之间的相似度会显着偏低，说明交叉检索具备很高的准确率。

#### 2. 长文本自相似度矩阵 (Long Texts Cosine Similarity Matrix)

```
[[1.          0.54958296 0.15263312 0.13238363]
```

* **对角线**：全为 `1.0` 左右。

* **行/列 0 与 1 之间**（气候长段落互比）：相似度为 **`0.5496`**。

* 与短文本相比，长文本内部同主题的相似度（~0.55 - 0.61）略微低于短文本（~0.63）。
* **原因**：长文本包含了更多样的词汇、背景信息和枝节修饰，向量平均池化（Mean-pooling）后引入了更多噪声，导致同类长文本之间的方向重合度不如精炼的短文本那么集中。但它们依然显著高于跨主题的相似度（跨主题值基本在 `0.02 ~ 0.15` 之间）。

### 八、 总结：这段代码的实际应用场景

这种“交叉相似度矩阵”的计算方式在工业界极其常见，直接对应了以下系统：

1. **智能客服 / 知识库问答（RAG）**：用户输入的简短问题（Short Text）与知识库里的长篇标准解答（Long Text）进行匹配。
2. **搜索引擎**：用用户的简短搜索词（Short Text）去召回并计算网页长文章（Long Text）的相关性得分。
