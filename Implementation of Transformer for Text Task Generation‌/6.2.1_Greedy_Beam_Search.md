Greedy_Beam_Search.py代码展示了如何使用 Python、PyTorch 和 Hugging Face 的 `transformers` 库，分别通过**底层手动实现（From Scratch）**和**调用库内置 API**两种方式，来实现 GPT-2 模型的 **Greedy Search（贪婪搜索）** 和 **Beam Search（束搜索）** 文本生成。

整个脚本可以分为五个核心模块：

---

### 一、 环境准备与模型加载

```python
import numpy as np
import torch
import torch.nn.functional as F
from transformers import GPT2LMHeadModel, GPT2Tokenizer

# 1. 初始化 GPT-2 模型和分词器
model_name = "gpt2"
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name)
model.eval()

```

* **组件加载**：加载了 OpenAI 的英文基础版 GPT-2 模型（`gpt2`）及其对应的分词器（Tokenizer）。
* **评估模式**：`model.eval()` 将模型设置为推理模式，关闭 Dropout 等训练专属操作，确保输出结果的确定性和稳定性。

### 二、 手动实现 Greedy Search（贪婪搜索）

```python
# 2. Greedy Search 修复版
def greedy_search(input_text, max_len=50):
  input_ids = tokenizer.encode(input_text, return_tensors="pt")
  generated = input_ids  # shape: [1, seq_len]

  with torch.no_grad():
    for _ in range(max_len):
      outputs = model(generated)
      next_token_logits = outputs.logits[:, -1, :]  # shape: [1, vocab_size]
      next_token = torch.argmax(
          next_token_logits, dim=-1, keepdim=True
      )  # shape: [1, 1]

      # 沿 seq 维度拼接 (dim=1)
      generated = torch.cat((generated, next_token), dim=1)

      # 判断标量数值是否等于 EOS Token ID
      if next_token.item() == tokenizer.eos_token_id:
        break

  return tokenizer.decode(generated[0], skip_special_tokens=True)

```

* **核心逻辑**：
1. 将输入文本编码为 Token ID 张量。
2. 在循环中，每次将当前已生成的序列输入模型，获取 `outputs.logits`。
3. `outputs.logits[:, -1, :]` 提取出**最后一个 Token 位置**对整个词表（Vocab Size）的预测得分（Logits）。
4. 使用 `torch.argmax` 无条件选择得分最高的那个词作为下一个词。
5. 将新词拼接到序列末尾，若遇到结束符 `eos_token_id` 则提前终止，最后解码输出文本。

### 三、 手动实现 Beam Search（束搜索）

```python
# 3. Beam Search 修复版
def beam_search(input_text, max_len=50, beam_width=3):
  input_ids = tokenizer.encode(input_text, return_tensors="pt")
  generated_sequences = [(input_ids, 0.0)]  # [(seq_tensor, cumulative_score)]

  with torch.no_grad():
    for _ in range(max_len):
      all_candidates = []
      for seq, score in generated_sequences:
        # 如果该序列已经以 EOS 结尾，不再继续扩展
        if seq[0, -1].item() == tokenizer.eos_token_id:
          all_candidates.append((seq, score))
          continue

        outputs = model(seq)
        next_token_logits = outputs.logits[:, -1, :]
        next_token_probs = F.log_softmax(next_token_logits, dim=-1)
        top_tokens = torch.topk(next_token_probs, beam_width, dim=-1)

        for i in range(beam_width):
          next_token = top_tokens.indices[0, i].unsqueeze(0).unsqueeze(0)  # [1, 1]
          new_seq = torch.cat((seq, next_token), dim=1)
          new_score = score + top_tokens.values[0, i].item()
          all_candidates.append((new_seq, new_score))

      # 按对数概率得分倒序排列，保留前 beam_width 个最优分支
      ordered = sorted(all_candidates, key=lambda x: x[1], reverse=True)
      generated_sequences = ordered[:beam_width]

      # 如果当前所有候选分支都到了 EOS 结尾，提前终止整体搜索
      if all(
          seq[0, -1].item() == tokenizer.eos_token_id
          for seq, _ in generated_sequences
      ):
        break

  # 取综合得分最高的分支
  best_sequence = generated_sequences[0][0]
  return tokenizer.decode(best_sequence[0], skip_special_tokens=True)

```

* **核心逻辑**：
1. 维护一个候选列表 `generated_sequences`，每个元素包含一个序列张量和对应的**累积对数概率得分**（Cumulative Log-Score）。
2. **分支扩展**：对当前的每个候选序列，利用 `F.log_softmax` 将 Logits 转换为对数概率，并用 `torch.topk` 挑选出概率最高的前 $B$ 个词（`beam_width=3`）。
3. **得分累加**：将新词的对数概率累加到原序列的总得分上（$\log(P_1 \times P_2) = \log P_1 + \log P_2$，用加法代替乘法可避免概率下溢）。
4. **剪枝排序**：将所有扩展出来的候选分支按得分从高到低排序，只保留前 `beam_width` 个最优分支，淘汰其余分支。

### 四、 测试运行（底层手动实现部分）

```python
# 4. 测试运行
input_text = "Once upon a time"
greedy_result = greedy_search(input_text)
beam_result = beam_search(input_text)

print("=== Greedy Search Result ===")
print(greedy_result)
print("\n=== Beam Search Result ===")
print(beam_result)

```

* 以英文短语 `"Once upon a time"` 作为提示词，分别调用上面手写的 `greedy_search` 和 `beam_search` 函数，并在控制台打印它们生成的后续文本。

### 五、 调用 Transformers 库内置的 `model.generate()`

```python
# 输入文本
input_text = "在城市的绿色和乡村的绿色之外，还有一块心灵的绿色，它"
input_ids = tokenizer.encode(input_text, return_tensors="pt")

# Greedy Search
greedy_output = model.generate(input_ids, max_length=80, do_sample=False)
greedy_text = tokenizer.decode(greedy_output[0], skip_special_tokens=True)

# Beam Search
beam_output = model.generate(
    input_ids, max_length=80, num_beams=5, early_stopping=True
)
beam_text = tokenizer.decode(beam_output[0], skip_special_tokens=True)

# 打印生成的文本
print("Greedy Search Result:\n", greedy_text)
print("\nBeam Search Result:\n", beam_text)

```

* **内置 API 的便捷性**：在实际工程中，我们通常不会手写上述底层的循环，而是直接调用 Hugging Face 封装好的 `model.generate()` 方法。
* `do_sample=False`：关闭随机采样，等同于 **Greedy Search**。
* `num_beams=5`：开启束搜索，束宽设为 5，同时配合 `early_stopping=True` 在遇到结束符时提前停止。
