T5_text_summarization.py代码是一个基于 **PyTorch** 和 **Hugging Face Transformers** 库微调与训练 **T5 模型**（以 `t5-small` 为例）来实现文本摘要（Text Summarization）任务的完整端到端脚本。

以下将从**整体架构流程、各步骤核心逻辑以及关键代码细节**进行详细说明。

---

### 一、 整体流程概览

整个脚本可以分为 9 个主要步骤：

1. **环境与网络配置**：设置 Hugging Face 国内镜像源，确保下载顺畅。
2. **模型与 Tokenizer 加载**：引入 T5 预训练模型及对应的分词器。
3. **数据集加载**：使用 `datasets` 库加载经典的 CNN/DailyMail 新闻摘要数据集。
4. **数据预处理**：对文本进行 Tokenization、添加 T5 专属的 `summarize: ` 前缀，并处理标签掩码。
5. **构建 DataLoader**：将处理好的数据包装为 PyTorch 的数据加载器（为了演示方便，截取了前 100 条）。
6. **训练配置**：初始化优化器（AdamW）并指定硬件设备（GPU/CPU）。
7. **模型训练循环**：执行单轮（Epoch）的前向传播、Loss 计算、反向传播与参数更新。
8. **推理函数定义**：编写用于生成摘要的 `generate_summary` 函数。
9. **效果测试**：拿测试集中的一条真实新闻进行模型推理并打印结果。

---

* **T5Tokenizer 与 T5ForConditionalGeneration**：分别用于将文本转化为数字 ID 的分词器，以及带有编码器-解码器（Encoder-Decoder）结构的条件生成模型。

#### 3. 核心数据预处理与前缀添加（第 4 步）

```python
def preprocess_function(examples):
  # 1. 拼接 T5 任务专属前缀
  inputs = ["summarize: " + article for article in examples["article"]]
  targets = [summary for summary in examples["highlights"]]

  # 2. 对输入（文章）和输出（摘要）分别进行 Tokenize
  model_inputs = tokenizer(
      inputs, max_length=512, truncation=True, padding="max_length"
  )
  labels = tokenizer(
      targets, max_length=150, truncation=True, padding="max_length"
  )

  # 3. 核心技巧：将标签中的 Padding Token 替换为 -100
  labels_ids = labels["input_ids"]
  labels_ids = [
      [(l if l != tokenizer.pad_token_id else -100) for l in label]
      for label in labels_ids
  ]

  model_inputs["labels"] = labels_ids
  return model_inputs

```

* **任务前缀（Task Prefix）**：T5 是一个多任务模型，必须通过 `summarize: ` 显式告诉模型当前要执行的是摘要任务。
* **`-100` 掩码机制**：在 PyTorch 的交叉熵损失函数（CrossEntropyLoss）中，默认会忽略值为 `-100` 的目标标签。将分词产生的填充字符（Padding）对应的 ID 设为 `-100`，可以**防止模型去计算填充部分的损失**，从而保证训练的准确性。
* **`batched=True`**：在 `dataset.map` 中开启批处理，能极大地加快大规模数据集的预处理速度。

#### 4. 模型训练与优化循环（第 5-7 步）

```python
# 截取前 100 条样本作为演示微调
train_dataset = tokenized_datasets["train"].select(range(100))
train_dataloader = DataLoader(train_dataset, batch_size=4, shuffle=True)

optimizer = AdamW(model.parameters(), lr=5e-5)

for epoch in range(epochs):
  model.train()
  total_loss = 0
  for step, batch in enumerate(train_dataloader):
    batch = {k: v.to(device) for k, v in batch.items()}

    optimizer.zero_grad()  # 清空历史梯度
    outputs = model(**batch)  # 前向传播，T5 会自动计算并返回 loss
    loss = outputs.loss
    loss.backward()  # 反向传播计算梯度
    optimizer.step()  # 更新权重

    total_loss += loss.item()

```

* **自包含 Loss 计算**：Hugging Face 的 `T5ForConditionalGeneration` 在输入中包含 `labels` 时，会在前向传播时**自动计算并返回负对数似然损失（loss）**，非常方便。
* **`AdamW` 优化器**：大语言模型微调的标准优化器，带有权重衰减（Weight Decay）修复，能带来更好的泛化性能。

#### 5. 推理生成与测试（第 8-9 步）

```python
def generate_summary(input_text):
  model.eval()
  text_to_summarize = "summarize: " + input_text
  inputs = tokenizer(
      text_to_summarize,
      return_tensors="pt",
      max_length=512,
      truncation=True,
      padding="max_length",
  ).to(device)

  with torch.no_grad():
    summary_ids = model.generate(
        inputs["input_ids"],
        max_length=150,
        num_beams=4,
        length_penalty=2.0,
        early_stopping=True,
    )

  summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
  return summary

```

* **`model.generate()` 参数详解**：
* `num_beams=4`：采用束搜索（Beam Search）策略，在每一步生成时保留概率最高的 4 条候选路径，显著提升生成句子的连贯性和质量。
* `length_penalty=2.0`：长度惩罚系数大于 1.0 时，会鼓励模型生成稍长一些的摘要，避免摘要过于短小精悍而丢失核心细节。
* `early_stopping=True`：当所有 Beam 路径都遇到结束标记（EOS）时提前停止生成，提高推理效率。


* **`skip_special_tokens=True`**：解码时自动过滤掉类似 `</s>`、`<pad>` 等特殊的控制符，只输出纯文本内容。
