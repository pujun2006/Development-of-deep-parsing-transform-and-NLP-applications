TopK_TopP.py代码使用 PyTorch 从零实现（From Scratch）了大语言模型中常用的两种核心随机采样策略：**Top-K 采样**和 **Top-P（核采样，Nucleus Sampling）**。代码通过一个包含 8 个词的模拟词汇表和一组模型输出分数（Logits），直观地展示了这两种算法的底层筛选与抽样逻辑。

整个脚本可以拆解为四个核心模块：

---

### 一、 模拟数据准备与概率转换

```python
import torch
import torch.nn.functional as F

# 模拟的词汇表及其对应的概率分布
vocab = ['the', 'cat', 'sat', 'on', 'a', 'mat', 'dog', 'barked']
logits = torch.tensor([1.5, 2.3, 1.2, 0.8, 1.4, 0.6, 1.8, 1.0])  # 模拟的模型输出概率分布
probabilities = F.softmax(logits, dim=-1)  # 转换为概率分布

```

* **模拟词汇表 (`vocab`)**：定义了一个包含 8 个英文单词的简易词表。
* **原始得分 (`logits`)**：模拟大模型最后一层输出的未经归一化的原始得分（Logits）。得分越高，代表该词被模型预测的倾向越强（例如 `'cat'` 的得分是 2.3，相对较高）。
* **概率转换 (`F.softmax`)**：通过 Softmax 函数将原本无界的 Logits 转换成和为 1 的概率分布，供后续的随机抽样使用。

---

### 二、 Top-K 采样实现

```python
# Top-K采样实现
def top_k_sampling(probabilities, k):
    values, indices = torch.topk(probabilities, k)
    chosen_index = torch.multinomial(values, 1)  # 从Top-K词中随机选择一个
    return indices[chosen_index.item()]

```

* **核心逻辑**：
1. **筛选前 $K$ 个高频词**：`torch.topk(probabilities, k)` 会找出概率最高的前 $K$ 个值（`values`）及其在原词表中的位置索引（`indices`）。
2. **多项式随机抽样**：`torch.multinomial(values, 1)` 根据这 $K$ 个词的权重（概率大小）进行随机抽样，返回抽中者在 Top-K 子集中的相对位置。
3. **映射回原词表**：`indices[chosen_index.item()]` 通过相对索引找到其在全局词表 `vocab` 中的真实索引。


* **执行效果**：当 $k=3$ 时，模型只会从概率最高的前 3 个词中通过随机抽样选出最终的词，从而有效过滤掉词表中其他概率极低的长尾噪音。

### 三、 Top-P（核采样）实现

```python
# Top-P采样实现
def top_p_sampling(probabilities, p=0.9):
    sorted_probs, sorted_indices = torch.sort(probabilities, descending=True)
    cumulative_probs = torch.cumsum(sorted_probs, dim=-1)

    # 获取最小的词集合，使其累积概率大于p
    idx = torch.where(cumulative_probs >= p)[0][0]

    # 从这些词中随机选择
    chosen_index = torch.multinomial(sorted_probs[:idx + 1], 1)
    return sorted_indices[chosen_index.item()]

```

* **核心逻辑**：
1. **降序排序**：`torch.sort(..., descending=True)` 将词表中的所有词按概率从大到小排序，同时保留它们原本的索引（`sorted_indices`），以便最后映射回去。
2. **计算累积概率**：`torch.cumsum(sorted_probs, dim=-1)` 计算排序后概率的累积和（例如前 1 个词累积 40%，前 2 个词累积 70%，前 3 个词累积 92%）。
3. **动态截断（阈值判定）**：`torch.where(cumulative_probs >= p)[0][0]` 找出累积概率首次达到或超过阈值 $p$（此处为 0.9）的那个截断位置索引 `idx`。
4. **构建动态集合并抽样**：截取 `sorted_probs[:idx + 1]`（即核心集 Nucleus），利用 `torch.multinomial` 在这个动态大小的候选池中进行随机抽样。
5. **还原索引**：通过 `sorted_indices` 映射回原词表的索引位置。


* **核心优势**：候选集的大小是**动态自适应**的——如果当前语境非常确定，可能只需要前 2、3 个词就能累积到 0.9 的概率；如果语境充满不确定性，候选池会自动扩大，将几十个词纳入进来，兼顾了安全性和创造力。

---

### 四、 执行与输出

```python
# 执行Top-K采样（选择前3个词）
k = 3
top_k_word = top_k_sampling(probabilities, k)
print(f"Top-K采样结果: {vocab[top_k_word]}")

# 执行Top-P采样（设置累积概率阈值为0.9）
top_p_word = top_p_sampling(probabilities, 0.9)
print(f"Top-P采样结果: {vocab[top_p_word]}")

```

* 这两行代码分别调用了上面定义好的两个函数，通过 `vocab[index]` 将返回的数字索引转换为人类可读的单词，并在控制台打印出最终通过 Top-K 和 Top-P 随机抽样出来的词。
