NGram.py代码使用 Python 实现了一个简易的 **Trigram（三元语法，$n=3$）语言模型**，并利用该模型进行基于马尔可夫假设的随机文本生成。

代码通过 `jieba` 分词处理中文文本，构建了“上下文 $\rightarrow$ 后续词候选列表”的映射字典，最后通过随机采样的方式自回归地生成新文本。

下面按模块详细拆解代码的执行过程和原理：

---

### 一、 准备工作与分词（Tokenization）

```python
import random
from collections import defaultdict
import jieba

# 输入文本
text = "机器学习是一种通过统计方法让计算机拥有学习能力的技术。这种技术可以帮助计算机从数据中提取特征、分析模式，从而完成预测任务。"

# 将文本分词
tokens = jieba.lcut(text)
print(tokens)

```

* **依赖库**：
* `random`：用于在生成文本时从候选词中随机抽样。
* `collections.defaultdict`：用于构建 n-gram 字典，当访问不存在的键时自动返回空列表 `[]`，避免报 `KeyError`。
* `jieba`：中文分词工具。中文没有天然的词间空格，必须先通过分词将句子切分为词语序列（`tokens`），n-gram 模型的统计单位才是“词”而不是“单字”。



---

### 二、 构建 n-gram 模型（训练阶段）

```python
# 定义n-gram模型的n值
n = 3

# 构建n-gram模型
n_grams = defaultdict(list)

# 生成n-grams字典
for i in range(len(tokens) - n):
    key = tuple(tokens[i:i + n - 1])  # 使用前n-1个词作为键
    next_word = tokens[i + n - 1]     # 使用第n个词作为值
    n_grams[key].append(next_word)

print(n_grams)

```

* **核心思想**：因为 $n=3$（Trigram），所以模型遵循二阶马尔可夫假设：**当前词只取决于前面紧邻的 2 个词**。
* **字典结构**：`n_grams` 的键（Key）是一个包含 $n-1$ 个词的元组 `tuple`（作为上下文），值（Value）是一个列表，记录了在训练文本中紧跟在这个上下文后面的所有可能词汇。
* **循环逻辑**：
* 滑动窗口遍历分词后的列表。
* `key = tuple(tokens[i:i + n - 1])`：取连续的 2 个词作为历史状态（例如 `('机器', '学习')`）。
* `next_word = tokens[i + n - 1]`：取紧随其后的第 3 个词作为目标词（例如 `'是'`）。
* `n_grams[key].append(next_word)`：将目标词追加到该上下文对应的候选列表中。



---

### 三、 文本生成函数（推理与生成阶段）

```python
# 定义生成文本函数
def generate_text(n_grams, num_words=15):
    # 随机选择n-gram的起始点
    start = random.choice(list(n_grams.keys()))
    result = list(start)

    for _ in range(num_words - len(start)):
        state = tuple(result[-(n - 1):])  # 获取最后n-1个词
        next_word_choices = n_grams.get(state, [])
        if not next_word_choices:
            break
        next_word = random.choice(next_word_choices)
        result.append(next_word)
    return ' '.join(result)

# 生成并输出文本
generated_text = generate_text(n_grams)
print("生成的文本:", generated_text)

```

这段代码实现了文本的**自回归生成（Autoregressive Generation）**：

1. **随机起点**：`random.choice(list(n_grams.keys()))` 从已学习的上下文组合中随机挑选一个作为句子的开头（例如 `('统计', '方法')`），并将它们放入 `result` 列表中。
2. **状态提取**：在循环中，每次截取 `result` 末尾的 $n-1$ 个词作为当前的 `state`（上下文窗口）。
3. **候选查询与安全检查**：
* `n_grams.get(state, [])`：查询当前状态下有哪些可能的高频后续词。
* `if not next_word_choices: break`：如果当前状态在训练集中是从未出现过的死胡同（没有后续词记录），则提前终止生成。


4. **随机采样**：`random.choice(next_word_choices)` 从候选列表中随机挑选一个词。此处没有使用单纯的贪婪搜索（总是选频率最高的前面词），而是通过随机抽样增加了生成文本的多样性。
5. **拼接返回**：将生成的词列表用空格连接（`' '.join(result)`）并输出。
