T5_text_fine_tuning.py代码对之前的 T5 文本摘要代码(T5_text_summarization.py)进行了几处**非常关键且专业**的优化，尤其是在推理阶段的鲁棒性和细节规范上。

以下是对这段代码的详细说明，重点剖析与上一版代码相比的**改进点**以及各个核心模块的逻辑：

---

### 一、 核心改进点（相比T5_text_summarization.py）

1. **显式传入 `attention_mask`（最大亮点）**：
在推理函数 `generate_summary` 中，`model.generate` 增加了 `attention_mask=inputs["attention_mask"]`。
* **原因**：在文本进行 `padding="max_length"` 填充时，文本尾部会被填满 `<pad>` 标记。如果不传 `attention_mask`，编码器会把这些填充的空白字符也当作真实的语义输入去计算注意力权重，这会导致模型分心、生成质量下降。传入 `attention_mask` 后，模型能够精准识别哪些是有效文本、哪些是填充空白。


2. **注释标明了代码修复点**：
代码中清晰地标注了“修复 1”至“修复 5”的注释，分别对应优化器引入、数据集列移除、命名空间兼容、Loss 掩码处理以及推理掩码传入，非常利于代码维护和他人学习。

### 二、 全代码逐段拆解说明

#### 1. 初始化与镜像配置（第 1-13 行）

```python
import os
import torch
from datasets import load_dataset
from torch.optim import AdamW
from torch.utils.data import DataLoader
from transformers import T5ForConditionalGeneration, T5Tokenizer

os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"

model_name = "t5-small"
tokenizer = T5Tokenizer.from_pretrained(model_name)
model = T5ForConditionalGeneration.from_pretrained(model_name)

```

* **环境准备**：通过国内镜像加速下载，加载标准的小型 T5 模型 (`t5-small`，约 6000 万参数)，适合在普通 GPU 甚至 CPU 上快速跑通实验。

#### 2. 数据集加载与预处理（第 15-46 行）

```python
try:
  dataset = load_dataset("abisee/cnn_dailymail", "3.0.0")
except Exception:
  dataset = load_dataset("cnn_dailymail", name="3.0.0")


def preprocess_function(examples):
  inputs = ["summarize: " + article for article in examples["article"]]
  targets = examples["highlights"]

  model_inputs = tokenizer(
      inputs, max_length=512, truncation=True, padding="max_length"
  )
  labels = tokenizer(
      targets, max_length=150, truncation=True, padding="max_length"
  )

  # 将填充字符 ID 转换为 -100，屏蔽 Loss 计算
  labels_ids = labels["input_ids"]
  labels_ids = [
      [(l if l != tokenizer.pad_token_id else -100) for l in label]
      for label in labels_ids
  ]

  model_inputs["labels"] = labels_ids
  return model_inputs


tokenized_datasets = dataset.map(
    preprocess_function,
    batched=True,
    remove_columns=dataset["train"].column_names,
)
tokenized_datasets.set_format("torch")

train_dataset = tokenized_datasets["train"].select(range(100))
train_dataloader = DataLoader(train_dataset, batch_size=4, shuffle=True)

```

* **容错加载**：兼顾了不同版本 `datasets` 库对 CNN/DailyMail 数据集命名空间的要求。
* **数据对齐**：通过 `remove_columns` 移除了原始的文本字符串列，只保留模型训练必需的张量字段（`input_ids`, `attention_mask`, `labels`），防止 `DataLoader` 在拼批次（collate）时报错。

#### 3. 训练循环（第 48-67 行）

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)
optimizer = AdamW(model.parameters(), lr=5e-5)

epochs = 1
for epoch in range(epochs):
  model.train()
  for step, batch in enumerate(train_dataloader):
    batch = {k: v.to(device) for k, v in batch.items()}

    optimizer.zero_grad()
    outputs = model(**batch)
    loss = outputs.loss
    loss.backward()
    optimizer.step()

    if (step + 1) % 5 == 0:
      print(f"Epoch {epoch+1}, Step {step+1}, Loss: {loss.item():.4f}")

```

* **高效微调**：利用 PyTorch 的标准梯度下降循环，每隔 5 个 Step 打印一次当前的训练损失（Loss），可以直观监控模型在小样本（100条）上的收敛情况。

#### 4. 推理生成函数（第 70-91 行）

```python
def generate_summary(input_text):
  model.eval()
  input_text = "summarize: " + input_text
  inputs = tokenizer(
      input_text,
      return_tensors="pt",
      max_length=512,
      truncation=True,
      padding="max_length",
  ).to(device)

  with torch.no_grad():
    summary_ids = model.generate(
        input_ids=inputs["input_ids"],
        attention_mask=inputs["attention_mask"],  # 显式传入掩码
        max_length=150,
        num_beams=4,
        length_penalty=2.0,
        early_stopping=True,
    )

  summary = tokenizer.decode(summary_ids[0], skip_special_tokens=True)
  return summary

```

* **束搜索参数说明**：
* `num_beams=4`：开启束搜索，平衡生成质量与计算开销。
* `length_penalty=2.0`：对生成长度进行轻微惩罚/鼓励，确保摘要不会过于短小。
* `early_stopping=True`：一旦所有 Beam 候选都输出结束符，立即停止解码。

test_text = dataset["test"][0]["article"]
print("Original Article:")
print(test_text[:300] + "...")
print("\nGenerated Summary:")
