Adversarial Data Augmentation.py代码演示了在自然语言处理（NLP）领域中非常经典的数据增强（Data Augmentation）技术。

在训练文本分类模型时，往往会遇到训练数据不足或样本单一的问题。通过对原始文本进行**近义词替换**、**简繁体转换**和**错别字模拟**，可以在不改变语义的前提下扩充数据集，从而**提高模型的泛化能力和鲁棒性（抗干扰能力）**。

下面详细拆解代码的核心逻辑：

---

### 一、 依赖库与初始化

```python
import random
from opencc import OpenCC
from nlpcda import Similarword

# 替代 synonyms 的近义词替换组件
smw = Similarword(create_num=1, change_rate=0.3)

data = [
    {"text": "这款产品非常好用，功能强大且易操作", "label": "positive"},
    {"text": "服务态度差，体验非常糟糕", "label": "negative"},
    {"text": "产品质量一般，但价格实惠", "label": "neutral"}
]

```

* **第三方库选择**：
* **`nlpcda` (Natural Language Processing Data Augmentation)**：一个专为中文设计的文本数据增强工具库，这里使用了它的 `Similarword`（近义词替换）组件。初始化时设置 `create_num=1`（每条文本生成 1 个变体）和 `change_rate=0.3`（30% 的词汇会被尝试替换）。
* **`Opencc`**：开源的中文简繁体转换工具，用于将简体中文转为繁体中文。


* **原始数据 (`data`)**：定义了一个包含 3 条不同情感倾向（正面、负面、中性）的文本分类样本集。

---

### 二、 三大核心数据增强策略

代码定义了三种不同维度的文本扰动函数：

#### 1. 近义词替换 (`synonym_replacement`)

```python
def synonym_replacement(text):
    res = smw.replace(text)
    return res[0] if res else text

```

* **原理**：利用 `nlpcda` 的词向量或同义词词典，在保持原意基本不变的情况下，把文本中的部分词汇替换为意思相近的词。
* **作用**：丰富句式表达，防止模型死记硬背特定词汇。

#### 2. 简繁体转换 (`convert_simplified_to_traditional`)

```python
cc = OpenCC('s2t')
def convert_simplified_to_traditional(text):
    return cc.convert(text)

```

* **原理**：通过 OpenCC 的 `'s2t'`（Simplified to Traditional）规则，将简体字转换为繁体字。
* **作用**：如果训练数据不仅面向内地用户，还面向港台或其他繁体中文用户，该增强能显著提升模型对繁体文本的适应能力。

#### 3. 随机同音/近音字错别字注入 (`typo_augmentation`)

```python
def typo_augmentation(text, typo_prob=0.2):
    typo_dict = {'好': '号', '差': '查', '强': '墙', '易': '依'}
    words = list(text)
    for i, word in enumerate(words):
        if random.random() < typo_prob and word in typo_dict:
            words[i] = typo_dict[word]
    return ''.join(words)

```

* **原理**：模拟网民在打字时容易出现的错别字或同音/近音字错误。代码定义了一个小字典（如把“好”写成“号”），并以 `20%`（`typo_prob=0.2`）的随机概率对文本中的字进行替换。
* **作用**：真实用户的输入往往包含大量错别字。让模型见过含错别字的训练样本后，它在生产环境中的抗干扰能力会更强。

---

### 三、 数据扩展流水线 (`augment_data`)

```python
def augment_data(data):
    augmented_data = []
    for entry in data:
        text = entry['text']
        label = entry['label']

        # 1. 保留原始样本
        augmented_data.append({"text": text, "label": label})
        # 2. 添加近义词替换样本
        augmented_data.append({"text": synonym_replacement(text), "label": label})
        # 3. 添加繁体转换样本
        augmented_data.append({"text": convert_simplified_to_traditional(text), "label": label})
        # 4. 添加错别字模拟样本
        augmented_data.append({"text": typo_augmentation(text), "label": label})

    return augmented_data

```

* **乘数效应**：该函数遍历原始数据的每一条样本，**无损保留原样本**的同时，通过上述三种增强方法各生成一条新样本。
* **标签绑定**：无论文本怎么变，其原本的业务标签（`label`）保持不变（例如正向评论变出近义词或繁体后，依然属于正向）。这意味着原本只有 3 条的数据，经过扩充后会变成 $3 \times 4 = 12$ 条。

---

### 四、 遍历执行与输出

```python
augmented_data = augment_data(data)
for entry in augmented_data:
    print(f"Text: {entry['text']}, Label: {entry['label']}")

```

* 执行扩充函数，并格式化打印出最终生成的所有数据集内容，直观展示增强后的文本多样性。
