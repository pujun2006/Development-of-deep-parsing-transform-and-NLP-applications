entence_transformers.py中的两段代码展示了在自然语言处理（NLP）和文本挖掘领域中非常实用的两个高级应用场景：**基于领域知识（情感词典）的向量特征增强**，以及**基于 Sentence-BERT 嵌入向量的无监督聚类分析**。

下面详细拆解这两段代码的核心逻辑与工程技术：

---

### 第一段代码：基于情感词典的特征增强与降维

这段代码通过结合 **SBERT（句子向量）** 与 **领域情感词典**，对文本的向量进行人工干预和修正，随后使用 **PCA** 降维以便于观察。

#### 1. 核心步骤逐行解析

```python
# 1. 初始化 SBERT 模型并生成文本嵌入
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
embeddings = model.encode(texts)

```

* **SBERT（Sentence-BERT）**：加载了一个轻量级且支持多语言的预训练模型（`paraphrase-multilingual-MiniLM-L12-v2`），它能将每段变长的文本转化为固定维度的密集向量（这里是 **384 维**）。

```python
# 2. 示例情感词典
sentiment_dict = {"好用": 1, "强大": 1, "差劲": -1, "糟糕": -1, "推荐": 1, "好": 1}

def enhance_embedding(text, embedding):
    words = jieba.lcut(text)  # 使用 jieba 进行中文分词
    weights = [sentiment_dict.get(word, 0) for word in words]

    # 计算情感增强因子
    enhancement_factor = np.mean(weights) if len(weights) > 0 else 0
    return embedding * (1 + enhancement_factor)

enhanced_embeddings = np.array([enhance_embedding(text, emb) for text, emb in zip(texts, embeddings)])

```

* **特征注入（Feature Augmentation）**：纯粹的语义向量有时无法精准捕捉特定的情感倾向。代码通过 `jieba` 分词检查文本中是否包含情感词典里的词：
* 如果包含正面词（如“好用”、“推荐”），平均权重为正，向量会被等比例放大（`1 + 因子`）。
* 如果包含负面词（如“差劲”、“糟糕”），平均权重为负，向量会被缩小或反向调节。


* **目的**：通过外部领域知识（词典）修正大模型的语义空间，使后续分类或聚类时对“情感特征”更加敏感。

```python
# 3. PCA 降维
pca = PCA(n_components=2)
reduced_embeddings = pca.fit_transform(enhanced_embeddings)

```

* **主成分分析（PCA）**：SBERT 生成的向量高达 384 维，人类无法直观理解。代码利用 `PCA` 将高维向量降至 **2 维**，以便于后续在二维平面上做可视化展示（如画散点图）。代码中特别注意到了样本量限制（`n_samples = 6`，所以降维维数必须小于等于 6）。

### 第二段代码：基于 Sentence-BERT 的文本聚类分析

这段代码展示了如何使用无监督学习算法（**K-Means 聚类**）对未经标注的文本进行自动归类。

#### 1. 核心步骤逐行解析

```python
# 1. 生成高维嵌入向量
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')
embeddings = model.encode(texts)

```

* 对 5 条中文评论进行分词和向量化编码，得到 384 维的稠密语义向量。代码中通过 `embedding[:5]` 打印了前 5 个维度的数值，用来直观查看向量结构。

```python
# 2. 定义聚类数并执行 K-Means
num_clusters = 2
kmeans = KMeans(n_clusters=num_clusters, random_state=0)
kmeans.fit(embeddings)
cluster_labels = kmeans.labels_

```

* **K-Means 聚类**：设定聚类数量 `num_clusters = 2`（对应正面、负面两类）。
* `kmeans.fit(embeddings)` 会在 384 维空间中自动寻找 2 个聚类中心（Centroids），并将每条文本的向量归类到距离最近的簇中。
* `cluster_labels` 会返回每条文本所属的类别标签（例如 `0` 或 `1`）。

```python
# 3. 输出聚类结果
for i, label in enumerate(cluster_labels):
    print(f"Text: {texts[i]} -> Cluster Label: {label}")

```

* 将文本与聚类标签对应打印，从而实现**无需人工标注的自动文本分类（无监督分类）**。

### 四、 总结与应用场景

1. **第一段代码的应用场景**：**知识增强（Knowledge-Enhanced Representation）**。在冷启动或标注数据极少时，利用领域词典对通用大模型的向量进行干涉，可以快速提升模型对特定业务（如情感分析、风控审核）的敏感度。
2. **第二段代码的应用场景**：**海量用户评论自动聚类/舆情分析**。当企业面对数以万计的客服工单或用户评论时，可以先用 SBERT 提特征，再用 K-Means 自动把它们聚成几大类，从而快速发现用户集中吐槽或赞赏的核心痛点。
