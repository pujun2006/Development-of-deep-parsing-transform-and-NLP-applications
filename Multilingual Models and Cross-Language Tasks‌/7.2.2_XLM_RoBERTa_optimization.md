XLM_RoBERTa_optimization.py这段更新后的代码对之前的XLM_RoBERTa.py结构做了一个非常巧妙且实用的优化：**直接利用分类模型（`classification_model`）内部的输出同时完成了文本分类和句向量提取**，避免了重复加载模型，节省了显存和计算资源。

以下是对这段代码的逐段详细拆解：

---

### 一、 初始化与多语言输入处理

```python
import torch
import torch.nn.functional as F
from transformers import (
    AutoModel,
    AutoModelForSequenceClassification,
    AutoTokenizer,
    M2M100ForConditionalGeneration,
    M2M100Tokenizer,
)

model_name = "xlm-roberta-base"

# 1. 使用通用 Auto 类初始化 Tokenizer 和分类模型
tokenizer = AutoTokenizer.from_pretrained(model_name)
classification_model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=3
)

texts = ["Hello, how are you?", "Bonjour, comment ça va?", "Hola, ¿cómo estás?"]
inputs = tokenizer(texts, return_tensors="pt", padding=True, truncation=True)

```

* **代码优化点**：这里**去掉了**上一版中单独加载基础编码器（`AutoModel.from_pretrained`）的代码，只保留了 `AutoModelForSequenceClassification`。
* **输入编码**：`tokenizer` 将英语、法语、西班牙语的多语言文本统一转换为模型可接受的 Tensor 格式，并通过 `padding=True` 对齐长度，`truncation=True` 限制最大长度。

---

### 二、 任务一：多语言文本分类预测（并获取隐藏层状态）

```python
print("--- 1. 多语言文本分类预测 ---")
with torch.no_grad():
  outputs = classification_model(**inputs, output_hidden_states=True)
  predictions = F.softmax(outputs.logits, dim=-1)

for idx, text in enumerate(texts):
  print(f"Text: {text}")
  print("Predicted Probabilities:", predictions[idx].numpy().round(4))
print("\n")

```

* **关键参数 `output_hidden_states=True**`：这是这一版代码精妙的地方。在进行分类前向传播时，通过设置该参数，模型不仅返回了分类的最终得分（`logits`），还会把各层的隐藏状态（Hidden States）一并返回。这为后面直接“借用”特征做好了准备。
* **Logits 与概率转化**：`outputs.logits` 的形状为 `[batch_size, num_labels]`，通过 `F.softmax(..., dim=-1)` 转换为和为 1 的归一化概率分布。

### 三、 任务二：提取跨语言通用句向量（Masked Mean Pooling）

```python
print("--- 2. 提取跨语言文本语义向量 (Sentence Embeddings) ---")
# 直接复用 classification_model 内部的 roberta backbone，无需重复加载模型
last_hidden_state = outputs.hidden_states[-1]

# 结合 attention_mask 进行正确的平均池化（排除 padding 干扰）
attention_mask = inputs["attention_mask"].unsqueeze(-1)
sum_embeddings = torch.sum(last_hidden_state * attention_mask, dim=1)
sum_mask = torch.clamp(attention_mask.sum(dim=1), min=1e-9)
sentence_embeddings = sum_embeddings / sum_mask

for idx, text in enumerate(texts):
  print(f"Text: {text}")
  print(
      "Sentence Vector (first 5 dims):",
      sentence_embeddings[idx, :5].numpy().round(4),
  )
print("\n")

```

* **复用特征**：`outputs.hidden_states[-1]` 获取了最后一层（Transformer 最后一层 Encoder 块输出）的 `last_hidden_state`，形状为 `[batch_size, seq_len, hidden_dim]`。
* **Masked Mean Pooling（带掩码的均值池化）**：
1. `attention_mask.unsqueeze(-1)`：将原本形状为 `[batch_size, seq_len]` 的掩码扩展维度，以便和隐藏状态相乘。
2. `last_hidden_state * attention_mask`：将文本中由于 `padding=True` 补齐的无效 Token 位置的特征向量全部置零，防止其污染平均值。
3. `torch.sum(..., dim=1)`：对有效 Token 的特征向量求和。
4. `torch.clamp(..., min=1e-9)`：计算每个句子实际的有效 Token 数量作为分母，并用 `torch.clamp` 设置下限，**完美防止分母为 0 的崩溃错误**。


* 通过这种方法，我们无需额外加载模型，就高效地提取出了这三句不同语言的句向量，它们在向量空间中具有极高的语义可比性。

### 四、 任务三：真正的多语言机器翻译（Seq2Seq 编码器-解码器）

```python
print("--- 3. 真正的机器翻译示例 (法文 -> 中文) ---")
trans_model_name = "facebook/m2m100_418M"
trans_tokenizer = M2M100Tokenizer.from_pretrained(trans_model_name)
trans_model = M2M100ForConditionalGeneration.from_pretrained(trans_model_name)

src_text = "Bonjour, comment ça va?"
trans_tokenizer.src_lang = "fr"  # 设置源语言为法文

encoded_input = trans_tokenizer(src_text, return_tensors="pt")
generated_tokens = trans_model.generate(
    **encoded_input,
    forced_bos_token_id=trans_tokenizer.get_lang_id("zh"),  # 设置目标语言为中文
)
translated_text = trans_tokenizer.batch_decode(
    generated_tokens, skip_special_tokens=True
)[0]

print(f"源文本 (法文): {src_text}")
print(f"翻译结果 (中文): {translated_text}")

```

* **架构分工说明**：
* 前两部分使用的 `xlm-roberta-base` 是 **Encoder-only**（仅编码器）架构，擅长“理解”和“提取特征”（用于分类、检索、向量化）。
* 第三部分使用的 `facebook/m2m100_418M` 是 **Encoder-Decoder**（编码器-解码器）架构，专门用于“生成”文本（如机器翻译、文本生成）。


* **翻译控制流**：
1. `trans_tokenizer.src_lang = "fr"` 告诉模型输入是法文。
2. `forced_bos_token_id` 强制解码器以中文起始符（Beginning of Sentence）开局，引导模型一步步自回归生成中文翻译结果。
