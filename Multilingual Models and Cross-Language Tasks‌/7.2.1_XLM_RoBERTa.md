7.2.1_XLM_RoBERTa.py代码展示了使用 Hugging Face `transformers` 库处理**多语言文本任务**的三个典型场景：**提取多语言语义向量（Feature Extraction）**、**多语言文本分类（Sequence Classification）**，以及**跨语言机器翻译（Translation）**。

下面详细拆解这段代码的逻辑和核心技术点。

---

### 一、 初始化与多语言输入构建

```python
import torch
import torch.nn.functional as F
from transformers import (
    AutoModel,
    AutoModelForSequenceClassification,
    AutoTokenizer,
    M2M100ForConditionalGeneration,
    M2M100Tokenizer,
)

model_name = "xlm-roberta-base"

# 1. 统一初始化 Tokenizer 和 Model (避免重复加载)
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name)
classification_model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=3
)

# 定义多语言输入文本 (包含英语、法语、西班牙语)
texts = ["Hello, how are you?", "Bonjour, comment ça va?", "Hola, ¿cómo estás?"]
inputs = tokenizer(texts, return_tensors="pt", padding=True, truncation=True)

```

* **模型选择**：这里选用了 `xlm-roberta-base`（简称 XLM-R）。它通过在 100 种语言的超大规模单语语料上进行掩码语言建模（MLM）预训练，能够将不同语言的语义映射到一个**共享的高维向量空间**中。
* **多语言批处理（Batching）**：`tokenizer(texts, ...)` 会自动将不同语言、不同长度的文本进行分词（Tokenization）、查表转换为 Token ID，并执行：
* `padding=True`：将较短的句子用填充符（Padding Token）补齐到批次中最长句子的长度，使之成为规整的二维张量。
* `truncation=True`：截断超过模型最大长度（通常为 512）的文本。
* 返回的 `inputs` 包含 `input_ids` 和 `attention_mask`。



---

### 二、 任务一：提取多语言文本的句向量表示 (Mean Pooling)

此任务展示了如何从基础的编码器模型中获取整句话的稠密向量（Sentence Embedding），这在语义检索、文本聚类和跨语言相似度计算中非常常用。

```python
print("--- 1. 提取多语言语义向量 ---")
with torch.no_grad():
  outputs = model(**inputs)
  # last_hidden_state: [batch_size, seq_len, hidden_dim]
  token_embeddings = outputs.last_hidden_state

  # 计算句子粒度的 Mean Pooling 向量 (忽略 Padding 影响)
  attention_mask = inputs["attention_mask"].unsqueeze(-1)
  sentence_embeddings = torch.sum(
      token_embeddings * attention_mask, dim=1
  ) / torch.clamp(attention_mask.sum(dim=1), min=1e-9)

```

* **`outputs.last_hidden_state`**：输出每个 Token 的上下文嵌入矩阵，形状为 `[batch_size, seq_len, hidden_dim]`（XLM-R Base 的隐藏维度一般是 768）。
* **Mean Pooling（均值池化）**：
由于每个句子的有效长度不同，填充部分（Padding）不能参与向量均值的计算，否则会拉偏语义。代码通过乘以 `attention_mask`（将填充位置置 0），然后只对有效 Token 求和，并除以有效 Token 的数量（用 `torch.clamp` 防止除零错误），从而得到高质量的**句向量**。
* **跨语言特性**：虽然这三句话是不同的语言（英语、法语、西班牙语），但因为它们表达的意思相同（“你好吗？”），在经过 `xlm-roberta-base` 后，它们在向量空间中的距离会非常近。

### 三、 任务二：多语言序列分类任务 (Sequence Classification)

此任务展示了如何利用预训练模型进行下游多语言分类（如情感分析、多语言意图识别）。

```python
print("--- 2. 多语言文本分类预测 ---")
with torch.no_grad():
  class_outputs = classification_model(**inputs)
  predictions = F.softmax(class_outputs.logits, dim=-1)

for idx, text in enumerate(texts):
  print(f"Text: {text}")
  print(
      "Predicted Class Probabilities:", predictions[idx].numpy().round(4)
  )
print("\n")

```

* **`AutoModelForSequenceClassification`**：在 XLM-R 基础架构之上自动拼接了一个线性分类头（Classification Head），这里指定了 `num_labels=3`（例如代表：消极、中性、积极三分类）。
* **Logits 与 Softmax**：模型直接输出原始的未归一化得分（Logits），通过 `F.softmax` 转化为和为 1 的类别概率分布。
* *注：由于代码中使用的是未经微调（Fine-tuning）的预训练模型权重，当前的分类概率输出是随机或无实际业务意义的，实际应用中需要在特定任务的标注数据集上进行微调。*

### 四、 任务三：真正的多语言机器翻译 (使用 M2M100 翻译模型)

跨语言编码器（如 XLM-R）擅长理解和表示多语言，但它们是 **Encoder-only** 架构，无法直接用于生成文本（翻译）。因此，代码切换到了 **Encoder-Decoder（编码器-解码器）** 架构的真正多语言翻译模型 **M2M100**。

```python
print("--- 3. 真正的多语言机器翻译 (法文/西班牙文 -> 中文) ---")
trans_model_name = "facebook/m2m100_418M"
trans_tokenizer = M2M100Tokenizer.from_pretrained(trans_model_name)
trans_model = M2M100ForConditionalGeneration.from_pretrained(trans_model_name)

# 以第二句法文 "Bonjour, comment ça va?" 翻译为中文为例
src_text = "Bonjour, comment ça va?"
trans_tokenizer.src_lang = "fr"  # 设置源语言为法文

encoded_zh = trans_tokenizer(src_text, return_tensors="pt")
generated_tokens = trans_model.generate(
    **encoded_zh,
    forced_bos_token_id=trans_tokenizer.get_lang_id("zh"),  # 目标语言设为中文
)
translated_text = trans_tokenizer.batch_decode(
    generated_tokens, skip_special_tokens=True
)[0]

print(f"源文本 (法文): {src_text}")
print(f"翻译结果 (中文): {translated_text}")

```

* **M2M100 模型**：由 Meta 推出的首个可以实现任意两种语言之间直接互译（Many-to-Many）的模型，不依赖于将所有语言先翻译成英语作为中转。
* **源语言设定 (`src_lang`)**：在分词前通过 `trans_tokenizer.src_lang = "fr"` 明确告知模型输入的是法文，以便模型在词表和位置编码中启用对应的源语言标识。
* **强制目标语言 (`forced_bos_token_id`)**：在自回归生成（`trans_model.generate`）时，通过 `forced_bos_token_id=trans_tokenizer.get_lang_id("zh")` 强制解码器以“中文（zh）”作为句首起始符（BOS），引导模型将法文翻译成中文。
* **解码输出**：`batch_decode` 将模型生成的 Token ID 序列还原为可读的字符串，并过滤掉特殊控制符号（`skip_special_tokens=True`）。
