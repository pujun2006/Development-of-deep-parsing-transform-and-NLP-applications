Adversarial_Training_embedding.py代码完整复现了多语言词嵌入对齐的核心思想——**基于对抗训练的无监督跨语言词向量对齐（基于 MUSE 框架的简化实现）**。代码通过 PyTorch 搭建了一个生成对抗网络（GAN），在没有任何双语词典或平行语料的前提下，将源语言（如英文）的词向量空间“旋转”并对齐到目标语言（如法文）的词向量空间中。

下面分步骤详细拆解该代码的运行逻辑与背后的技术原理：

---

### Step 1: 模拟数据与 L2 归一化

```python
source_embeddings = np.random.rand(5000, 300)  # 5000 个英文词，300 维
target_embeddings = np.random.rand(5000, 300)  # 5000 个法文词，300 维

# L2 归一化：将词向量模长化为 1
source_embeddings = source_embeddings / np.linalg.norm(
    source_embeddings, axis=1, keepdims=True
)
target_embeddings = target_embeddings / np.linalg.norm(
    target_embeddings, axis=1, keepdims=True
)

```

* **模拟数据**：这里生成了两个随机矩阵，分别代表源语言和目标语言的 5000 个词向量（300维）。在实际应用中，这些矩阵来自 Word2Vec、FastText 等预训练单语词向量。
* **L2 归一化（关键预处理）**：将每个词向量的模长归一化为 1（即落在单位超球面上）。这样做好处有二：
1. 消除了不同语言词频或词向量绝对大小的差异。
2. 归一化后，**余弦相似度（Cosine Similarity）**等价于向量的**内积**（Dot Product），这为后续的矩阵正交变换奠定了良好的几何基础。



---

### Step 2: 定义生成器与判别器

#### 1. 生成器（Generator / 映射矩阵）

```python
class Generator(nn.Module):

  def __init__(self, input_dim):
    super(Generator, self).__init__()
    self.linear = nn.Linear(input_dim, input_dim, bias=False)
    nn.init.eye_(self.linear.weight)  # 初始化为单位矩阵 I

  def forward(self, x):
    return self.linear(x)

```

* **核心角色**：生成器扮演“转换器”的角色，即学习一个线性映射矩阵 $W$。
* **无偏置（`bias=False`）**：对齐操作主要依赖空间旋转和反射，不需要平移。
* **单位矩阵初始化（`nn.init.eye_`）**：将权重矩阵初始化为对角线为 1、其余为 0 的单位矩阵。这意味着训练刚开始时，源空间几乎不变，这给非凸优化提供了一个极佳的起点，能显著加速收敛并防止训练崩塌。

#### 2. 判别器（Discriminator）

```python
class Discriminator(nn.Module):

  def __init__(self, input_dim):
    super(Discriminator, self).__init__()
    self.model = nn.Sequential(
        nn.Linear(input_dim, 128),
        nn.LeakyReLU(0.2),
        nn.Linear(128, 64),
        nn.LeakyReLU(0.2),
        nn.Linear(64, 1),
    )

  def forward(self, x):
    return self.model(x)

```

* **核心角色**：一个多层感知机（MLP），充当“鉴别专家”。它的任务是区分输入的一个词向量究竟是“经过生成器变换后的源语言词向量（假样本）”**还是**“真实的目标语言词向量（真样本）”。
* **无 Sigmoid 激活与 `BCEWithLogitsLoss**`：最后一层不加 Sigmoid，而是输出一个原始 Logits 值。配合 PyTorch 的 `BCEWithLogitsLoss` 使用，数值计算更加稳定，能有效避免因 `log(0)` 导致的 `NaN` 错误。
* **LeakyReLU**：防止标准 ReLU 在负半轴导数为 0 带来的“神经元死亡”问题，有助于对抗训练的梯度流通。

---

### Step 3: 对抗训练过程（核心博弈循环）

整个训练采用标准的 GAN 极小极大优化（Min-Max Optimization），每个 Epoch 包含三个核心步骤：

#### 1. 训练判别器 D

```python
d_optimizer.zero_grad()
fake_target = generator(source_batch)

real_labels = torch.ones(batch_size, 1)  # 真样本标签：1
fake_labels = torch.zeros(batch_size, 1)  # 假样本标签：0

real_loss = criterion(discriminator(target_batch), real_labels)
fake_loss = criterion(discriminator(fake_target.detach()), fake_labels)  # .detach() 切断梯度，防止传给生成器

d_loss = (real_loss + fake_loss) / 2
d_loss.backward()
torch.nn.utils.clip_grad_norm_(
    discriminator.parameters(), max_norm=1.0
)  # 梯度裁剪防爆炸
d_optimizer.step()

```

* 判别器试图把真实目标语言向量判为 `1`，把生成器伪造的向量判为 `0`。
* 注意使用了 `.detach()`，确保在训练判别器时，梯度不会回传污染生成器的参数。

#### 2. 训练生成器 G

```python
g_optimizer.zero_grad()
fake_target = generator(source_batch)
g_loss = criterion(
    discriminator(fake_target), real_labels
)  # 生成器希望判别器把假样本判为 1

g_loss.backward()
torch.nn.utils.clip_grad_norm_(generator.parameters(), max_norm=1.0)
g_optimizer.step()

```

* 生成器的目标是“骗过判别器”——它把生成的假向量输入判别器，但故意将标签设为 `real_labels`（即 `1`）。这样，当判别器认为它是真的时，生成器的损失就会降低。

#### 3. 正交步骤（Safe Orthogonalization）—— 词向量对齐的灵魂

```python
with torch.no_grad():
  W = generator.linear.weight.data
  if not torch.isnan(W).any() and not torch.isinf(W).any():
    try:
      # SVD 分解
      U, S, Vh = torch.linalg.svd(W, full_matrices=False)
      # 强制更新为正交矩阵：W = U * V^T (即 U * Vh)
      generator.linear.weight.data = torch.mm(U, Vh)
    except Exception as e:
      pass

```

* **为什么要做正交化？** 纯粹的 GAN 可能会把向量空间随意扭曲、拉伸或压缩，这会破坏单语词向量内部精妙的几何结构（比如词与词之间的相对夹角）。
* **数学原理（Procrustes 投影）**：通过对权重矩阵 $W$ 进行奇异值分解（SVD），令 $W = U \Sigma V^T$，然后将奇异值全部置为 1（即令 $W = U V^T$）。这样数学上保证了 $W^T W = I$（正交约束）。正交变换**只旋转、不缩放也不扭曲**，完美保护了单语词向量空间的内部结构。

### Step 4: 导出结果与相似度计算

```python
aligned_source_embeddings = generator(source_embeddings).detach().numpy()
target_embeddings_np = target_embeddings.numpy()

similarities = cosine_similarity(
    aligned_source_embeddings, target_embeddings_np
)
print("\n对齐后的前 5 个词对相似度矩阵：")
print(similarities[:5, :5])

```

* 训练结束后，使用训练好的生成器（矩阵 $W$）对整个源语言嵌入矩阵进行一次前向传播，得到 `aligned_source_embeddings`。
* 利用 `sklearn` 的 `cosine_similarity` 计算对齐后的源语言词向量与目标语言词向量之间的相似度矩阵。
* 在真实的双语词典对齐任务中，可以通过在这个相似度矩阵中寻找互为“最近邻（Nearest Neighbor）”或使用 CSLS 指标来抽取互译词对。
