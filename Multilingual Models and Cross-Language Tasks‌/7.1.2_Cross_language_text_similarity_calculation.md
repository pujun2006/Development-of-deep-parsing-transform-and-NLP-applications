Cross_language_text_similarity_calculation.py代码完整展示了跨语言词嵌入对齐中**最经典的监督学习方法：正交普鲁克兹分析（Orthogonal Procrustes Analysis）**。

与之前使用生成对抗网络（GAN）的**无监督对齐**不同，这段代码采用的是**监督对齐**（或称闭式解对齐）。它假设我们已经知道了一组互为翻译的“锚点词对”（在代码中通过索引一一对应的随机矩阵模拟），并利用线性代数中的奇异值分解（SVD）一步到位、数学上完美地求解出最优的正交投影矩阵 $W$。

下面分步骤详细拆解该代码的核心逻辑和数学原理：

---

### Step 1 & 2: 模拟对齐数据与基准评估

```python
np.random.seed(42)
source_embeddings = np.random.randn(100, 300)  # 100个源语言词，300维
target_embeddings = np.random.randn(100, 300)  # 100个目标语言词，300维

# L2 范数归一化
source_embeddings = source_embeddings / np.linalg.norm(
    source_embeddings, axis=1, keepdims=True
)
target_embeddings = target_embeddings / np.linalg.norm(
    target_embeddings, axis=1, keepdims=True
)

# 计算对齐前的平均余弦相似度
initial_sim = np.diag(
    cosine_similarity(source_embeddings, target_embeddings)
).mean()

```

* **L2 归一化**：将每个词向量的模长归一化为 1。归一化后，向量之间的**余弦相似度等价于它们的内积（Dot Product）**，这保证了后续矩阵运算与几何夹角的一致性。
* **基准评估（`initial_sim`）**：由于数据是随机生成的，对齐前互为对应位置的词对（第 $i$ 个源词和第 $i$ 个目标词）的相似度平均值接近于 0。这作为我们衡量对齐效果的**基线（Baseline）**。

---

### Step 3: 正交 Procrustes 算法（核心数学解）

这是整个代码的灵魂所在。我们需要寻找一个正交矩阵 $W$，使得源矩阵 $X$（`src_emb`）乘以 $W$ 后，尽可能接近目标矩阵 $Y$（`tgt_emb`）。

数学优化目标为：


$$\min_{W} \Vert{}WX - Y\Vert{}_F^2 \quad \text{subject to } W^T W = I$$

该问题的最优解（当年由 Schönemann 在 1966 年提出，并在 2017 年被 Mikolov 等人引入 NLP 词向量对齐）可以通过奇异值分解（SVD）直接得到闭式解：

```python
def train_orthogonal_projection(src_emb, tgt_emb):
  # 1. 计算跨语言协方差矩阵 M = X^T * Y
  M = src_emb.T.dot(tgt_emb)

  # 2. 对 M 进行奇异值分解 (SVD)
  U, S, Vh = np.linalg.svd(M)

  # 3. 计算最佳正交映射矩阵 W = U * V^T (其中 Vh 即 V^T)
  projection_matrix = U.dot(Vh)
  return projection_matrix

```

* **协方差矩阵 $M = X^T Y$**：它捕捉了源空间和目标空间中对应词对之间的协同变化关系。
* **SVD 分解（$M = U \Sigma V^T$）**：将协方差矩阵分解为左奇异向量矩阵 $U$、奇异值矩阵 $\Sigma$ 和右奇异向量转置矩阵 $V^T$。
* **$W = U V^T$ 的精妙之处**：如果直接做最小二乘法，得到的矩阵 $W$ 会包含拉伸或压缩（会破坏单语空间内部的几何结构）。而强行丢弃奇异值矩阵 $\Sigma$（即令其变为单位阵），只保留 $U$ 和 $V^T$ 的组合，数学上恰好证明了这就是**满足正交约束（$W^T W = I$）条件下的全局最优解**。它只对空间进行旋转和反射，绝不扭曲词与词之间的相对距离。

---

### Step 4: 验证投影矩阵的正交性

```python
is_orthogonal = np.allclose(W.T.dot(W), np.eye(300))
print(f"Projection Matrix is Orthogonal: {is_orthogonal}")

```

* **正交性检验**：数学上正交矩阵的定义是 $W^T W = I$（单位矩阵）。代码通过 `np.allclose` 检查 $W^T W$ 是否无限接近于 300维的单位矩阵。输出结果通常为 `True`，证明 SVD 解法完美保证了正交性。

---

### Step 5 & 6: 应用投影与效果验证

```python
# 使用投影矩阵对齐源语言嵌入
projected_src = source_embeddings.dot(W)

# 计算对齐后的词对平均余弦相似度
aligned_sim = np.diag(cosine_similarity(projected_src, target_embeddings)).mean()
print(f"Aligned Pairwise Similarity (After Alignment):  {aligned_sim:.4f}")

```

* **坐标变换**：`source_embeddings.dot(W)`（即 $XW$）将整个源语言空间旋转到了目标语言空间中。
* **效果对比**：
* 因为本代码中输入的是纯随机噪声（原本毫无关联），经过正交 Procrustes 强行对齐后，对应位置的相似度指标会从原本接近 0 的数值大幅飙升（在完全随机的数据上甚至能通过矩阵强行拟合到一个较高数值）。
* 在真实的双语词典对齐任务中（例如用真实的英文-法文词典训练 $W$），这一步能够让原本语言不通的词向量空间实现高度重合，词与词之间的跨语言检索准确率（Precision@1）通常能达到 80%~90% 以上。
