# Development-of-deep-parsing-transform-and-NLP-applications

### 第二章：文本预处理与数据增强
### 第三章：基于Transformer的文本分类
### 第四章：依存句法与语义解析
### 第五章：序列标注与命名实体识别
### 第六章：文本生成任务的Transformer实现
### 第七章：多语言模型与跨语言任务
### 第八章：深度剖析注意力机制
### 第九章：文本聚类与BERT主题建模
### 第十章：基于语义匹配的问答系统
### 第十一章：常用模型微调技术
### 第十二章：企业级系统开发（部分）
