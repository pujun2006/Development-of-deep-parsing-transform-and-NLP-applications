Scaled_Dot_Product_Attention.py代码实现的是 Transformer 模型中最核心的机制——**缩放点积注意力机制（Scaled Dot-Product Attention）**。它是论文《Attention Is All You Need》中提出的自注意力（Self-Attention）计算过程的标准 PyTorch 实现。

下面详细拆解这段代码的逻辑和数学原理：

---

### 一、 核心数学公式

代码中实现的核心公式为：


$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

---

### 二、 代码逐段详解

#### 1. 维度设置与张量初始化

```python
batch_size = 2
seq_len = 4
d_k = 64  # 键和查询的维度
d_v = 64  # 值的维度

Q = torch.rand(batch_size, seq_len, d_k)
K = torch.rand(batch_size, seq_len, d_k)
V = torch.rand(batch_size, seq_len, d_v)

```

* **`batch_size = 2`**：批次大小，表示模型同时处理 2 个独立的样本/句子。
* **`seq_len = 4`**：序列长度，表示每个句子包含 4 个词（或 Token）。
* `d_k = 64`, `d_v = 64`：向量维度。Q 和 $K$ 的维度必须相同（都是 `d_k`），以便进行点积计算；V 的维度可以是不同的（这里设为 `d_v = 64`）。
* **`torch.rand`**：生成服从 $[0, 1)$ 均匀分布的随机张量，分别模拟查询矩阵 $Q$、键矩阵 $K$ 和值矩阵 $V$。它们的形状分别为：
* $Q$: `(2, 4, 64)`
* $K$: `(2, 4, 64)`
* $V$: `(2, 4, 64)`



---

#### 2. 计算查询和键的点积（并进行缩放）

```python
scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(torch.tensor(d_k, dtype=torch.float32))

```

* **`K.transpose(-2, -1)`**：将 $K$ 矩阵的最后两个维度进行转置。转置前形状为 `(2, 4, 64)`，转置后形状变为 `(2, 64, 4)`。
* **`torch.matmul(Q, K.transpose(-2, -1))`**：计算 $Q$ 和转置后的 $K$ 的矩阵乘法。
* 形状变化：`(2, 4, 64) × (2, 64, 4) → (2, 4, 4)`。
* 这一步计算出了每个词与其他所有词之间的**相似度得分（Attention Scores）**。


* **除以 $\sqrt{d_k}$（缩放）**：`torch.sqrt(torch.tensor(d_k))` 即 $\sqrt{64} = 8$。
* **为什么需要缩放？** 当维度 $d_k$ 很大时，点积的值会非常大，导致通过 Softmax 后梯度变得极小（梯度消失）。除以 $\sqrt{d_k}$ 可以使方差保持为 1，让训练更稳定。



---

#### 3. Softmax 归一化得到注意力权重

```python
attention_weights = F.softmax(scores, dim=-1)

```

* **`F.softmax(..., dim=-1)`**：对最后一维（即序列长度维度，大小为 4）应用 Softmax 函数。
* 这会将相似度得分转换为**概率分布**（权重和为 1）。对于每个词，它能看出它需要对句子中其他各个词分配多少注意力（权重）。
* `attention_weights` 的形状保持为 `(2, 4, 4)`。

---

#### 4. 对值矩阵进行加权求和

```python
output = torch.matmul(attention_weights, V)

```

* **`torch.matmul(attention_weights, V)`**：用计算好的注意力权重矩阵去乘值矩阵 $V$。
* 形状变化：`(2, 4, 4) × (2, 4, 64) → (2, 4, 64)`。


* **最终含义**：`output` 中的每一行，都是 $V$ 中所有行根据注意力权重进行加权组合后的结果。它融合了上下文信息，代表了结合了全局关联后的新词表示。
