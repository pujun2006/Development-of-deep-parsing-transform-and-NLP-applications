LayerNorm_Res.py代码展示并对比了 PyTorch 中两种不同架构的深度神经网络：**普通前馈神经网络（带有 LayerNorm）** 和 **深度残差网络（Residual Network，带有残差连接与 LayerNorm）**。

这两部分代码的核心目的，是演示如何结合 **层归一化（Layer Normalization）** 和 **残差连接（Residual Connection）** 来构建和训练深度模型。

下面分模块详细拆解：

---

### 第一部分：普通前馈神经网络 (`SimpleModel`)

这部分实现了一个基础的三层全连接网络，并在隐藏层中显式地加入了 **LayerNorm（层归一化）** 和 **ReLU 激活函数**。

#### 1. 模型架构定义

```python
class SimpleModel(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(SimpleModel, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.layer_norm1 = nn.LayerNorm(hidden_dim)  # 第一层的层归一化
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.layer_norm2 = nn.LayerNorm(hidden_dim)  # 第二层的层归一化
        self.fc3 = nn.Linear(hidden_dim, output_dim)

```

* **`nn.LayerNorm(hidden_dim)`**：对每个样本的特征维度进行归一化（使均值为 0，方差为 1）。与 Batch Normalization 不同，LayerNorm 独立于 Batch 大小，在 Transformer 和序列模型中非常常用。

#### 2. 前向传播 (`forward`)

```python
    def forward(self, x):
        x = self.fc1(x)
        x = self.layer_norm1(x)
        x = torch.relu(x)  # 使用ReLU激活函数
        x = self.fc2(x)
        x = self.layer_norm2(x)
        x = torch.relu(x)
        x = self.fc3(x)
        return x

```

* 数据流向：`Linear -> LayerNorm -> ReLU -> Linear -> LayerNorm -> ReLU -> Linear`。
* 注意这里的经典顺序：先通过线性层变换，然后通过 LayerNorm 规范化，最后再送入非线性激活函数 ReLU。

#### 3. 训练与测试

* 使用 `nn.MSELoss()`（均方误差损失）作为回归任务的损失函数。
* 使用 `optim.Adam` 优化器进行 100 轮（Epoch）的梯度下降训练，通过 `loss.backward()` 和 `optimizer.step()` 更新权重。
* 最后用随机生成的测试数据输入模型，打印输出结果。

### 第二部分：深度残差网络 (`DeepResidualNetwork`)

这部分模仿了 ResNet 的核心思想（残差学习），通过引入 **跨层连接（Skip Connection / Residual Connection）** 来解决深层网络可能出现的梯度消失或退化问题。

#### 1. 残差块定义 (`ResidualBlock`)

```python
class ResidualBlock(nn.Module):
    def __init__(self, input_dim):
        super(ResidualBlock, self).__init__()
        self.fc1 = nn.Linear(input_dim, input_dim)
        self.fc2 = nn.Linear(input_dim, input_dim)
        self.layer_norm = nn.LayerNorm(input_dim)

    def forward(self, x):
        # 输入经过第一层全连接层和ReLU激活
        residual = x
        out = torch.relu(self.fc1(x))
        out = self.fc2(out)
        # 加入残差连接，并通过层归一化
        out = self.layer_norm(out + residual)
        return torch.relu(out)

```

* **残差核心逻辑（`out + residual`）**：
* 将输入 `x` 备份到 `residual` 中。
* `x` 经过两层线性变换后得到 `out`。
* 将主干路的输出 `out` 与原始输入 `residual` 直接相加（`out + residual`）。
* **为什么有效？** 即使中间的线性层学不到东西（权重趋近于 0），梯度也可以通过残差边“高速公路”直接回传到上一层，极大地缓解了深层网络的梯度消失问题。



#### 2. 堆叠残差网络 (`DeepResidualNetwork`)

```python
class DeepResidualNetwork(nn.Module):
    def __init__(self, input_dim, output_dim, num_blocks):
        super(DeepResidualNetwork, self).__init__()
        self.blocks = nn.ModuleList([ResidualBlock(input_dim) for _ in range(num_blocks)])
        self.fc_out = nn.Linear(input_dim, output_dim)

    def forward(self, x):
        for block in self.blocks:
            x = block(x)
        return self.fc_out(x)

```

* **`nn.ModuleList`**：用于管理多个相同的 `ResidualBlock`。这里设置了 `num_blocks = 5`，即串联了 5 个残差块。
* 经过这 5 个深度的残差块反复提炼特征后，最后通过一个全连接层 `fc_out` 映射到目标维度 `output_dim`。

#### 3. 训练与测试

* 同样配置了 MSE 损失函数和 Adam 优化器，对 5 层残差网络进行了 100 轮训练，观察 Loss 下降情况并进行前向推理测试。
