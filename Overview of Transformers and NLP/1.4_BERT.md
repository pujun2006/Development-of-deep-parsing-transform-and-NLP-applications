BERT.py代码实现了一个基于 **BERT 预训练模型的文本分类器（Text Classification）**。它展示了如何加载 Hugging Face 提供的预训练 BERT 模型，并在其基础上外接一个全连接层，用来完成具体的分类任务（例如情感分析：判断积极或消极）。

下面分模块详细解析这段代码的实现原理和运行流程。

---

## 一、 定义 BERT 分类模型 (`BERTClassifier`)

这部分代码通过继承 `nn.Module`，构建了一个自定义的文本分类神经网络。

```python
class BERTClassifier(nn.Module):
    def __init__(self, bert_model_name, num_classes):
        super(BERTClassifier, self).__init__()
        self.bert = BertModel.from_pretrained(bert_model_name)
        self.fc = nn.Linear(self.bert.config.hidden_size, num_classes)
        self.dropout = nn.Dropout(0.3)

```

* **`BertModel.from_pretrained(bert_model_name)`**: 加载预训练的 BERT 模型。由于 BERT 是纯编码器架构，它负责提取文本的深层语义特征。
* **`self.fc`**: 分类全连接层。输入维度是 BERT 的隐藏层大小（例如 `bert-base-uncased` 的 `hidden_size` 是 768），输出维度是分类的类别数 `num_classes`（本例中为 2，代表二分类）。
* **`self.dropout(0.3)`**: 随机丢弃 30% 的神经元，用于防止模型在训练时过拟合（Overfitting）。

```python
    def forward(self, input_ids, attention_mask):
        # 1. BERT 模型输出
        outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)

        # 2. 取 [CLS] 标记对应的隐藏状态
        cls_output = outputs.last_hidden_state[:, 0, :]

        # 3. Dropout 和全连接层进行分类
        cls_output = self.dropout(cls_output)
        out = self.fc(cls_output)
        return out

```

* **输入参数**:
* `input_ids`: 文本分词后对应的词汇索引。
* `attention_mask`: 注意力掩码，告诉 BERT 哪些是实际的词，哪些是填充（Padding）的空白。


* **核心亮点 —— 提取 `[CLS]` 标记**：
* BERT 在处理输入文本时，会在句首自动强制插入一个特殊的分类标记 `[CLS]`。
* `outputs.last_hidden_state` 的形状是 `(Batch_Size, Sequence_Length, Hidden_Size)`。
* `[:, 0, :]` 表示**取所有样本的第 0 个位置（即 `[CLS]` 标记）的特征向量**。在 BERT 设计中，这个 `[CLS]` 经过全部数据的交互后，聚合了整句话的全局语义信息，因此常被直接拿来做分类任务。


* **最终输出**：经过 Dropout 和全连接层后，输出形状为 `(Batch_Size, num_classes)` 的未经归一化的得分（Logits）。

## 二、 加载组件与分词器初始化

```python
bert_model_name = "bert-base-uncased"
tokenizer = BertTokenizer.from_pretrained(bert_model_name)
model = BERTClassifier(bert_model_name, num_classes=2)

```

* **`bert-base-uncased`**: 表示使用基础版的、不区分大小写的英文 BERT 模型。
* **`tokenizer`**: 分词器，负责把人类看的文本字符串转换成 BERT 能够理解的数字 ID（Token IDs）。

---

## 三、 输入文本的编码处理

```python
texts = ["This is a positive example.", "This is a negative example."]
encoding = tokenizer(texts, return_tensors='pt', padding=True, truncation=True, max_length=32)

input_ids = encoding['input_ids']
attention_mask = encoding['attention_mask']

```

* **`tokenizer(...)`**: 将两句英文文本转换为张量。
* **关键参数**:
* `return_tensors='pt'`: 返回 PyTorch 张量（PyTorch Tensors）。
* `padding=True`: 自动将较短的句子用填充符补齐，确保它们长度一致。
* `truncation=True`: 如果句子超过最大长度则自动截断。
* `max_length=32`: 限制单句最大长度不超过 32 个 Token。
* **attention_mask说明**:
* attention_mask 就是用来做“屏蔽”的二进制标记：1 代表这是真实的文本内容，模型在计算注意力时要正常关注它；0 代表这是为了对齐而人为填充的空白（Padding），模型在计算注意力时会把它忽略掉（将其权重设为极小值）。在这段代码中，attention_mask 的值全为 1 是因为输入的这两句话经过分词和填充后，长度正好完全一致，没有任何地方需要填充（Padding）。

---

## 四、 模型推理与概率转换

```python
output = model(input_ids, attention_mask)

print("BERT模型输出形状:", output.shape)
print("BERT模型输出:", output)
print("转换为概率：", torch.softmax(output, dim=1))

```

* **`output = model(...)`**: 将处理好的 `input_ids` 和 `attention_mask` 送入模型前向传播。
* 因为批次大小为 2（传入了两句话），类别数为 2，所以输出形状是 **`(2, 2)`**。
* **`torch.softmax(output, dim=1)`**: 原始输出是一堆没有归一化的实数得分（Logits）。通过 Softmax 函数按行（`dim=1`）进行归一化，把它们转换成**和为 1 的概率分布**，方便我们直观判断每句话属于各个类别的概率。
