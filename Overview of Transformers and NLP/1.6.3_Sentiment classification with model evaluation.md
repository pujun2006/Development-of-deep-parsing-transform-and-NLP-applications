Sentiment classification with model evaluation在前几例的基础上，跨越到了一个全新的阶段：**引入了 PyTorch 的标准数据管道（Dataset 与 DataLoader）以及一个完整的“训练-评估（Training & Evaluation）”闭环流程**。

在前几例中，我们处理的都是孤立的样本；而这段代码展示了如何把真实业务中的文本数据集打包成批次（Batch），喂给模型进行训练，最后再切换到验证模式评估模型的效果。

下面逐模块详细解析这段代码的核心实现。

---

## 一、 构建自定义数据集类（`SentimentDataset`）

在 PyTorch 中处理自定义数据，通常需要继承 `torch.utils.data.Dataset` 并实现三个核心方法：

```python
class SentimentDataset(Dataset):

  def __init__(self, texts, labels, tokenizer, max_length=32):
    self.texts = texts
    self.labels = labels
    self.tokenizer = tokenizer
    self.max_length = max_length

  def __len__(self):
    return len(self.texts)  # 返回数据集的总样本数

  def __getitem__(self, idx):
    text = self.texts[idx]
    label = self.labels[idx]
    # 对单条文本进行分词、填充和截断
    encoding = self.tokenizer(
        text,
        truncation=True,
        padding='max_length',
        max_length=self.max_length,
        return_tensors='pt',
    )
    return {
        'input_ids': encoding['input_ids'].flatten(),  # 压平为一维张量
        'attention_mask': encoding['attention_mask'].flatten(),
        'label': torch.tensor(label, dtype=torch.long),  # 类别标签
    }

```

* **`__len__`**：让 PyTorch 知道数据集一共有多少条数据。
* **`__getitem__`**：根据索引 `idx` 获取单条文本和标签，并由分词器将其转换为张量。
* **`.flatten()`**：分词器默认返回的张量带有批次维度（形状如 `(1, max_length)`），通过 `flatten()` 将其降维，方便后续由 `DataLoader` 自动拼成新的批次。

---

## 二、 数据加载器与数据集划分

```python
# 准备数据
texts = ["这个产品真的很好，使用感受非常棒！", "服务态度差，完全不推荐。", "很满意，物流很快。", "质量不行，很失望。"]
labels = [1, 0, 1, 0]  # 1表示积极，0表示消极

# 划分训练集和测试集 (各 2 条样本)
train_texts, val_texts, train_labels, val_labels = train_test_split(
    texts, labels, test_size=0.5, random_state=42
)
train_dataset = SentimentDataset(train_texts, train_labels, tokenizer)
val_dataset = SentimentDataset(val_texts, val_labels, tokenizer)

# 定义数据加载器
train_loader = DataLoader(train_dataset, batch_size=2, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=2)

```

* **`train_test_split`**：利用 Scikit-Learn 将原本的 4 条样本平分为 2 条训练集、2 条验证集。
* **`DataLoader`**：PyTorch 的批次管理器。通过 `batch_size=2`，它会自动把多条样本打包成大小为 2 的 Batch。其中 `train_loader` 设置了 `shuffle=True`（每个 Epoch 随机打乱顺序），防止模型死记硬背样本顺序。

---

## 三、 训练循环（Training Loop）

这部分模拟了一个完整的训练轮次（Epoch）：

```python
model.train()  # 1. 开启训练模式（启用 Dropout）
for batch in train_loader:  # 2. 逐批次读取数据
  input_ids = batch['input_ids']
  attention_mask = batch['attention_mask']
  labels = batch['label']

  optimizer.zero_grad()  # 3. 清空上一轮梯度
  outputs = model(input_ids, attention_mask)  # 4. 前向传播
  loss = loss_fn(outputs, labels)  # 5. 计算带权重的交叉熵损失

  loss.backward()  # 6. 反向传播求梯度
  optimizer.step()  # 7. 更新模型参数
  scheduler.step()  # 8. 更新学习率

  print("训练损失:", loss.item())

```

* 因为 `batch_size=2` 且训练集共 2 条样本，所以这个 `for` 循环只会执行 **1 次**（即处理 1 个 Batch），完成一次完整的参数更新。

---

## 四、 模型评估与推理（Evaluation Mode）

训练完成后，代码进入评估阶段：

```python
model.eval()  # 1. 切换到评估模式（关闭 Dropout）
with torch.no_grad():  # 2. 关闭梯度计算，节省显存和加速计算
  for batch in val_loader:
    input_ids = batch['input_ids']
    attention_mask = batch['attention_mask']
    labels = batch['label']

    outputs = model(input_ids, attention_mask)  # 前向传播获取得分
    predictions = torch.argmax(
        outputs, dim=1
    )  # 3. 取概率最大（得分最高）的类别作为预测结果

    print("真实标签:", labels)
    print("预测结果:", predictions)

```

* **`model.eval()`**：关闭 Dropout 等随机正则化机制，确保模型在验证或测试时的输出稳定、确定。
* **`torch.no_grad()`**：在评估时不需要反向传播，关闭梯度追踪可以大幅减少显存消耗。
* **`torch.argmax(outputs, dim=1)`**：模型输出的是分类得分（Logits），通过 `argmax` 找出每一行中数值最大的那个维度的索引（即预测模型认为它是 0 还是 1），从而与真实标签进行比对。
