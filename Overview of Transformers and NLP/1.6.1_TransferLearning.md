TransferLearning.py代码展示了在真实训练场景中一个非常重要的核心技巧 —— **参数冻结（Freezing Parameters）**、**学习率调度器（Scheduler）** 以及 **单步训练迭代（Training Step）**。

相比于前面单纯的“推理（Inference）”，其模拟了如何让 BERT 真正参与学习和优化。下面逐模块详细解析其实现原理。

---

## 一、 模型层面的升级：参数冻结（Freezing Layers）

```python
class BERTClassifier(nn.Module):
    def __init__(self, bert_model_name, num_classes):
        super(BERTClassifier, self).__init__()
        self.bert = BertModel.from_pretrained(bert_model_name)
        self.fc = nn.Linear(self.bert.config.hidden_size, num_classes)
        self.dropout = nn.Dropout(0.3)

        # 冻结 BERT 前几层
        for param in list(self.bert.parameters())[
            : int(len(list(self.bert.parameters())) * 0.7)
        ]:
            param.requires_grad = False

```

* **为什么要冻结部分参数？**
BERT-Base 拥有 1.1 亿参数。底层的 Transformer 块主要负责提取基础、通用的语言学特征（如词性、基本语法），这些特征在预训练阶段已经学得非常完美了。如果把所有参数都拿来微调，不仅计算慢、容易过拟合，还有可能把预训练好的通用能力“破坏掉”（灾难性遗忘）。
* **代码实现细节**：
* `list(self.bert.parameters())` 获取了 BERT 内部所有的权重参数列表。
* `* 0.7` 计算出前 70% 的参数。
* `param.requires_grad = False` 明确告诉 PyTorch：**在进行反向传播时，这部分参数不需要计算梯度，也不需要更新**。因此，最终只有后 30% 的 BERT 权重以及顶层的全连接层（`self.fc`）会参与训练。

## 二、 优化器与学习率调度器（Optimizer & Scheduler）

```python
# 优化器和学习率调度器
optimizer = optim.AdamW(
    filter(lambda p: p.requires_grad, model.parameters()), lr=2e-5
)
scheduler = get_linear_schedule_with_warmup(
    optimizer, num_warmup_steps=10, num_training_steps=100
)

```

1. **`filter(lambda p: p.requires_grad, model.parameters())`**：
因为我们在前面冻结了 70% 的参数，所以不能把整个模型的参数都交给优化器。这里使用过滤器，**只把那些 `requires_grad=True`（即需要更新的参数）交由 AdamW 优化器管理**。
2. **`get_linear_schedule_with_warmup`（预热与线性衰减调度器）**：
* 在大模型微调中，直接使用固定学习率往往效果不好。
* **Warmup（预热）**：在训练刚开始的前几步（这里是 `num_warmup_steps=10`），让学习率从 0 慢慢爬升到设定的初始学习率（`2e-5`），防止模型初期受到突变大梯度的冲击。
* 随后，学习率会随着训练步数（`num_training_steps=100`）的增加进行线性衰减，帮助模型在后期平稳收敛。



---

## 三、 模拟单步训练循环（Training Step）

代码最后模拟了一次完整的神经网络训练迭代过程（通常在正式训练时，这个过程会放在 `for epoch in range(...)` 的循环中）：

```python
model.train()  # 1. 切换到训练模式（启用 Dropout）
optimizer.zero_grad()  # 2. 清空上一轮遗留的梯度

output = model(input_ids, attention_mask)  # 3. 前向传播：计算输出
loss = nn.CrossEntropyLoss()(
    output, torch.tensor([1, 0])
)  # 4. 计算损失：假设真实标签是 [1, 0]

loss.backward()  # 5. 反向传播：计算所有未冻结参数的梯度
optimizer.step()  # 6. 优化器更新权重
scheduler.step()  # 7. 更新学习率

```

* **`model.train()`**：将模型设置为训练状态，这会激活我们在定义模型时加上的 `nn.Dropout(0.3)`（在推理时 Dropout 会自动关闭）。
* **`optimizer.zero_grad()`**：PyTorch 默认会累加梯度，所以在每次计算新梯度前必须清空旧梯度。
* **`nn.CrossEntropyLoss`**：多分类常用的交叉熵损失函数，用来衡量模型预测的概率分布与真实标签之间的差距。
* **`loss.backward()` 与 `optimizer.step()**`：大模型训练的标准组合拳，根据误差自动调整网络权重，让模型变得更聪明。
