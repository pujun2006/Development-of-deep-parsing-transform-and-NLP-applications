Emotion classification based on BERT.py代码在TransferLearning.py基础上，进一步引入了多项在**实际工业级微调（Fine-tuning）中非常关键的高级优化策略**。相比于前例，它在正则化、学习率策略、分层优化以及类别失衡处理上做出了精细化的调整。

下面逐模块详细解析这段代码的核心升级点。

---

## 一、 模型层面的调整：更强的正则化与放开更多层

```python
class BERTClassifier(nn.Module):
    def __init__(self, bert_model_name, num_classes):
        super(BERTClassifier, self).__init__()
        self.bert = BertModel.from_pretrained(bert_model_name)
        self.dropout = nn.Dropout(0.5)  # 调高了 Dropout 比例
        self.fc = nn.Linear(self.bert.config.hidden_size, num_classes)

        # 冻结比例调整为 50%
        for param in list(self.bert.parameters())[
            : int(len(list(self.bert.parameters())) * 0.5)
        ]:
            param.requires_grad = False

```

1. **`nn.Dropout(0.5)`**：
* 将 Dropout 丢弃率从之前的 `0.3` 提升到了 `0.5`。这意味着在训练时有一半的神经元会被随机屏蔽，强制网络学习更加鲁棒的特征，能更有效地防止模型在小数据集上过拟合。


2. **50% 冻结比例**：
* 相比于TransferLearning.py中冻结 70% 的参数，这里只冻结了前 50% 的参数。这意味着**放开了更多的 BERT 内部层数（特别是靠近顶层的 Transformer 块）**，允许它们根据当前的任务进行更充分的微调。



---

## 二、 核心亮点：分层学习率（Differential Learning Rates）与权重衰减

```python
optimizer = optim.AdamW(
    [
        {
            "params": model.bert.encoder.layer[-2:].parameters(),
            "lr": 1e-5,
        },  # 倒数两层
        {"params": model.fc.parameters(), "lr": 2e-5},  # 分类全连接层
    ],
    weight_decay=1e-4,
)

```

这是大模型微调中最经典、最高级的技巧之一：**不同模块采用不同的学习率（Differential Learning Rates）**。

* **为什么需要分层学习率？**
* BERT 的底层已经学习到了通用的语言学特征，如果用太大的学习率去刷它们，容易导致“灾难性遗忘”（把原本好用的特征破坏掉）。因此，对较浅或中间的层使用较小的学习率（或干脆冻结）。
* 而代码中特意提取了**倒数两层（`model.bert.encoder.layer[-2:]`）**和**顶层分类头（`model.fc`）**，为它们设置了相对大一点的学习率（`1e-5` 和 `2e-5`），让这些最靠近任务输出的层能够更快、更敏锐地适应新任务。


* **`weight_decay=1e-4`（权重衰减 / L2 正则化）**：
在优化器中加入权重衰减，对模型的权重大小进行惩罚，防止某些权重过大而导致模型过于复杂或过拟合。

---

## 三、 学习率调度器：余弦退火与预热（Cosine Schedule with Warmup）

```python
scheduler = get_cosine_schedule_with_warmup(
    optimizer, num_warmup_steps=10, num_training_steps=100
)

```

* 相比于前面用过的“线性衰减调度器”，这里换成了**余弦退火调度器（Cosine Annealing）**。
* **工作曲线**：在预热阶段（Warmup）学习率从 0 平滑上升，而在进入训练主阶段后，学习率会按照**余弦函数的弧形轨迹**缓慢下降至接近于 0。这种曲线在实际训练中能帮助模型更平稳地穿过复杂的损失曲面，通常比线性衰减能取得更好的收敛效果和最终精度。

---

## 四、 应对数据不平衡：带权重的交叉熵损失

```python
loss_fn = nn.CrossEntropyLoss(
    weight=torch.tensor([0.6, 0.4])
)  # 损失权重
loss = loss_fn(output, torch.tensor([1, 0]))

```

* **`weight=torch.tensor([0.6, 0.4])`**：
在真实的业务场景中（如情感分析），正样本和负样本的数量往往是不平衡的。通过在 `CrossEntropyLoss` 中传入 `weight` 参数，可以对不同类别的损失给予**不同的惩罚权重**。
* 这意味着如果某个类别样本较少，模型在预测错该类别时会受到更大的惩罚，从而纠正模型偏向多数类的倾向。
