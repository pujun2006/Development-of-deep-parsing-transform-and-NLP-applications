GPT2.py代码实现的是基于 **GPT-2 预训练模型的文本自动生成（Text Generation）**。它展示了如何给模型输入一段提示词（Prompt），然后让模型发挥“文字接龙”的能力，自动续写一段连贯的故事或文本。

下面分模块详细解析这段代码的实现原理。

---

## 一、 加载 GPT-2 模型和分词器

```python
gpt_model_name = "gpt2"
tokenizer = GPT2Tokenizer.from_pretrained(gpt_model_name)
model = GPT2LMHeadModel.from_pretrained(gpt_model_name)

```

* **`GPT2Tokenizer`**: GPT-2 的分词器，负责把输入的英文文本字符串切分成 Token，并转化为模型能理解的数字 ID（即模型词汇表（Vocabulary）中的索引位置（Index））。
* **`GPT2LMHeadModel`**:
* 前面我们在学 BERT 时用的是 `BertModel`（只负责提取特征）。
* 这里的 **`LMHead`**（Language Modeling Head，语言模型头）意味着该模型在底层 Decoder 的输出之上，外接了一个线性层，能够将隐藏状态直接映射回**整个词表（Vocabulary）中每个词的概率分布**，从而实现“预测下一个词”的生成能力。



---

## 二、 输入文本编码

```python
input_text = "Once upon a time in a distant land,"
input_ids = tokenizer.encode(input_text, return_tensors='pt')

```

* **提示词（Prompt）**：`"Once upon a time in a distant land,"`（从前在一个遥远的土地上，）。
* **`tokenizer.encode`**：将这段文本转换成对应的数字张量（Tensor），形状通常是 `(1, Sequence_Length)`，这里的 `return_tensors='pt'` 指定返回 PyTorch 张量。

---

## 三、 核心生成函数：`model.generate` 与采样超参数

这是整个代码最核心的部分。GPT-2 在生成文本时，不仅是选概率最高的那一个词，而是通过一套复杂的采样策略（Sampling Strategy）来控制生成的质量和创造力。

```python
output_sequences = model.generate(
    input_ids=input_ids,
    max_length=50,  # 设置生成文本的最大长度
    num_return_sequences=1,  # 返回的生成序列数
    no_repeat_ngram_size=2,  # 防止生成重复的短语
    top_k=50,  # 限制每次生成的单词数量
    top_p=0.95,  # 采用nucleus sampling
    temperature=0.7,  # 控制生成文本的随机性
)

```

各项关键参数的含义如下：

1. **`max_length=50`**：限制生成的总长度（包括输入的提示词在内一共 50 个 Token）。也就是说，模型最多再续写几十个词就会停下。
2. **`num_return_sequences=1`**：告诉模型这次只生成 1 个版本的续写结果。
3. **`no_repeat_ngram_size=2`**：**防重复机制**。强制规定任何长度为 2 的词组（N-gram）不能在文本中重复出现，防止模型陷入类似“and the and the and the”的死循环。
4. **`top_k=50`**：在每一步预测下一个词时，模型会把词表中所有词按概率从高到低排序，**只保留概率最高的前 50 个词**，把其他概率极低的奇奇怪怪的词直接过滤掉，确保语义通顺。
5. **`top_p=0.95`（核采样 / Nucleus Sampling）**：一种更动态的过滤机制。它会将候选词的概率从大到小累加，当累加概率达到 95%（0.95）时截断，剩下的词直接抛弃。这让模型在保持高概率的同时，兼顾了一定的多样性。
6. **`temperature=0.7`（温度系数）**：控制生成文本的“随机性”或“创造力”。
* 温度越低（如 0.2），概率高的词被选中的概率会被无限放大，生成的内容更死板、更确定。
* 温度越高（如 1.2），词与词之间的概率差距被拉平，模型会变得更有想象力，但有时也会胡言乱语。这里设为 `0.7` 是一个比较均衡、适合讲故事的参数。



---

## 四、 解码与结果输出

```python
generated_text = tokenizer.decode(
    output_sequences[0], skip_special_tokens=True
)

print("GPT模型生成的文本:")
print(generated_text)

```

* **`output_sequences[0]`**：`generate` 函数返回的是包含输入和生成结果的完整数字序列，这里取出第 0 条。
* **`tokenizer.decode(...)`**：把一串冷冰冰的数字 ID 逆向还原成人类看得懂的英文文本字符串。
* **`skip_special_tokens=True`**：在解码时，自动过滤掉文本中可能包含的诸如 `<|endoftext|>` 等特殊控制符号，让输出更加干净整洁。
