Syntax structure extraction and analysis.py代码是对前一个示例的升级版。它使用了经典英文全字母句（Pangram）`"The quick brown fox jumps over the lazy dog."`，不仅展示了基础的依存关系遍历，还引入了 **Displacy 可视化工具** 以及对嵌套结构（如名词短语内部修饰语）的深度提取。

下面详细拆解这段代码的核心逻辑与功能：

---

### 一、 初始化与模型加载

```python
import spacy
from spacy import displacy

# 加载SpaCy的语言模型
nlp = spacy.load("en_core_web_sm")

# 示例句子
text = "The quick brown fox jumps over the lazy dog."

# 处理文本，生成依存关系树
doc = nlp(text)

```

1. **`from spacy import displacy`**：导入 spaCy 专门用于可视化语法树的模块。
2. **`nlp = spacy.load("en_core_web_sm")`**：加载英文小型预训练模型。
3. **`doc = nlp(text)`**：处理这句经典的英语全字母句（包含了26个字母），完成分词、词性标注和依存句法分析。

---

### 二、 基础依存关系全景输出

```python
print("Token\tDependency\tHead\tChildren")
for token in doc:
    print(f"{token.text}\t{token.dep_}\t{token.head.text}\t{[child.text for child in token.children]}")

```

* 这一段代码与之前类似，遍历句中的每一个词，以表格化的方式打印出：
* **`Token`**：当前词。
* **`Dependency`**：依存标签。
* **`Head`**：中心词（父节点）。
* **`Children`**：子节点列表。



---

### 三、 使用 Displacy 可视化依存关系树

```python
# 使用displacy可视化依存关系树
print("\nRendering dependency tree visualization...")
displacy.render(doc, style="dep", jupyter=False, options={'distance': 90})

```

* **`displacy.render()`**：spaCy 的核心可视化函数。
* **`style="dep"`**：指定渲染类型为依存关系树（Dependency Tree）。
* **`jupyter=False`**：表示当前代码是在普通 Python 脚本（非 Jupyter Notebook）环境中运行。此时它会输出一段 HTML/SVG 源码，或者在支持的浏览器/环境中自动生成可视化图表。
* **`options={'distance': 90}`**：设置节点之间的间距为 90 像素，让生成的依存树图表更加舒展、易于阅读。

---

### 四、 核心句法角色与修饰关系识别

```python
print("\nIdentifying syntactic roles:")
for token in doc:
    # 提取主语、谓语、宾语
    if token.dep_ in {"nsubj", "ROOT", "dobj"}:
        print(f"{token.text} ({token.dep_}) <- {token.head.text} ({token.head.dep_})")
    # 提取修饰语
    elif token.dep_ in {"amod", "advmod", "prep", "pobj"}:
        print(f"{token.text} ({token.dep_}) modifies -> {token.head.text} ({token.head.dep_})")

```

* 通过条件分支筛选出句子的骨干结构：
* **`nsubj`**（主语）：`fox` ⬅️ 指向 `jumps`。
* **`ROOT`**（根节点/谓语）：`jumps`。
* `amod` / `prep` / `pobj`等：用于捕捉形容词修饰（如 `quick`、`brown`、`lazy`）以及介词结构（如 `over` 和 `dog`）。



---

### 五、 进一步提取复杂嵌套结构（对象与其修饰语）

```python
print("\nExtracting objects and their modifiers:")
for token in doc:
    if token.dep_ == "dobj":
        print(f"Object: {token.text}")
        for child in token.children:
            if child.dep_ in {"amod", "det"}:
                print(f"  Modifier: {child.text}")

```

* **逻辑意图**：这段代码旨在寻找句中的**直接宾语（`dobj`）**，并进一步向下遍历这个宾语的子节点（Children），找出修饰它的形容词（`amod`）或限定词（`det`，如 `the`, `a`）。
* **💡 代码小贴士（针对本句的实际输出）**：
在这句示例 *"The quick brown fox jumps over the lazy dog."* 中，动词 `jumps` 后面跟的是介词短语 `over the lazy dog`，其中的 `dog` 是介词的宾语（`pobj`），而不是直接宾语（`dobj`）。因此，在运行该循环时，`token.dep_ == "dobj"` **在当前句子中不会被触发**。
如果想在当前句子中测试这个嵌套提取逻辑，可以将 `if token.dep_ == "dobj":` 改为 `if token.dep_ in {"dobj", "pobj"}:`，这样就能成功提取出 `dog` 的修饰词（`the` 和 `lazy`）了。
