BERT_GNN_2.py代码将前一个简单的函数式脚本重构为了一个**模块化、面向对象的完整 PyTorch 模型架构**。

整个代码展示了如何将 **BERT（Transformer）特征提取** 与 **GNN（图神经网络）结构蒸馏** 完美封装进一个端到端的 PyTorch `nn.Module` 中。

---

### 一、 核心改进与设计亮点

1. **国内镜像源配置 (`os.environ`)**：
```python
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"

```



```

2. **面向对象的模块化封装 (`BertGNNModel`)**：
   前一段代码是平铺直叙的函数调用，而这段代码将其封装为了一个标准的 PyTorch 模型类。它组合了 `bert_model` 和 `gnn_layer`，符合现代深度学习工程规范，便于后续进行端到端的联合训练（Training）、反向传播（Backward）和模型保存。

3. **动态长度适配 (`seq_len`)**：
   更换了输入句子（`"The quick brown fox jumps over the lazy dog"`），并使用 `tokens['input_ids'].shape[1]` **动态获取实际的 Token 数量（11个，包含 `[CLS]` 和 `[SEP]`）**，使图的构建与输入文本严格对齐，具备极强的泛用性。

### 二、 逐段详细拆解

#### 1. 初始化与分词
```python
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
bert_model = BertModel.from_pretrained('bert-base-uncased')

text = "The quick brown fox jumps over the lazy dog"
tokens = tokenizer(text, return_tensors='pt', padding=True)

```

* **分词结果**：包含 9 个英文单词，加上句首的 `[CLS]` 和句尾的 `[SEP]`，总共产生 **11 个 Token**。`tokens` 字典中包含了 `input_ids` 和 `attention_mask`。

#### 2. 自定义 GNN 层 (`GNNLayer`)

```python
class GNNLayer(nn.Module):

  def __init__(self, in_features, out_features):
    super(GNNLayer, self).__init__()
    self.linear = nn.Linear(in_features, out_features)

  def forward(self, node_features, adj_matrix):
    # 消息聚合：(N, N) * (N, in_features) -> (N, in_features)
    aggregated = torch.matmul(adj_matrix, node_features)
    return torch.relu(self.linear(aggregated))

```

* **邻居聚合**：`torch.matmul(adj_matrix, node_features)` 利用矩阵乘法，将邻接矩阵中定义的邻居节点特征加权求和，汇总到当前节点。
* **特征降维与激活**：通过线性层（`768 -> 128`）和 ReLU 激活函数，输出更新后的高维语义-结构融合表示。

#### 3. 组合模型类 (`BertGNNModel`)

```python
class BertGNNModel(nn.Module):

  def __init__(self, bert_model, gnn_layer):
    super(BertGNNModel, self).__init__()
    self.bert = bert_model
    self.gnn = gnn_layer

  def forward(self, input_ids, attention_mask, adj_matrix):
    # 1. 动态获取 BERT 输出特征: (1, seq_len, 768)
    outputs = self.bert(input_ids=input_ids, attention_mask=attention_mask)
    token_embeddings = outputs.last_hidden_state.squeeze(0)  # (seq_len, 768)

    # 2. 通过 GNN 更新节点特征: (seq_len, 128)
    gnn_output = self.gnn(token_embeddings, adj_matrix)
    return gnn_output

```

* **前向传播逻辑**：
1. 输入送入 BERT，获取包含上下文信息的稠密特征张量。
2. 去除批次维度后，得到形状为 `(11, 768)` 的节点特征矩阵。
3. 将节点特征矩阵与构建好的 `adj_matrix` 一起输入 GNN 层，注入句法拓扑偏置，最终输出 `(11, 128)` 的融合特征。



#### 4. 动态图构建与邻接矩阵初始化

```python
seq_len = tokens['input_ids'].shape[1]  # 11

G = nx.DiGraph()
edges = [(i, i + 1) for i in range(seq_len - 1)]  # 10 条链式边
G.add_edges_from(edges)

adj_matrix = nx.adjacency_matrix(G).todense()
adj_matrix = torch.FloatTensor(adj_matrix)

# 添加自环 (Self-loop)
adj_matrix += torch.eye(seq_len)

```

* 自动生成一个 `11 × 11` 的邻接矩阵。
* `+ torch.eye(seq_len)` 确保每个 Token 在进行邻居聚合时，也能完整保留自身的 BERT 特征，防止信息被稀释或抹杀。

#### 5. 实例化并执行前向传播

```python
gnn_layer = GNNLayer(in_features=768, out_features=128)
model = BertGNNModel(bert_model, gnn_layer)

gnn_output = model(
    input_ids=tokens['input_ids'],
    attention_mask=tokens['attention_mask'],
    adj_matrix=adj_matrix,
)

```

* 实例化混合模型，传入张量进行前向推断，最终输出尺寸完美匹配：`torch.Size([11, 128])`。
