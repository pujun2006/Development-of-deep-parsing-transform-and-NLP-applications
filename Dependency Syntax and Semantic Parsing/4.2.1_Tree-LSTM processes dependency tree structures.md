Tree-LSTM processes dependency tree structures.py代码实现了一个基于 PyTorch 的 **Child-Sum Tree-LSTM（子节点求和树形长短期记忆网络）**。它是标准线性 LSTM 在树状结构（如依存句法树）上的自然扩展，能够将任意分叉的树结构自底向上地编码为一个固定维度的向量。

代码主要由三个核心类和一个测试示例组成，以下进行逐层详细拆解：

---

### 一、 `TreeNode` 类：树结构的基础数据单元

这部分定义了树的节点结构，用于手动或通过解析器构建依存句法树。

```python
class TreeNode:

  def __init__(self, word_idx):
    self.word_idx = word_idx  # 词在词表中的索引（Vocabulary Index）
    self.children = []  # 存储子节点的列表（支持任意多个子节点）

  def add_child(self, child):
    self.children.append(child)

  def is_leaf(self):
    return len(self.children) == 0  # 判断是否为叶子节点（没有子节点）

```

* **作用**：模拟语言学中的句法树节点。每一个节点保存了一个词的索引 (`word_idx`) 和它的所有子节点指针 (`children`)。

---

### 二、 `TreeLSTMCell` 类：核心状态转移计算

这是 Child-Sum Tree-LSTM 的核心计算单元。它接收当前节点的输入词向量，以及**所有子节点**传上来的隐状态 (`child_h`) 和记忆单元 (`child_c`)，计算出当前节点的最新状态。

#### 1. 初始化 (`__init__`)

```python
self.W_i = nn.Linear(input_dim, hidden_dim)  # 输入门对当前输入的权重
self.U_i = nn.Linear(hidden_dim, hidden_dim)  # 输入门对子节点总和的权重
# 同理定义了遗忘门 (W_f, U_f)、输出门 (W_o, U_o) 和候选记忆单元 (W_u, U_u)

```

* **注意**：Child-Sum 的特点在于：
* **输入门、输出门、候选记忆**：它们对子节点信息的感知是通过**所有子节点隐状态之和**（$\sum h_k$）来获取的。
* **遗忘门**：对**每个子节点**单独计算（因为每个子节点有不同的遗忘程度）。



#### 2. 前向传播 (`forward`)

```python
def forward(self, x, child_h, child_c):
  # 1. 聚合所有子节点的隐状态之和: (1, hidden_dim)
  child_h_sum = torch.sum(child_h, dim=0)

  # 2. 计算输入门 i、输出门 o、候选记忆 u（基于当前输入 x 和子节点隐状态总和）
  i = torch.sigmoid(self.W_i(x) + self.U_i(child_h_sum))
  o = torch.sigmoid(self.W_o(x) + self.U_o(child_h_sum))
  u = torch.tanh(self.W_u(x) + self.U_u(child_h_sum))

  # 3. 对每个子节点分别计算遗忘门 f，并与对应的子节点记忆细胞 c 相乘后累加
  f_list = []
  for h in child_h:
    f = torch.sigmoid(self.W_f(x) + self.U_f(h))
    f_list.append(f)

  f_c_sum = torch.sum(
      torch.stack([f * c for f, c in zip(f_list, child_c)]), dim=0
  )

  # 4. 更新当前节点的记忆单元 c 和隐状态 h
  c = i * u + f_c_sum
  h = o * torch.tanh(c)

  return h, c

```

* **数学原理对应**：
* 聚合了子节点信息的求和项对应了公式中的 $\sum_{k \in K(j)} h_k$。
* 记忆细胞更新公式：$c_j = i_j \odot \tilde{c}_j + \sum_{k \in K(j)} f_{jk} \odot c_k$。

### 三、 `TreeLSTM` 类：递归遍历与特征提取

该类管理词嵌入层（Embedding）和 Cell 单元，并通过递归方式从树的叶子节点一直计算到根节点。

```python
class TreeLSTM(nn.Module):

  def __init__(self, vocab_size, embedding_dim, hidden_dim):
    super(TreeLSTM, self).__init__()
    self.embedding = nn.Embedding(vocab_size, embedding_dim)
    self.cell = TreeLSTMCell(embedding_dim, hidden_dim)
    self.hidden_dim = hidden_dim

  def forward(self, tree):
    h, c = self.recursive_forward(tree)
    return h  # 返回根节点的隐状态作为整棵树的全局表示

  def recursive_forward(self, node):
    # 将当前节点的 word_idx 转为张量并获取词嵌入 x，形状为 (1, embedding_dim)
    node_idx_tensor = torch.tensor([node.word_idx], dtype=torch.long)
    x = self.embedding(node_idx_tensor)

    if node.is_leaf():
      # 递归终止条件（叶子节点）：没有子节点，初始化全 0 的占位张量
      child_h = torch.zeros(1, 1, self.hidden_dim)
      child_c = torch.zeros(1, 1, self.hidden_dim)
    else:
      # 非叶子节点：递归计算所有子节点的 (h, c)
      child_h_list, child_c_list = [], []
      for child in node.children:
        h, c = self.recursive_forward(child)
        child_h_list.append(h)
        child_c_list.append(c)

      # 将子节点的列表堆叠并调整形状为 (num_children, 1, hidden_dim)
      child_h = torch.stack(child_h_list, dim=0).squeeze(1)
      child_c = torch.stack(child_c_list, dim=0).squeeze(1)

    # 调用 Cell 计算当前节点的隐状态并返回
    return self.cell(x, child_h, child_c)

```

* **自底向上（Bottom-Up）递归**：`recursive_forward` 采用深度优先搜索（DFS）的思想。
1. 如果遇到叶子节点，由于它没有子代，直接赋零向量。
2. 如果是中间节点，会先递归计算完它的所有子节点，把子节点的隐状态 `stack` 起来，再传给 `TreeLSTMCell` 融合成当前节点的隐状态。

### 四、 示例执行过程

代码最后构建了一个简单的树结构并进行了测试：

```text
       root (词索引 0)
      /    \
  child1  child2 (词索引 2)
    |
  child3 (词索引 3)

```

1. **构建结构**：`root` 有两个子节点 `child1` 和 `child2`；`child1` 有一个子节点 `child3`。
2. **计算顺序**：
* 先计算叶子节点 `child3`（其子节点为空，用全 0 处理）。
* 接着计算 `child1`（它的子节点是 `child3`）。
* 然后计算 `child2`（叶子节点，用全 0 处理）。
* 最后计算 `root`（它的子节点是 `child1` 和 `child2`）。


3. **输出**：整棵树从叶子到根层层汇聚，最终输出 `root` 节点的隐状态向量（形状为 `[1, 100]`），这个向量完整融合了整棵句法树的结构与语义信息。
