Data_multi_labeling_processing.py代码是一个使用 Python 的 `sentence-transformers` 库和 `scikit-learn` 库实现语义匹配（Semantic Textual Similarity, STS）任务的完整端到端示例。

它展示了如何将文本转化为向量（Embeddings）、计算向量间的余弦相似度，并将结果与标注标签（Label）进行对照。

下面对这段代码进行逐模块的**详细拆解与说明**：

---

### 一、 核心模块功能拆解

#### 1. 模拟数据集构建 (`pd.DataFrame`)

```python
data = {
    "text1": [...],
    "text2": [...],
    "label": [2, 2, 1, 1, 0] # 2=高度相似, 1=部分相似, 0=不相似
}
df = pd.DataFrame(data)

```

* **目的**：构建一个包含文本对（`text1` 和 `text2`）及人工标注标签（`label`）的结构化数据集。
* **数据特点**：模拟了真实业务中的多级相关性标注体系（前面讨论的 0、1、2 分值）。

#### 2. 数据集切分 (`train_test_split`)

```python
train_df, test_df = train_test_split(df, test_size=0.3, random_state=42)

```

* **目的**：利用 `scikit-learn` 将数据集划分为**训练集**（Train）和**测试集**（Test）。`test_size=0.3` 表示 30% 的数据划为测试集，`random_state=42` 确保每次运行划分结果一致。

#### 3. 模型加载 (`SentenceTransformer`)

```python
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

```

* **目的**：加载一个预训练的**多语言双塔模型（Bi-Encoder）**。
* **模型特点**：`paraphrase-multilingual-MiniLM-L12-v2` 支持包括中文在内的 50 多种语言，能够将任意长度的句子映射为高维密集向量（Embedding），并在向量空间中保持语义相近的句子距离更近。

#### 4. 逐对相似度计算核心函数 (`compute_paired_similarity`)

这是整段代码的核心逻辑，用于计算对应文本对之间的语义相似度：

```python
def compute_paired_similarity(df):
    # 1. 编码：分别将 text1 和 text2 转换为 PyTorch 张量向量
    embeddings_text1 = model.encode(df["text1"].tolist(), convert_to_tensor=True)
    embeddings_text2 = model.encode(df["text2"].tolist(), convert_to_tensor=True)

    # 2. 计算余弦相似度
    cosine_scores = util.pairwise_cos_sim(embeddings_text1, embeddings_text2)
    
    # 3. 转换回 NumPy 格式以便放入 DataFrame
    return cosine_scores.cpu().numpy()

```

* **双塔分离编码**：`model.encode()` 分别对 `text1` 列和 `text2` 列独立进行向量化，这是典型的双塔模型（Bi-Encoder）架构，具备极高的检索和计算效率。
* **`util.pairwise_cos_sim` 的优势**：
* 如果用普通的 `util.cos_sim(A, B)`，会计算一个 $N \times N$ 的全量交叉相似度矩阵（矩阵中第 $i$ 行第 $j$ 列代表 `text1[i]` 和 `text2[j]` 的相似度）。
* 而 `util.pairwise_cos_sim` 直接计算逐行对应（Pair-wise）的相似度（即只计算 `text1[i]` 与 `text2[i]` 的相似度），返回一个一维张量，避免了不必要的矩阵对角线提取操作（如代码注释中注释掉的 `torch.diag` 方案）。



#### 5. 结果整合与输出

```python
train_df = train_df.copy()
test_df = test_df.copy()

train_df["pred_similarity"] = compute_paired_similarity(train_df)
test_df["pred_similarity"] = compute_paired_similarity(test_df)

print("--- 训练集评估结果 ---")
print(train_df[["text1", "text2", "label", "pred_similarity"]])
...

```

* `.copy()`：防止触发 Pandas 的 `SettingWithCopyWarning` 警告。
* 将计算出的相似度分数值赋给新列 `pred_similarity`，并打印展示，方便我们直观比对模型预测分值（连续的浮点数，如 0.0 ~ 1.0）**与**人工标注标签（离散值 0, 1, 2）之间的对齐程度。

### 三、 代码背后的业务意义与局限性

1. **零样本（Zero-shot）推理**：
这段代码**没有经过任何训练集微调（Fine-tuning）**，直接使用了预训练好的模型开箱即用。
2. **分值映射思考**：
* 模型的 `pred_similarity` 输出通常在 `[-1, 1]` 或 `[0, 1]` 之间（余弦相似度）。
* 人工标签 `label` 是离散的 `[0, 1, 2]`。在实际项目中，如果想用模型替代人工或辅助排序，通常需要设定**阈值（Thresholds）**（例如：相似度 $> 0.8$ 判为标签 2，$0.5 \sim 0.8$ 判为 1，$< 0.5$ 判为 0）或使用回归/分类损失函数对模型进行有监督微调。
