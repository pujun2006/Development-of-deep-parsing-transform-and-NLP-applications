semantic_similarity.py代码是一个基于 Python 和 `sentence-transformers` 库的完整实战示例，展示了**如何使用句子嵌入（Sentence Embedding）计算一组中文句子的语义相似度，并找出与每个句子最相似的其他句子**。

以下是对代码各个核心部分的逐行详细说明：

---

### 一、 核心模块导入与模型加载

```python
import torch
from sentence_transformers import SentenceTransformer, util

# 加载支持多语言的句子嵌入模型
model = SentenceTransformer('paraphrase-multilingual-MiniLM-L12-v2')

```

* **`SentenceTransformer`**：这是 Hugging Face `transformers` 库之上的一个高级封装，专门用于高效生成句子级别的稠密向量。
* **`paraphrase-multilingual-MiniLM-L12-v2`**：这是一个轻量且高效的多语言模型（支持中文、英文等 50 多种语言）。它能将不同语言但含义相近的句子映射到同一个向量空间中，非常适合跨语言检索和中文语义相似度计算。
* **`util`**：`sentence-transformers` 内置的工具箱，提供了计算余弦相似度、点积等常用数学运算的便捷函数。

---

### 二、 准备文本数据与向量化

```python
# 定义一组句子用于计算相似度
sentences = [
    "机器学习是人工智能的一个重要分支。",
    "人工智能包含机器学习和深度学习技术。",
    "今天的天气很好，适合外出游玩。",
    "下周的天气可能会下雨。"
]

# 将句子转化为嵌入向量
embeddings = model.encode(sentences, convert_to_tensor=True)

```

* **`sentences`**：包含 4 个句子的列表。其中前两句在语义上紧密相关（都涉及人工智能和机器学习），后两句在语义上相关（都涉及天气）。
* **`model.encode(...)`**：将文本列表输入深度学习模型，批量转换为高维稠密向量。
* **`convert_to_tensor=True`**：将输出结果直接转换为 PyTorch 的 Tensor（张量格式），以便后续能够直接调用 PyTorch 的高效计算函数。

---

### 三、 计算相似度矩阵

```python
# 计算余弦相似度矩阵
cosine_similarities = util.pytorch_cos_sim(embeddings, embeddings)

# 打印余弦相似度矩阵
print("句子间余弦相似度矩阵：")
print(cosine_similarities)

```

* **`util.pytorch_cos_sim(embeddings, embeddings)`**：计算矩阵与自身（即所有句子两两之间）的余弦相似度。
* **输出结果**：会得到一个 $4 \times 4$ 的相似度矩阵。
* 对角线上的值通常为 1.0（因为句子和自身的夹角为 0，余弦值为 1）。
* 矩阵中的非对角线元素代表第 $i$ 个句子与第 $j$ 个句子的语义相似度得分（范围通常在 $[-1, 1]$ 之间，正数代表正相关，值越大语义越相似）。



---

### 四、 编写函数并实现相似句子检索

```python
# 定义函数来获取最相似的句子
def find_most_similar(sentence_idx, sentences, cosine_similarities, top_n=3):
    """
    输出与指定句子最相似的句子及其相似度。
    """
    similarities = cosine_similarities[sentence_idx]
    top_results = torch.topk(similarities, k=top_n + 1)  # 包含自身

    print(f"\n与句子 '{sentences[sentence_idx]}' 最相似的句子:")
    for idx, score in zip(top_results.indices[1:], top_results.values[1:]):  # 跳过自身
        print(f"句子: {sentences[idx]}, 相似度: {score:.4f}")

```

* **`similarities = cosine_similarities[sentence_idx]`**：提取出当前目标句子与其他所有句子的相似度得分向量。
* **`torch.topk(..., k=top_n + 1)`**：PyTorch 的高效函数，用于找出得分最高的前 $k$ 个元素。
* 这里 `k = top_n + 1` 是因为相似度最高的一定是句子本身（相似度为 1.0）。


* **`top_results.indices[1:]` 与 `top_results.values[1:]**`：通过切片 `[1:]` **跳过第一项（即自身）**，只保留排名前列的其它邻近句子及其对应的相似度得分。

---

### 五、 循环展示结果

```python
# 展示每个句子最相似的句子
for i in range(len(sentences)):
    find_most_similar(i, sentences, cosine_similarities)

```

* 这段代码遍历所有句子，依次调用上面定义好的函数，最终在控制台打印出每个句子在语料库中最匹配的其他句子。
* **预期输出效果**：当输入关于“机器学习”的句子时，模型能够识别出另一句关于“人工智能”的句子与其相似度最高；而当输入“天气”相关的句子时，也会精准匹配到另一句关于天气的句子，体现了语义嵌入不受字面差异限制的优势。
