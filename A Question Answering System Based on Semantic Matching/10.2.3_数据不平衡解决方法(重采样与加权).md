在机器学习、数据挖掘以及自然语言处理（如不平衡文本分类、语义匹配中的负样本过多等）任务中，数据不平衡（Data Imbalance）是一个非常常见且棘手的问题。当正负样本比例严重失调（例如 99:1 或 1000:1）时，模型往往会倾向于预测多数类，导致对少数类的识别能力极差。

解决数据不平衡的核心手段主要分为两大流派：**重采样（Resampling）**与**加权（Weighting / 成本敏感学习）**。以下是这两种方法的详细说明与实践指南。

---

## 一、 重采样方法（Resampling Methods）

重采样是在**数据层面**通过人为调整训练集中各类样本的数量，使其恢复平衡。它主要分为欠采样、过采样以及混合采样。

### 1. 欠采样（Undersampling / 降采样）

* **核心思想**：减少多数类（Majority Class）的样本数量，使其与少数类（Minority Class）的数量相匹配。
* **常用方法**：
* **随机欠采样（Random Undersampling）**：随机丢弃多数类样本。
* *优点*：简单直接，显著减少训练数据量，大幅缩短模型训练时间。
* *缺点*：会丢失多数类中的重要信息，可能导致模型欠拟合。


* **Tomek Links（托梅克链接）**：寻找不同类别中距离最近的一对样本（即边界处的“敌人”），如果它们互为最近邻，则删除多数类样本。这能有效清洗决策边界附近的噪声。
* **Edited Nearest Neighbors (ENN)**：检查多数类样本的 K 个近邻，如果其多数近邻属于少数类，则将该多数类样本剔除。


* **适用场景**：多数类样本极其庞大、计算资源有限、且多数类包含大量冗余数据时。

### 2. 过采样（Oversampling / 上采样）

* **核心思想**：增加少数类（Minority Class）的样本数量，或通过算法合成新的少数类样本。
* **常用方法**：
* **随机过采样（Random Oversampling）**：随机复制少数类样本。
* *优点*：不丢失信息。
* *缺点*：容易导致模型过拟合（Overfitting），因为完全相同的样本被反复学习。


* **SMOTE（Synthetic Minority Over-sampling Technique，合成少数类过采样技术）**：
* *原理*：不直接复制，而是通过计算少数类样本之间的特征距离，在特征空间中利用线性插值**随机合成**新的少数类样本。
* *步骤*：对每个少数类样本 $x$，通过 KNN 算法找到其 $K$ 个近邻；随机选择一个近邻 $x_{n}$；在 $x$ 和 $x_{n}$ 之间的连线上随机选择一点作为新样本。


* **ADASYN（Adaptive Synthetic）**：与 SMOTE 类似，但它根据学习难度自适应地为更难学（即周边多数类样本更多）的少数类样本生成更多合成点。


* **适用场景**：少数类样本极少（如罕见病诊断、欺诈检测），直接丢弃多数类损失太大的情况。

### 3. 混合采样（Hybrid Sampling）

* **核心思想**：结合过采样与欠采样。
* **经典组合**：**SMOTE + Tomek Links** 或 **SMOTE + ENN**。
* 先用 SMOTE 生成少数类样本，解决信息不足的问题；
* 再用 Tomek Links 或 ENN 清洗边界处因合成而产生的噪声和重叠样本，使决策边界更加清晰。



> **⚠️ 重采样工程红线**：
> 无论是过采样还是欠采样，**必须在划分训练集（Train Set）之后、在训练集内部进行**。绝对不能对整个数据集（包括验证集和测试集）进行重采样，否则会导致严重的**数据泄露（Data Leakage）**，使模型在测试集上的评估结果严重失真。

## 二、 加权方法（Weighting / 成本敏感学习）

与重采样改变数据分布不同，加权方法（Cost-Sensitive Learning）**在**算法层面（损失函数）入手，不改变原始数据，而是通过赋予不同类别不同的错分惩罚权重来解决不平衡。

### 1. 类别权重调整（Class Weights）

在计算损失函数（Loss Function）时，对少数类的样本错误预测施加更高的惩罚。

* **核心逻辑**：如果少数类的样本数量是多数类的 $\frac{1}{10}$，那么当模型将少数类预测错时，其带来的 Loss 应该是多数类错分 Loss 的 10 倍。
* **数学表达（以交叉熵损失为例）**：

$$\text{Loss} = - \sum_{i} w_{y_i} y_i \log(\hat{y}_i)$$



其中 $w_{y_i}$ 是类别 $y_i$ 的权重。
* **常见权重计算公式**：

$$w_i = \frac{\text{Total Samples}}{\text{Number of Classes} \times \text{Samples of Class } i}$$


* **主流框架实现**：
* **Scikit-learn**：在许多分类器中直接提供 `class_weight='balanced'` 参数（自动根据样本频率逆向计算权重）。
* **PyTorch**：在 `nn.CrossEntropyLoss(weight=class_weights_tensor)` 中传入权重张量。



### 2. 损失函数改进：Focal Loss

在极端不平衡（如图像检测中的背景与前景、语义匹配中的海量负样本）场景下，传统的类别权重可能无法解决简单样本过多（Easy Negatives）淹没梯度的问题。此时常用 **Focal Loss**。

* **原理**：动态缩放因子。它会根据样本预测的置信度，自动降低“易分类样本”（即那些模型已经很有把握猜对的多数类样本）的权重，使模型在训练时将主要注意力集中在难分类样本（Hard Examples）上。
* **公式特征**：

$$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$



其中 $(1 - p_t)^\gamma$ 是调制系数，$\gamma$ 越大，对易分样本的惩罚衰减越剧烈。

## 三、 重采样 vs. 加权：如何选择？

| 维度 | 重采样（Resampling） | 加权（Weighting） |
| --- | --- | --- |
| **本质** | 改变数据分布（增减样本） | 改变损失函数权重（调整惩罚力度） |
| **优点** | 直观，对大多数传统模型和深度模型均有效；便于后续进行数据可视化分析。 | 不增加训练数据量，训练速度快；不会引入合成样本带来的潜在噪声。 |
| **缺点** | 过采样会增加训练时间，且可能引入噪声；欠采样会丢失信息。 | 对极端不平衡（如 1:10000）有时效果有限；部分复杂模型调参较难。 |
| **推荐实践** | 树模型（如 XGBoost, LightGBM）或样本量适中时，SMOTE 是常用利器。 | 大规模深度学习、大模型微调或计算资源受限时，优先尝试 `class_weight` 或 Loss 调整。 |

## 四、 补充：不平衡数据的评估陷阱

在处理数据不平衡时，**绝对不能单纯依赖准确率（Accuracy）**。如果正负样本比例是 99:1，一个永远预测负例的“笨拙模型”准确率也能达到 99%，但毫无业务价值。

应采用以下更健康的评估指标：

1. **Precision（精确率）与 Recall（召回率）**：关注少数类的表现。
2. **F1-Score**：Precision 和 Recall 的调和平均数。
3. **PR-AUC（Precision-Recall Curve Area）**：在极度不平衡数据中，PR-AUC 比 ROC-AUC 更能敏锐反映模型对少数类的识别能力。
