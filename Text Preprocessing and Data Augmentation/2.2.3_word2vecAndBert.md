word2vecAndBert.py代码是一个经典的 **Word2Vec 静态词向量** 与 **BERT 动态预训练模型** 的对比与应用示例，主要用于展示传统词嵌入和现代 Transformer 语言模型在文本表示、相似度计算以及嵌入生成上的异同。

整个脚本可以分为五个核心模块：

---

### 一、 Word2Vec 嵌入生成模块

```python
sentences = [
    ["自然", "语言", "处理", "是", "人工智能", "的", "重要", "组成"],
    ["机器", "学习", "是", "人工智能", "的", "核心", "领域"],
    ["深度", "学习", "广泛", "应用", "于", "图像", "处理", "和", "语音", "识别"]
]

word2vec_model = Word2Vec(sentences, vector_size=50, window=2, min_count=1, sg=1, epochs=100)

```

* **核心逻辑**：使用 `gensim` 库训练了一个轻量级的 Word2Vec 模型。
* **参数解析**：
* `vector_size=50`：将每个词映射为 50 维的稠密向量。
* `sg=1`：使用 **Skip-gram** 结构（通过中心词预测上下文，适合小型语料）。
* `window=2`：上下文窗口大小为 2。


* **功能演示**：
* 获取单个词（如 `"自然"`、`"人工智能"`）的 50 维静态词向量。
* 计算词与词之间的相似度（如 `similarity("自然", "语言")`）。
* 寻找语义最相近的词（如 `most_similar("人工智能")`）。



---

### 二、 BERT 嵌入生成模块

```python
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
bert_model = BertModel.from_pretrained('bert-base-chinese')

def get_bert_embedding(text):
    inputs = tokenizer(text, return_tensors="pt")
    outputs = bert_model(**inputs)
    cls_embedding = outputs.last_hidden_state[:, 0, :]
    return cls_embedding

```

* **核心逻辑**：加载了中文预训练 BERT 模型（`bert-base-chinese`）。
* **特征提取**：
* 通过 `tokenizer` 将整句中文转化为 BERT 兼容的输入 Tensor。
* 利用 `bert_model` 前向传播，获取最后一层隐藏状态（`last_hidden_state`）。
* **取 `[CLS]` 标记**（即位置索引 `[:, 0, :]`）作为整句话的聚合语义表示（形状为 `[1, 768]`）。

* **核心思想**：对比**静态词向量**与**动态词向量**的区别。
* **本质差异**：
* **Word2Vec** 是**静态的**：一个词在任何语境下都对应同一个固定向量（查表即得）。
* **BERT** 是**动态的**（上下文相关的）：同一个词在不同句子中，其生成的向量会随着上下文变化而改变（体现一词多义）。

### 四、 综合分析与文本平均嵌入

```python
def average_word2vec_embedding(text, model):
    words = list(jieba.cut(text))
    valid_embeddings = [model.wv[word] for word in words if word in model.wv]
    if len(valid_embeddings) == 0:
        return torch.zeros(model.vector_size)
    return sum(valid_embeddings) / len(valid_embeddings)

```

* **核心逻辑**：由于 Word2Vec 是**基于词**的，若想表示一整句话，通常采用**简单的算术平均法**（Bag-of-Words 平均）。
* **中文适配**：使用 `jieba.cut` 将中文长句切分为词语列表，过滤掉不在 Word2Vec 词表中的词后，对剩余词向量求平均，以此作为整句的粗略向量表示。
