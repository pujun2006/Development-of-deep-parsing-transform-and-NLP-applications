character_level_embedding.py代码使用 PyTorch 框架实现了一个基础的**字符级嵌入模型（Character-level Embedding Model）**。它展示了如何从零构建字符词汇表、处理未登录字符（OOV）、对文本进行基于字符的定长编码填充，并通过嵌入层与平均池化（Mean Pooling）将整句文本转化为稠密向量表示。

下面对代码的各个部分进行详细拆解：

---

### 1. 准备文本数据

```python
# 示例文本数据，包含OOV词汇
sentences = [
    "深度学习是一种机器学习技术",
    "语言处理在人工智能中扮演重要角色",
    "自然语言处理是一门重要学科",
    "新兴技术包括量子计算和深度神经网络"
]

```

这里定义了 4 个包含专业领域术语的中文句子，作为模型的原始训练/处理语料。

---

### 2. 构建字符级词汇表

```python
# 创建字符级别词汇表
def build_char_vocab(sentences):
    char_vocab = set()
    for sentence in sentences:
        for char in sentence:
            char_vocab.add(char)
    char2idx = {char: idx + 1 for idx, char in enumerate(char_vocab)}
    char2idx['<PAD>'] = 0  # 添加填充标记
    return char2idx

char2idx = build_char_vocab(sentences)
vocab_size = len(char2idx)

```

* **按字符拆解**：遍历所有句子中的每一个字符，利用集合 `set` 去重，收集语料库中出现过的一切独立汉字。
* **建立映射字典 (`char2idx`)**：
* 为每个字符赋予一个从 1 开始的唯一整数索引。
* **特殊标记 (`<PAD>`)**：将索引 `0` 分配给 `<PAD>`（Padding，填充标记），用于对齐不同长度的句子。


* **`vocab_size`**：获取整个字符词汇表的总大小（包含 `<PAD>`）。

---

### 3. 定义字符级嵌入模型 (`CharLevelEmbedding`)

```python
# 定义字符级嵌入模型
class CharLevelEmbedding(nn.Module):
    def __init__(self, vocab_size, embed_dim):
        super(CharLevelEmbedding, self).__init__()
        self.char_embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)

    def forward(self, x):
        embedded_chars = self.char_embedding(x)
        # 计算字符嵌入的平均表示
        return embedded_chars.mean(dim=1)

```

* **`nn.Embedding`**：PyTorch 的查表嵌入层。
* `vocab_size`：词表大小。
* `embed_dim=16`：将每个字符映射为 16 维的稠密向量。
* `padding_idx=0`：指定索引 `0`（即 `<PAD>`）对应的嵌入向量在训练过程中始终保持为全零，不参与梯度更新。


* **前向传播 (`forward`)**：
* 输入形状为 `(batch_size, max_len)` 的字符 ID 张量。
* 经过嵌入层后，张量形状变为 `(batch_size, max_len, embed_dim)`。
* **平均池化 (`mean(dim=1)`)**：沿着序列长度维度（维度 1）求平均值，将一个包含多个字符的句子矩阵“压缩”为一个统一的 16 维句向量。



---

### 4. 文本编码与填充对齐 (`encode_sentence`)

```python
# 生成字符ID序列
def encode_sentence(sentence, char2idx, max_len=20):
    char_ids = [char2idx.get(char, 0) for char in sentence]  # 0作为OOV字符
    if len(char_ids) < max_len:
        char_ids += [0] * (max_len - len(char_ids))  # 填充字符
    else:
        char_ids = char_ids[:max_len]
    return torch.tensor(char_ids)

encoded_sentences = [encode_sentence(sentence, char2idx) for sentence in sentences]
encoded_tensor = torch.stack(encoded_sentences)

```

* **字符映射与 OOV 处理**：`char2idx.get(char, 0)` 尝试查找字符索引。如果某个字符不在词表中（即遇到未登录词/新字符），`.get()` 会返回默认值 `0`（将其安全降级为 `<PAD>` 或视为 OOV 字符处理）。
* **定长截断与填充 (`max_len=20`)**：
* 深度学习模型要求输入矩阵形状一致。若句子长度小于 20，则在末尾补 `0` 补齐；若大于 20，则截断前 20 个字符。


* **`torch.stack`**：将多个一维的张量堆叠为一个形状整齐的二维矩阵张量（`batch_size x max_len`）。

---

### 5. 模型初始化、执行与输出

```python
# 初始化模型
embed_dim = 16  # 嵌入维度
char_embed_model = CharLevelEmbedding(vocab_size, embed_dim)

# 生成字符级嵌入
char_embeddings = char_embed_model(encoded_tensor)

# 输出结果
print("字符级词汇表:", char2idx)
print("编码后的字符ID序列:\n", encoded_tensor)
print("字符级嵌入:\n", char_embeddings)

```

* 实例化设定 16 维的字符嵌入模型。
* 将编码后的二维张量 `encoded_tensor` 传入模型，顺利得到输出结果：
1. **字符级词汇表**：列出所有独立汉字及其对应的数字 ID。
2. **编码后的字符 ID 序列**：展示对齐到相同长度（20维）的整数矩阵。
3. **字符级嵌入**：输出每个句子经过平均池化后得到的最终 16 维稠密特征表示。
