dataAug.py代码实现了一个基于 Python 的中文文本数据增强（Data Augmentation）脚本，主要利用了 **Jieba**（中文分词工具）和 **NLTK (WordNet)**（语义词典）来实现**同义词替换**和**词级句子反转**。以下分模块详细拆解该代码：

---

### 一、 初始化与库导入

```python
import random
import jieba
import nltk
from nltk.corpus import wordnet as wn

# 首次使用需要下载中文 WordNet 支持
nltk.download('omw-1.4')
nltk.download('omw-2.0')
nltk.download('wordnet')

```

* **依赖库说明：**
* `random`：用于随机打乱词序和随机抽取同义词。
* `jieba`：国内最常用的中文分词库，将连续的中文文本切分为独立的词语列表。
* `nltk` 与 `wn`：自然语言处理工具包 NLTK 中的词网（WordNet）模块。通过指定 `lang='cmn'`（普通话/中文），它可以用来查询中文词汇的同义词。


* **资源下载：** `nltk.download` 用于下载多语言词网（OMW）及英文/通用 WordNet 语料库，这是支持跨语言同义词检索的基础。

### 二、 核心函数 1：中文同义词替换 (`synonym_replacement_zh`)

```python
def synonym_replacement_zh(sentence, n=2):
  # 1. 使用 jieba 切分为中文词语列表
  words = list(jieba.cut(sentence))
  new_words = words[:]
  
  # 2. 筛选并打乱候选词（优先替换长度大于1的词，避免单字替换带来的歧义）
  shuffled_words = [w for w in words if len(w) > 1]
  random.shuffle(shuffled_words)

  num_replaced = 0
  for word in shuffled_words:
    # 3. lang='cmn' 指定查询中文词条的同义词集合 (Synset)
    synsets = wn.synsets(word, lang='cmn')
    synonyms = set()

    for syn in synsets:
      for lemma in syn.lemmas('cmn'):
        syn_name = lemma.name()
        if syn_name != word: # 排除词本身
          synonyms.add(syn_name)

    # 4. 如果找到同义词，随机挑选一个替换原列表中的词
    if synonyms:
      synonym = random.choice(list(synonyms))
      new_words = [synonym if w == word else w for w in new_words]
      num_replaced += 1
      if num_replaced >= n: # 达到指定的替换次数后退出
        break

  return ''.join(new_words)  # 中文拼接不需要中间加空格

```

#### 逻辑亮点：

1. **精准过滤：** 通过 `len(w) > 1` 过滤掉大部分虚词、标点或无意义的单字，聚焦于具有实际语义的名词、动词或形容词。
2. **WordNet 多语言检索：** NLTK 的 WordNet 不仅包含英文，还通过 Open Multilingual WordNet (OMW) 关联了中文词汇。利用 `wn.synsets(word, lang='cmn')` 和 `lemma.name()` 可以跨语言或在多语言词典结构中检索同义词。
3. **安全替换：** 使用列表推导式将句中匹配到的所有该词实例进行替换，并通过控制 `n` 限制最大替换词数，防止过度改写导致句子语义完全丢失。

### 三、 核心函数 2：中文词级句子反转 (`reverse_sentence_zh`)

```python
def reverse_sentence_zh(sentence):
  # 使用 jieba 进行词级切分后反转
  words = list(jieba.cut(sentence))
  reversed_words = words[::-1] # 切片操作倒序排列
  return ''.join(reversed_words)

```

#### 逻辑亮点：

* **词级 vs 字符级：** 英文的反转通常按字符或按单词（空格分隔）进行。由于中文没有天然的空格分词，直接用 `[::-1]` 会把汉字顺序彻底打乱（例如“我喜欢”变成“欢喜我”）。而该函数先通过 `jieba.cut` **按词切分**，再将词的顺序颠倒（例如：“自然语言处理” $\rightarrow$ “处理” + “语言” + “自然”），在某些需要打乱局部逻辑、测试模型对语序鲁棒性的场景中更加合理。

### 四、 批量测试与输出

```python
sentences = [
    '机器学习可以用于分类和回归任务。',
    '深度学习的应用覆盖了计算机视觉和自然语言处理。',
    '数据增强方法可以帮助提高模型的泛化能力。',
]

print('--- 单句增强测试 ---')
print('原句:', sentence)
print('中文同义词替换:', synonym_replacement_zh(sentence))
print('中文词级反转:', reverse_sentence_zh(sentence))

print('\n--- 批量增强结果 ---')
for s in sentences:
  print('原句:', s)
  print('同义词替换:', synonym_replacement_zh(s, n=1))
  print('词级反转:', reverse_sentence_zh(s))

```

* 这部分代码展示了如何传入单句和多句列表进行自动化增强。
* 在批量测试中，将 `n` 设为 `1`（每次只替换 1 个词），可以温和地扩充文本多样性，避免句子由于替换过多而变得不通顺。
