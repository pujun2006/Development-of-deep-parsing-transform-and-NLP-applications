NGramAndBERT.py代码演示了自然语言处理（NLP）中两种不同粒度的分词方式：**基于统计窗口的字符级 n-gram 分词**以及**基于深度学习预训练模型的 BERT 子词分词（WordPiece）**。

下面对代码的各个部分进行详细拆解：

---

### 1. 库与模块导入

```python
import re
from nltk import ngrams
from transformers import BertTokenizer

```

* `re`：Python 的标准正则表达式库，用于文本清洗（如去除标点符号）。
* `ngrams`：来自 `nltk` 库的工具函数，用于快速生成指定长度 $N$ 的连续片段组合。
* `BertTokenizer`：来自 Hugging Face `transformers` 库的 BERT 分词器，用于加载官方的中文 BERT 分词工具。

---

### 2. 文本清洗与 n-gram 分词函数

```python
# 示例文本
text = "自然语言处理是人工智能的重要领域。"

# 定义n-gram分词函数
def generate_ngrams(text, n):
    # 去除标点符号
    text = re.sub(r'[^\w\s]', '', text)

    # 切分为单词列表
    #words = text.split()
    words = list(text)

    # 生成n-grams
    n_grams = list(ngrams(words, n))
    # 将n-gram转为字符串形式
    ngram_strings = [' '.join(gram) for gram in n_grams]

    return ngram_strings

```

* **去标点**：`re.sub(r'[^\w\s]', '', text)` 利用正则匹配移除了句末的句号 `.`，使文本变为 `"自然语言处理是人工智能的重要领域"`。
* **切分粒度（关键细节）**：
* 代码中注释掉了 `words = text.split()`（原本用于英文按空格切词）。
* 实际执行的是 `words = list(text)`，这会将中文句子**强行拆解为单字列表**：`['自', '然', '语', '言', '处', '理', '是', '人', '工', '智', '能', '的', '重', '要', '领', '域']`。


* **生成 n-gram 片段**：
* `ngrams(words, n)` 按照滑动窗口生成长度为 $N$ 的元组。
* `[' '.join(gram) for gram in n_grams]` 将元组中的单字用空格拼接回字符串形式，便于直观观察。



---

### 3. 执行 n-gram 与 BERT 分词

```python
# 二元和三元分词
bigrams = generate_ngrams(text, 2)
trigrams = generate_ngrams(text, 3)

# BERT分词
bert_tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
bert_tokens = bert_tokenizer.tokenize(text)

```

* **二元分词 (`bigrams`, $N=2$)**：
* 基于单字滑动窗口，输出结果形如：`['自 然', '然 语', '语 言', '言 处', ...]`。


* **三元分词 (`trigrams`, $N=3$)**：
* 输出结果形如：`['自 然 语', '然 语 言', '语 言 处', ...]`。


* **BERT 分词 (`bert-base-chinese`)**：
* 加载了中文 BERT 官方预训练分词器。
* 对于中文，`bert-base-chinese` 默认采取**按字切分**（Character-level Tokenization），同时会保留标点符号。因此其输出结果为：`['自', '然', '语', '言', '处', '理', '是', '人', '工', '智', '能', '的', '重', '要', '领', '域', '。']`。



---

### 4. 结果输出

```python
# 输出结果
print("原始文本:", text)
print("二元分词结果:", bigrams)
print("三元分词结果:", trigrams)
print("BERT分词结果:", bert_tokens)

二元分词结果: ['自 然', '然 语', '语 言', '言 处', '处 理', '理 是', '是 人', '人 工', '工 智', '智 能', '能 的', '的 重', '重 要', '要 领', '领 域']
三元分词结果: ['自 然 语', '然 语 言', '语 言 处', '言 处 理', '处 理 是', '理 是 人', '是 人 工', '人 工 智', '工 智 能', '智 能 的', '能 的 重', '的 重 要', '重 要 领', '要 领 域']
BERT分词结果: ['自', '然', '语', '言', '处', '理', '是', '人', '工', '智', '能', '的', '重', '要', '领', '域', '。']

注：BERT 分词器代码 bert_tokenizer.tokenize(text) 没有进行去标点的前置处理，它忠实地还原了输入文本中的每一个字符，包括最后的标点。

```

这段代码最终在控制台打印出原始文本、两种窗口大小的字级别 n-gram 组合，以及 BERT 分词器处理后的 Tokens 列表，方便直观对比传统统计滑动窗口与现代预训练模型分词的异同。
