EDA.py代码实现的是 **EDA（Easy Data Augmentation，文本数据增强）** 算法的 **中文适配版本**。

EDA 是 NLP 领域常用的一套简单高效的数据增强技术，由 Jason Wei 等人在 2019 年提出。它通过四种简单的文本扰动操作来扩充训练数据，从而提升模型的泛化能力。

由于代码中后半部分是对前半部分英文/通用框架的**中文优化版**（引入了 `jieba` 分词和中文 WordNet 支持），将重点围绕**第二段完整的中文实现代码**进行详细解析。

---

### 一、 整体架构概览

该代码主要包含以下几个部分：

1. **环境与库准备**：导入 `random`、`jieba`（中文分词）以及 `nltk` 的中文 WordNet 词库。
2. **四大核心增强算子**：
* 同义词替换 (SR, Synonym Replacement)
* 随机插入 (RI, Random Insertion)
* 随机删除 (RD, Random Deletion)
* 随机交换 (RS, Random Swap)


3. **EDA 主函数**：控制各算子的执行比例，完成从“分词 $\rightarrow$ 增强 $\rightarrow$ 拼接”的全流程。
4. **测试运行**：对输入的一句中文进行增强并打印结果。

#### 4. 随机删除 (Random Deletion, RD)

```python
def random_deletion(words, p):
  if len(words) == 1:
    return words
  new_words = [word for word in words if random.uniform(0, 1) > p]
  if len(new_words) == 0:
    return [random.choice(words)]
  return new_words

```

* **工作原理**：
* 以概率 $p$ 随机遍历并丢弃句子中的词。
* **安全保护**：为防止句子被删空（长度为 0），代码做了边界判断，若删光了则随机保留原句中的一个词。


* **目的**：模拟真实场景中常见的丢字、口语化不完整的情况，增强模型鲁棒性。

#### 6. EDA 主函数与中文适配亮点

```python
def eda(sentence, alpha_sr=0.1, alpha_ri=0.1, alpha_rs=0.1, p_rd=0.1):
  # 关键点 1：使用 jieba 进行中文分词
  words = list(jieba.cut(sentence))
  num_words = len(words)
  augmented_sentences = []

  # 计算各项操作的变换词数（基于比例 alpha）
  n_sr = max(1, int(alpha_sr * num_words))
  n_ri = max(1, int(alpha_ri * num_words))
  n_rs = max(1, int(alpha_rs * num_words))

  # 关键点 2：使用 ''.join() 拼接中文词语（不用空格）
  augmented_sentences.append(''.join(synonym_replacement(words, n_sr)))
  augmented_sentences.append(''.join(random_insertion(words, n_ri)))
  augmented_sentences.append(''.join(random_swap(words, n_rs)))
  augmented_sentences.append(''.join(random_deletion(words, p_rd)))

  return augmented_sentences

```

* **核心亮点（相比英文版代码的改进）**：
1. **分词处理**：英文天然以空格分词，而中文连写，因此必须通过 `jieba.cut` 将中文句子切分为词语列表。
2. **WordNet 语言参数**：调用 WordNet 时显式指定 `lang='cmn'`（Chinese Mandarin），以便准确抓取中文同义词。
3. **无缝拼接**：英文拼接时用空格 `' '.join(...)`，而中文词语之间不需要空格，因此改为了 ` ''.join(...)`。
4. **计算公式**：`n = max(1, int(alpha * num_words))` 确保即使句子较短，每种增强操作也能至少对一个词生效。
