StemmingAndLemmatization.py代码演示了自然语言处理（NLP）中词干提取（Stemming）**与**词形还原（Lemmatization）的具体实现过程。代码利用 `nltk`（Natural Language Toolkit）库对一组包含不同词性与形态变化的英文单词进行了处理与对比。

下面对代码的各个部分进行详细拆解：

---

### 1. 库与资源的导入和初始化

```python
import nltk
from nltk.stem import SnowballStemmer, WordNetLemmatizer
from nltk.corpus import wordnet

# 下载WordNet词典资源
nltk.download('wordnet')
nltk.download('omw-1.4')

# 初始化词干提取器和词形还原器
stemmer = SnowballStemmer("english")
lemmatizer = WordNetLemmatizer()

```

* **导入模块**：
* `SnowballStemmer`：比经典的 Porter 算法更现代、更强大的词干提取器（支持多语言，这里指定为 `"english"`）。
* `WordNetLemmatizer`：基于 WordNet 语义词典的词形还原器。
* `wordnet`：词典语料库，用于提供词汇之间的语义和形态关系。


* **资源下载**：`nltk.download()` 确保本地拥有 WordNet 词典及多语言词网扩展（`omw-1.4`），这是词形还原器正常运行所必需的依赖。
* **初始化**：分别实例化了 Snowball 词干提取器和 WordNet 词形还原器对象。

---

### 2. 准备测试数据

```python
# 示例文本数据
text = ["running", "happier", "boxes", "studies", "easily", "flying"]

```

测试列表包含了具有代表性的形态变化词汇：

* 动词分词（`running`, `flying`）
* 形容词比较级（`happier`）
* 名词复数（`boxes`）
* 动词第三人称单数或名复数同形（`studies`）
* 副词（`easily`）

---

### 3. 核心处理函数

```python
# 定义词干提取与词形还原函数
def stem_and_lemmatize(words):
    stemmed_words = []
    lemmatized_words = []
    for word in words:
        # 词干提取
        stemmed_word = stemmer.stem(word)
        stemmed_words.append(stemmed_word)

        # 词形还原，指定词性为动词以提高准确性
        lemmatized_word = lemmatizer.lemmatize(word, pos=wordnet.VERB)
        lemmatized_words.append(lemmatized_word)

    return stemmed_words, lemmatized_words

```

* **词干提取逻辑**：`stemmer.stem(word)` 纯粹基于规则通过截断后缀来获取词干，**不依赖词典和上下文**。
* **词形还原逻辑**：`lemmatizer.lemmatize(word, pos=wordnet.VERB)` 查阅词典将单词还原。
* **注意点（代码中的局限）**：此处代码在循环中**硬编码**指定了 `pos=wordnet.VERB`（动词词性）。这意味着无论输入是名词（如 `boxes`）还是形容词（如 `happier`），还原器都会**强制尝试将其当作动词**来处理。这会导致部分非动词的还原结果不够精准（例如 `boxes` 作为动词原形可能是 `box`，但如果原意是名词复数，正确的词形还原应当指定 `pos=wordnet.NOUN` 得到 `box`）。



---

### 4. 执行与输出

```python
# 清洗后的词干和词形还原结果
stemmed, lemmatized = stem_and_lemmatize(text)

# 输出结果
print("原始文本:", text)
print("词干提取结果:", stemmed)
print("词形还原结果:", lemmatized)

```
