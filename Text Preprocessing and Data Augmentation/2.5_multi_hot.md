multi_hot.py代码完整演示了前面讨论的**多标签分类、Multi-Hot 编码生成以及二进制存储优化**的整个核心流程。

下面逐段详细说明代码的逻辑和实现步骤：

---

### 一、 模拟数据集准备

```python
import pandas as pd
import numpy as np
import json

# 示例标签数据，包含多个标签
data = {
    "id": [1, 2, 3],
    "text": [
        "自然语言处理是一门重要的学科",
        "深度学习在图像识别领域表现优异",
        "机器学习可以用于预测股票价格"
    ],
    "tags": [
        ["NLP", "人工智能", "计算机科学"],
        ["深度学习", "计算机视觉", "人工智能"],
        ["机器学习", "金融", "预测"]
    ]
}

# 创建DataFrame
df = pd.DataFrame(data)

```

* **说明**：这里模拟了一个包含 3 个样本的数据集（`df`）。每个样本有唯一标识 `id`、文本内容 `text`，以及一个包含多个标签的列表 `tags`（例如第一条数据同时属于 `NLP`、`人工智能`、`计算机科学` 三个标签）。

---

### 二、 统计所有标签并建立索引字典

```python
# 获取所有唯一标签并生成标签索引字典
all_tags = sorted(set(tag for sublist in df['tags'] for tag in sublist))
tag_to_index = {tag: idx for idx, tag in enumerate(all_tags)}

```

* **说明**：
1. 通过推导式展平所有样本的标签列表，并用 `set` 去重、`sorted` 排序，获取整个数据集中**所有不重复的标签集合**（即标签空间）。
2. 为每一个标签分配一个固定的整数索引（例如：`{'NLP': 0, '人工智能': 1, ...}`）。这是后续构建固定长度 Multi-Hot 向量的基础。



---

### 三、 实现 Multi-Hot 编码函数并应用

```python
# Multi-Hot编码
def multi_hot_encode(tags, tag_to_index):
    multi_hot_vector = np.zeros(len(tag_to_index), dtype=int)
    for tag in tags:
        if tag in tag_to_index:
            multi_hot_vector[tag_to_index[tag]] = 1
    return multi_hot_vector

# 为每个样本生成Multi-Hot编码
df['multi_hot'] = df['tags'].apply(lambda tags: multi_hot_encode(tags, tag_to_index))

```

* **说明**：
1. `multi_hot_encode` 函数接收一个样本的标签列表和标签索引字典。
2. 首先创建一个全为 `0` 的 NumPy 数组（长度等于总标签数），数据类型为整型 (`int`)。
3. 遍历该样本拥有的标签，如果在字典中找到，则将该标签对应索引位置的值置为 `1`。
4. 使用 pandas 的 `.apply()` 方法将该函数应用到 DataFrame 的每一行，生成一列 `multi_hot` 向量。



---

### 四、 打印输出结果

```python
# 输出标签编码字典和每个样本的编码结果
print("标签编码字典:", tag_to_index)
print("\n每个样本的Multi-Hot编码:")
print(df[['id', 'text', 'multi_hot']])

```

* **说明**：展示最终的字典映射关系以及每个样本转化为 Multi-Hot 稀疏/多热向量后的直观结果。

---

### 五、 存储优化：二进制格式保存与加载

```python
# 存储优化：将编码后的标签矩阵保存为二进制格式
multi_hot_matrix = np.stack(df['multi_hot'].values)
np.save('multi_hot_labels.npy', multi_hot_matrix)

# 读取并展示存储的二进制标签矩阵
loaded_multi_hot_matrix = np.load('multi_hot_labels.npy')
print("\n加载后的Multi-Hot编码矩阵:")
print(loaded_multi_hot_matrix)

```

* **说明**：
1. `np.stack(...)` 将 DataFrame 中多行独立的 NumPy 向量堆叠组合成一个标准的 **2D 标签矩阵**（形状为 `样本数 × 总标签数`）。
2. `np.save(...)` 将这个矩阵以 **NumPy 原生的二进制格式（`.npy`）** 高效持久化到磁盘中。这种二进制存储去除了文本解析的开销，不仅文件体积小，而且在模型训练时能够实现极速加载。
3. `np.load(...)` 演示了如何在后续训练中直接将二进制矩阵快速读回内存。



---

### 六、 辅助存储（保存为 CSV）

```python
# 将DataFrame存储为CSV
df.drop(columns=['tags', 'multi_hot']).to_csv('data_with_labels.csv', index=False, encoding='utf-8')
print("\n已将数据和标签编码保存至CSV文件: data_with_labels.csv")

```

* **说明**：由于复杂的对象（如列表、NumPy 数组）直接存入 CSV 会变成字符串，可读性变差且读取时需要 `eval` 解析，因此这里移除了 `tags` 和 `multi_hot` 列，仅把基础的文本数据保存为常规的 `data_with_labels.csv` 文件。在实际项目中，通常是“文本/ID存放在 CSV 或数据库中，而标签矩阵采用二进制 `.npy` 或 `HDF5` 单独高效存储”。
