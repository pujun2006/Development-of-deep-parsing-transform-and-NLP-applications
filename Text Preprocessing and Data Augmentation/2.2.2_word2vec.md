word2vec.py代码演示并对比了自然语言处理（NLP）中的两种经典嵌入技术：**Word2Vec（静态词嵌入）** 与 **BERT（动态上下文嵌入）**。

下面对代码的各个部分进行详细拆解：

---

### 1. 准备训练数据与 Word2Vec 模型的训练

```python
# 示例文本数据
sentences = [
    ["自然", "语言", "处理", "是", "人工智能", "的", "重要", "组成"],
    ["机器", "学习", "是", "人工智能", "的", "核心", "领域"]
]

# 训练Word2Vec模型
word2vec_model = Word2Vec(sentences, vector_size=50, window=2, min_count=1, sg=1)  # 使用Skip-gram模型

```

* **预分词语料 (`sentences`)**：Word2Vec 需要接收“已分词”的句子列表（二维列表），这里提供了两个人工分好的中文句子。
* **Word2Vec 参数配置**：
* `vector_size=50`：将每个词映射为 50 维的稠密向量。
* `window=2`：上下文窗口大小为 2（考虑前后各 2 个词的共现关系）。
* `min_count=1`：忽略词频小于 1 的词（语料很小，所以设为 1 确保所有词都被收录）。
* `sg=1`：选择 **Skip-gram** 架构（以中心词预测上下文，适合小型语料）。



---

### 2. 获取 Word2Vec 词向量

```python
# 获取Word2Vec词嵌入
word2vec_nlp = word2vec_model.wv['自然']
word2vec_ai = word2vec_model.wv['人工智能']

```

* 通过 `word2vec_model.wv['词语']` 可以直接从训练好的静态词表中查询指定词汇的 50 维向量。
* **静态特性**：无论是哪个句子，只要词是“自然”或“人工智能”，其查出来的向量都是**固定不变**的。

---

### 3. BERT 分词器与模型的初始化

```python
# 初始化BERT分词器和模型
tokenizer = BertTokenizer.from_pretrained('bert-base-chinese')
bert_model = BertModel.from_pretrained('bert-base-chinese')

```

* 加载预训练的中文 BERT 分词器 (`BertTokenizer`) 和核心神经网络模型 (`BertModel`)。

---

### 4. 定义 BERT 嵌入提取函数

```python
# 定义BERT词嵌入提取函数
def get_bert_embedding(text):
    # 分词并转为ID
    inputs = tokenizer(text, return_tensors="pt")
    # 获取BERT嵌入
    outputs = bert_model(**inputs)
    # 获取[CLS]标记的嵌入表示
    cls_embedding = outputs.last_hidden_state[:, 0, :]
    return cls_embedding

```

* **`tokenizer(text, return_tensors="pt")`**：将输入的整句字符串进行子词切分，并转化为 PyTorch 格式的张量（包含 `input_ids`, `attention_mask` 等）。
* **`bert_model(**inputs)`**：将输入送入 BERT 模型进行前向传播，输出包含整个序列隐层状态的张量。
* **`outputs.last_hidden_state[:, 0, :]`**：
* BERT 在处理文本时，会在最前面自动拼接一个特殊的分类标记 `[CLS]`（Classification）。
* `[:, 0, :]` 表示提取序列中第一个位置（索引为 0 的 `[CLS]` 标记）的隐层向量。在文本分类或整句表征任务中，`[CLS]` 的向量通常被用来综合代表整句话的语义。



---

### 5. 执行与输出

```python
# 获取BERT嵌入
text = "自然语言处理是人工智能的重要组成"
bert_embedding = get_bert_embedding(text)

# 输出结果
print("Word2Vec '自然' 词嵌入:", word2vec_nlp)
print("Word2Vec '人工智能' 词嵌入:", word2vec_ai)
print("BERT句子嵌入:", bert_embedding)

```

这段代码最终在控制台打印出：

1. 词语“自然”的 50 维 Word2Vec 静态词向量。
2. 词语“人工智能”的 50 维 Word2Vec 静态词向量。
3. 整个句子“自然语言处理是人工智能的重要组成”通过 BERT 提取出的整句级向量（通常维度为 `[1, 768]`，其中 768 是 `bert-base` 的隐藏层维度）。
